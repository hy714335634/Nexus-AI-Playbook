# Bridge 多连接

## 这是什么

**Nexus Bridge** 是一条把 AI 助手和你自己服务器连起来的安全通道。只要在服务器上粘贴一条 `curl` 指令，Agent 就能在该服务器上执行 Shell 命令、读取状态、提交长任务——同一个会话最多可以**同时接入 5 台服务器**，一条指令还能在所有服务器上**并行执行**。

Bridge 不在 Nexus 后台保存你服务器的 SSH 密钥，也不需要你开放入站端口：连接由你的服务器**主动发起**，随时 `Ctrl+C` 即可断开。

## 使用场景

| 场景 | 怎么用 |
| --- | --- |
| **单机运维** | 让 Agent 帮你看 `df -h`、排查日志、重启服务。 |
| **多机巡检** | 接入多台服务器，一条 `server="all"` 同时拿到所有机器的状态。 |
| **长任务托管** | 系统升级、大构建、数据迁移等耗时任务交给 Bridge 的异步任务，Agent 只在完成时回看结果。 |
| **受控访问** | 给访客/同事开一个只读会话，用命令规则把 `rm`、`reboot` 等危险命令挡在门外。 |

## 如何使用

### 1. 在会话中打开 Bridge 面板

在任意会话右上角点击「Bridge」图标，弹出连接面板。

<!-- SCREENSHOT: bridge-panel-empty -->

### 2. 生成连接指令

面板上可以设置：

- **别名**（可选）：用于在多连接场景下区分服务器，不填则自动取 hostname。
- **连接模式**：`HTTP`（默认，穿透力强）或 `WebSocket`（延迟更低）。
- **自动重连**：开启后断线会自动恢复，最长可保留 24 小时。

点击「生成指令」，系统给出一条 `curl` 单行命令，类似：

```bash
curl -sSL 'https://your-nexus/bridge/script?mode=http' | \
  NEXUS_TOKEN="..." NEXUS_HOST="your-nexus" NEXUS_PORT="443" \
  NEXUS_SSL="true" python3 -
```

<!-- SCREENSHOT: bridge-curl-command -->

### 3. 在目标服务器上粘贴执行

登录到你要接入的服务器，**粘贴并运行**该命令。只要能访问 Nexus 地址、装有 Python 3，就能立刻看到欢迎横幅：

```

║   B R I D G E  ·  远程桥接已建立               ║
╚════════════════════════════════════════════════╝

✓ 连接成功  Nexus Bridge 通道已激活
┌──────────────────────────────┐
│  主机名称   web-01           │
│  操作系统   Linux            │
│  当前用户   ubuntu           │
└──────────────────────────────┘

⚡ Agent 现在可以通过此通道远程操控本服务器
```

<!-- SCREENSHOT: bridge-client-banner -->

### 4. 让 Agent 使用这台服务器

连接建立后，面板上会出现一个绿色勾选。接下来直接在聊天里提要求即可：

- 「帮我看一下 web-01 的磁盘占用」
- 「对所有服务器跑 `uptime` 对比一下」
- 「升级这台机器的系统包，升完告诉我」

Agent 会自动选择合适的工具：

| 工具 | 适用场景 | 典型动作 |
| --- | --- | --- |
| `remote_shell` | 一般命令（< 2 分钟） | 查状态、改配置、快速诊断 |
| `remote_shell(server="all")` | 多机并行 | 巡检、批量部署 |
| `remote_task` | 长耗时任务（> 2 分钟） | 升级、构建、迁移 |
| `remote_task_status` | 查进度/结果 | Agent 自行轮询 |

### 5. 新增更多连接或断开

- **继续添加服务器**：再次点击「新增连接」，重复上述流程。每条连接可单独设别名和命令规则。
- **断开单台**：在连接列表里点击该服务器右侧的断开按钮。
- **断开全部**：点击「全部断开」。

<!-- SCREENSHOT: bridge-multi-connection-list -->

### 6.（可选）设置命令规则

如果不希望 Agent 执行某些命令，可以在 Bridge 面板的「命令规则」里选一种模式：

| 模式 | 行为 |
| --- | --- |
| `none` | 不限制，所有命令放行 |
| `readonly` 预设 | 只允许 `ls / cat / ps / docker ps` 等只读命令 |
| `no_destructive` 预设 | 屏蔽 `rm -rf`、`shutdown`、fork bomb、`dd` 等破坏性命令 |
| 自定义白名单 | 只允许匹配正则的命令 |
| 自定义黑名单 | 拒绝匹配正则的命令 |

违规命令会直接被拦截，Agent 会收到 `BLOCKED` 提示并看到被拦截的规则。

## 关键参数 / 限制

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 每个会话最大连接数 | 5 | 超限时生成指令接口返回 `409`。 |
| 命令执行超时 | 120 秒 | `remote_shell` 的单次命令上限，可在 Agent 调用时调整。 |
| 连接空闲超时 | 300 秒 | 未收到心跳的连接会被标记为 `connection_lost`。 |
| 初始连接令牌有效期 | 10 分钟 | 超时后需重新生成 `curl` 指令。 |
| 重连令牌有效期 | 24 小时 | 仅「自动重连」开启时签发。 |
| 客户端最大重连尝试 | 10 次 | 超过后客户端脚本退出。 |
| 标准输出截断 | 末尾 50 KB | 超长日志只保留结尾。 |
| 标准错误截断 | 末尾 10 KB | 同上。 |
| 异步任务结果保留 | 1 小时 | 完成 1 小时后会被后台清理。 |
| 客户端依赖 | 仅 Python 3 标准库 | 无需额外 `pip install`。 |
| 命令工作目录 | 远端用户 `$HOME` | 所有命令默认在家目录执行。 |

## 常见问题

### Q1: Bridge 会把我服务器的凭据上传到云端吗？

不会。Bridge 连接由你的服务器**主动发起**，Nexus 只保存一个短期令牌用于握手，**不保存** SSH 密钥、root 密码等任何凭据。`curl` 命令里出现的 `NEXUS_TOKEN` 是一次性令牌，用过即失效。

### Q2: 我的服务器在内网 / 无公网 IP，能用吗？

可以。Bridge 只需要服务器能**访问** Nexus 服务的地址（默认 HTTPS 443），**不需要** Nexus 能访问到你的服务器。大多数企业内网都满足这个条件。如果外网完全封锁，请让运维开通对 Nexus 域名的出站白名单即可。

### Q3: 我关掉运行 `curl` 的终端会怎么样？

- **未开启自动重连**：连接立刻断开，之后 Agent 调用 `remote_shell` 会提示「无活跃连接」。
- **开启自动重连**：客户端会尝试重新建立连接（最多 10 次，每次间隔 5 秒）；24 小时内可用重连令牌恢复。只要**不是**你在 Bridge 面板点「断开」，重连就允许。

### Q4: Agent 能在 Windows 服务器上用吗？

Bridge 客户端基于 Python 3 标准库，理论上可在装有 Python 3 的 Windows / macOS 机器上运行；但远端命令默认以 Bash 的方式 `shell=True` 执行，且工作目录固定为家目录。在 Windows 上建议通过 WSL、Git Bash 或等价的 POSIX 环境运行客户端脚本，并注意命令语法差异。

### Q5: 长耗时任务断线了，结果会丢吗？

不会立即丢。`remote_task` 在远端后台线程执行，Agent 可随时用 `remote_task_status(task_id)` 查进度。任务结果在服务端默认保留 **1 小时**，建议 Agent 完成后尽快取回或让它直接写入服务器上的文件。

### Q6: 能审查 `curl` 拉下来的脚本内容吗？

可以。把 `curl -sSL '...'` 里的 URL 单独打开即可看到完整 Python 源码，脚本**仅使用标准库**、**只跟你配置的 Nexus 地址通信**。如果你的安全策略不允许管道执行，也可以先下载脚本、审计后再手动运行。
