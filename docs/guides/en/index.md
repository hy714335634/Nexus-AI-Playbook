# Guides & Tutorials

This is the hands-on chapter. A few end-to-end tutorials walk you through building real, working agents from scratch, then you'll connect Nexus-AI to the wider MCP ecosystem, and finally there's a collection of tips and best practices distilled from day-to-day use.

If you've finished the "Getting Started" chapter, work through the Hermes, Tech Blog, and MCP tutorials in order. If you just want to look up a specific tip, jump straight to "Tips & Best Practices".
