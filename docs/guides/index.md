# 使用指南

这一章是动手实践的部分：先用几篇实战教程带你从零构建几个真实可用的 Agent，再把 Nexus-AI 与外部 MCP 生态打通，最后汇总一批日常使用中积累下来的技巧与最佳实践。

如果你已经完成了「快速开始」章节，可以按顺序做完 Hermes、技术博客、MCP 三篇教程；如果你只想查阅某类技巧，直接跳到「技巧与最佳实践」即可。
