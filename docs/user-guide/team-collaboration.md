# 团队协作

在 Nexus-AI 里，你不必单打独斗。你做出来的智能体、技能、项目等成果，可以一次性交给整个团队使用；同事的成果，也会出现在你的工作台上。这篇文档告诉你如何和团队一起协作。

::: tip 一句话理解
把资源分享给「某个人」，是点对点；分享给「整个部门」，是一次让全组都能用——这就是团队协作最省事的方式。
:::

## 你所在的团队

在 Nexus-AI 里，每个人都会被归入一个或多个**团队**（也叫「部门」或「用户组」）。团队用来把同一个部门、同一个项目的人聚在一起，方便统一分享资源、统一管理。

关于团队，你需要知道几件事：

- 团队由**管理员统一创建和维护**。你被分到哪个团队、团队里有哪些人，都由管理员安排，你自己不需要（也无法）新建或修改团队。
- 团队可以有**上下级关系**，比如「市场部」下面再分「市场一组」「市场二组」，形成一棵组织树。
- 你在团队里的身份，决定了你能收到哪些分享——只要一份资源分享给了你所在的团队，你就自动能用。

::: info 找不到自己在哪个团队？
团队的划分由管理员负责。如果你不确定自己属于哪个团队，或需要加入某个团队，直接联系你的系统管理员即可。
:::

## 一次分享给整个团队

和同事协作，最常见的做法是把一组资源放进一个「文件夹」，然后把这个文件夹分享给**整个团队**，而不是挨个转发给每个人。

::: tip 先准备好文件夹
分享之前，你需要先有一个装着资源的文件夹。如何新建文件夹、往里面添加资源，请看[资源组与共享](./resource-groups-sharing.md)。这里只讲「分享给团队」这一步。
:::

操作步骤如下：

1. 打开你要分享的文件夹，进入它的详情页。
2. 点击右上角的「分享」按钮。
3. 在弹出的窗口里，把分享对象从「某个人」切换到**团队（部门 / 用户组）**，然后搜索并选中目标团队。
4. 为这个团队选择一个权限级别（查看者 / 编辑者 / 拥有者）。
5. 确认。团队里的每个人立刻就能在自己的「共享给我的」里看到这个文件夹。

![settings-sharing](/images/settings-sharing.png)

::: tip 新同事自动获得权限
分享给团队后，团队里**现有的每个人**都会拿到访问权；日后**新加入这个团队的人也会自动获得**，你不用再补分享一次。这正是「分享给团队」比「分享给个人」更省事的地方。
:::

## 权限级别怎么选

给团队分享时，你要为对方选一个权限级别。三种级别的区别如下：

| 权限 | 团队成员能做什么 |
| --- | --- |
| 查看者 | 只能查看和使用文件夹里的资源 |
| 编辑者 | 查看使用，并能调整文件夹里的内容 |
| 拥有者 | 完全管理，包括把文件夹再分享给别的团队或个人 |

::: warning 拥有者权限要慎重
把「拥有者」权限交给整个团队，意味着组里任何人都能修改内容、甚至把文件夹再分享出去。一般情况下，给团队「查看者」或「编辑者」就足够了。
:::

## 团队成员如何使用共享给自己的资源

如果有人把文件夹分享给了你所在的团队，你可以这样查看：

1. 在左侧导航栏点击「共享资源」。
2. 在「共享给我的」一组里，找到分享给你的文件夹。
3. 点开文件夹，就能看到里面的全部资源，并直接使用。

![resource-groups-list](/images/resource-groups-list.png)

::: info 你只能看到资源本身
作为被分享的一方，你能看到并使用文件夹里的资源，但看不到「这个文件夹还分享给了谁」。完整的分享名单只有文件夹的创建者和管理员能看到。
:::

## 收回团队的访问权

如果你是文件夹的创建者，想让某个团队不再能访问：

1. 进入文件夹详情页，找到「访问权限」区域。
2. 在列表里找到对应的团队那一行。
3. 把鼠标停上去，点击出现的「移除」按钮。

移除后，该团队的成员将不再能看到这个文件夹。你自己作为创建者（拥有者）的权限不受影响，也无法被移除。

::: warning 谁能分享和收回
只有文件夹的创建者或系统管理员能把它分享给团队、或收回团队的访问权。别人分享给你的文件夹，你无权替他改分享设置。
:::

## 常见问题

::: tip 我把资源分享给团队，但有个同事说看不到？
先确认三点：一是这位同事确实属于你分享的那个团队（团队成员由管理员维护）；二是你分享的是「团队」而不是某个人；三是让他刷新一下「共享资源」页面。如果仍看不到，联系管理员核对他的团队归属。
:::

::: tip 分享给团队后，还能单独给某个人更高的权限吗？
可以。团队分享和个人分享互不冲突。你可以先把文件夹以「查看者」分享给整个团队，再单独把某个人设为「编辑者」，这个人就会拥有更高的权限。
:::

::: tip 团队解散或调整了怎么办？
团队的增减、成员调整都由管理员操作。团队一旦调整，成员能访问的资源会随之自动更新——不再属于某团队的人，也就不再能访问分享给该团队的文件夹。
:::

::: tip 我想给团队分享「应用」可以吗？
不可以。「应用」不支持放进共享文件夹，因此也无法通过文件夹分享给团队。智能体、技能、项目、连接器、密钥、指令、工具、服务器、模板等其他类型都可以。如果你想让同事用你的 Agent，可以把它[发布成应用](./publish-first-app.md)，发布后它会出现在[应用中心](./app-center.md)，所有人都能看到。
:::
