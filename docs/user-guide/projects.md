# 工坊管理

工坊是你所有创建任务的大本营。每当你想让系统帮你做一个 Agent、一个技能、一个工具或一个应用，都从这里开始；创建过的项目也会全部留在这里，方便你随时回来查看进度、管理或删除。

![projects-list](/images/projects-list.png)

## 如何打开工坊

点击左侧导航栏的「工坊」，就能进入工坊页面。页面顶部标题是「工坊」，下方副标题写着「管理 Agent 构建项目，追踪构建进度」。

## 从工坊创建新东西

页面顶部有四张彩色卡片，对应四种可以创建的东西。点哪张就开始创建哪种：

| 卡片 | 说明 |
| --- | --- |
| Agent | 构建智能 Agent |
| Skill | 构建可复用 Skill |
| Tool | 构建独立工具 |
| App | 构建可发布应用 |

操作方法：

1. 想清楚你要做什么，然后点击对应的卡片。
2. 点「Agent」会进入一个专门的创建页面；点「Skill」「Tool」或「App」会弹出一个填写窗口，按提示写下你的需求即可。
3. 填好需求、确认创建后，系统就开始在后台一步步构建，并把这个项目加入下方的项目列表。

::: tip 构建要等多久？
一次完整构建通常需要约 20–40 分钟。你不用一直守着，可以先去做别的事，稍后回来查看结果。想了解每一步进展，请看「构建进度」一篇。
:::

::: warning 「App」点击后提示升级？
「App」（可发布应用）是企业版才有的功能。如果你使用的是基础版，点击「App」卡片会弹出升级提示，而不会进入创建流程。其余三种（Agent、Skill、Tool）不受影响。
:::

## 看懂项目卡片

创建过的项目都会以卡片形式排列在页面下方。每张卡片会告诉你这个项目的关键信息：

- **名称**：例如「中英互译助手」。
- **类型标签**：标明这是 Agent、Skill、Tool 还是 App。
- **状态标签**：当前进行到什么程度（见下表）。
- **需求描述**：你当初填写的那段话。
- **构建概况**：一共分几步、花了多长时间、处理的文字量等。
- **进度**：正在构建的项目会实时显示完成百分比和当前所处的步骤。

项目的常见状态有：

| 状态 | 含义 |
| --- | --- |
| 构建中 | 系统正在后台制作，会实时显示进度 |
| 已完成 | 已经做好，可以去对应的列表页使用 |
| 失败 | 构建没能完成 |
| 已暂停 | 你手动停下了构建，可随时恢复 |

## 快速找到某个项目

项目多了以后，用页面上的筛选、搜索和排序功能可以快速定位。

**按状态查看**：页面上方有一排状态统计，显示「构建中」「已完成」「失败」以及「总计」各有多少个。点击其中一项即可只看该状态的项目。

**按类型筛选**：紧邻的一排按钮可按类型过滤——「全部」「Agent」「Skill」「Tool」「App」，每个后面都带着数量。如果某个类型下既有新建的项目、也有在原有成果上修改的项目，还会多出「构建」和「更新」两个小按钮，方便你进一步区分。

**搜索**：在「搜索项目名称...」输入框里输入关键词，列表会即时缩小到名称匹配的项目。

**排序**：点击「最近更新」下拉菜单，可以换一种排列方式：

| 排序方式 | 效果 |
| --- | --- |
| 最近更新 | 最近有变化的排在最前（默认） |
| 最近创建 | 最新建立的排在最前 |
| 名称 A–Z | 按名称正序排列 |
| 名称 Z–A | 按名称倒序排列 |

## 在已有成果上做的更新

有些项目是在原来成果的基础上改出来的（例如把一个应用从旧版本升级到新版本）。这类项目的卡片上会出现版本箭头，比如「v1→v2」「v3→v4」，一眼就能看出它是第几次改动。

如果同一个成果被更新过很多次，工坊只在列表里保留最新的那一条，其余较早的更新会折叠收起，卡片上用一个小徽标标出更新次数，让列表保持清爽。想看全部更新记录时，点一下「更新」按钮即可把它们全部展开。

## 打开项目查看进度

点击任意一张项目卡片，就会进入这个项目的构建进度页，在那里可以看到每一步的详细进展、暂停或恢复构建，以及删除项目。具体说明请看「构建进度」一篇。

## 常见问题

**创建后可以关掉页面吗？**
可以。构建在后台自动进行，关掉页面或退出登录都不会中断它。稍后回到工坊，点开对应项目就能接着看进度。

**为什么筛选后有些项目不见了？**
它们只是被筛选条件暂时隐藏了。把状态或类型切回「全部」、清空搜索框，就能重新看到所有项目。

**做好的东西去哪里用？**
当项目状态变成「已完成」后，你就可以在对应的列表页（例如 Agent 列表、应用中心）找到并使用刚刚做好的成果了。
