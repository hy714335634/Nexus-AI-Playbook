# 技巧与最佳实践

功能你都会用了，这一篇是"用得更顺手"的经验集：怎么把需求说清楚、怎么和 Agent 高效对话、怎么把好用的成果攒下来反复用。都是些不难做、但能明显提升结果的小习惯，挑你用得上的看即可。

::: tip 一句话记住
**结果好不好，八成取决于你把需求和问题说得清不清楚。** 下面大半篇都在教你这件事。
:::

## 一、把需求描述得更好

创建 Agent 时，你写的那段描述，直接决定了造出来的助手好不好用。一句好描述通常包含三件事：**给谁用、要它做什么、希望的结果长什么样**。

| 不够清楚 | 更好的说法 |
|----------|------------|
| 帮我处理文档 | 创建一个能读取 PDF 合同、提取关键条款并列成清单的助手 |
| 分析数据 | 创建一个能分析每月销售表格、找出增长和下滑并写成简短总结的助手 |
| 做个客服 | 创建一个能根据我们的产品说明回答常见客户问题的助手 |

![agents-new](/images/agents-new.png)

几个实用习惯：

1. **说清楚"输入"和"输出"**：它拿到的是什么（一份表格？一段文字？），你想要的是什么（一份清单？一段总结？一张图？）。
2. **举个例子**：如果能给一句"比如遇到 XX 就 YY"的例子，造出来的助手会更懂你的意图。
3. **一次只让它专注一件事**：与其造一个"什么都能干"的万能助手，不如造几个各管一摊的专用助手，每个都更好用。
4. **用你平时说话的方式写**：不需要任何专业或技术词汇——这正是平台的设计目的。

::: tip 想不好怎么描述？
先照着上表改一句就行。造好后不满意，随时可以让它重新调整，不必一次到位。更多技巧见[创建 Agent](./create-agent.md)。
:::

## 二、不追求一次到位

造 Agent 不是一锤子买卖。**第一版当草稿看**，用几句真实任务试一试，再告诉它哪里要改——这样比反复琢磨"怎么一次写完美的描述"省事得多。

- 造好后先用**一件你最初就想让它做的事**去试，看结果对不对。
- 不满意就直接在对话里说"这里换成……""结果再简短些"，或者回到创建页重新调整。
- 大改动可以直接重新造一个，旧的留着对比，挑好用的那个。

## 三、和 Agent 高效对话

![chat](/images/chat.png)

- **发送快捷键是 Shift + Enter**：按 Enter 只是换行，不会发送。这点和多数聊天软件相反，容易踩坑。
- **一次说清一个任务**：与其把五件事塞进一句话，不如一件一件说，回答会更准。
- **给足背景**：把相关的前提、限制、偏好一起讲清楚，它不用猜，你也少来回。
- **方向不对就喊停**：回复过程中发送按钮会变成「停止生成」，点它就能中断，已经写出来的内容会保留，你可以换个问法。
- **一个话题开一段会话**：同一个 Agent 可以开多段会话，各自独立、互不干扰——一段聊正事、一段做试验，回头都找得到。

::: tip 对话很长、回答变慢了？
点对话工具条上的「压缩上下文」，让系统把早前的内容整理收拢，Agent 就能继续流畅作答。日常细节见[对话](./chat.md)。
:::

## 四、善用文件

对话时可以带上文件，让 Agent 结合文件内容来回答，比你把内容手打进去省事得多。

- 支持上传图片、Excel、Word、PDF 等，也可以**直接粘贴截图**。
- 文件连同你的问题一起发送即可。
- 想找 Agent 处理后生成的文件，点顶部「文件管理」，在「工作空间」里查看和下载。

## 五、把好用的成果攒下来

用着用着，你会积累不少 Agent、对话和文件。花点心思归置，下次就能快速找回、反复复用，而不是每次从头再来。

| 做法 | 好处 |
|------|------|
| 给相关工作建一个[工坊](./projects.md)分门别类 | 找东西不再靠翻记录 |
| 把常用的 Agent [收藏](./chat.md)起来 | 下次一步就能打开 |
| 把成熟好用的 Agent 发布成[应用](./app-center.md) | 自己和同事都能开箱即用 |
| 把一套做事方法沉淀成[技能](./skills.md) | 换个场景也能复用，不用重教 |

::: tip 越用越省力
平台的设计思路就是"攒得越多、越好用"。今天多花一分钟归置，明天就少花十分钟重复劳动。
:::

## 六、让 Agent 更能干、更自动

当基础操作用顺了，可以往这几个方向进阶：

- **接上真实数据和系统**：给 Agent 装[工具](./tools.md)，或接入公司已有系统（见[业务集成中心](./integration-center.md)），它就能查真实信息、办真实业务。
- **让它定时自动跑**：用[事件任务](./events.md)让 Agent 按时间自动工作，比如每天早上自动出一份报告，不用你手动催。
- **随身召唤**：界面里的[内置助手](./assistants.md)能随时帮你查数、答疑、指路，遇到不会的先问它。

## 七、遇到问题别慌

- **构建卡住或失败**：先刷新[构建进度](./build-progress.md)页看看是不是已经继续了；确实失败就重新发起一次，或把需求描述得更清楚些。
- **回复是一段段冒出来的**：这是实时作答的正常表现，不是卡住了，等它写完即可。
- **登录不进去**：先确认网址、账号、密码没输错（注意大小写），仍不行联系管理员。
- **实在搞不定**：问一下界面里的[内置助手](./assistants.md)，或联系你们的管理员。

## 常见问题

**我不懂技术，也能把 Agent 用好吗？**
能。这套平台就是给不写代码的业务人员用的。用你平时说话的方式描述需求、提问，就是最好的用法。

**描述总是写不好，有没有捷径？**
有。照着"给谁用、做什么、要什么结果"三点写，再参考本页第一节的对照表改一句，然后交给它试——试完再改，比空想快得多。

**造好的 Agent、聊过的对话会丢吗？**
不会。它们都留在你的账号里，下次登录还在，可以反复使用。

**同一个 Agent 开好几段会话会互相串吗？**
不会。每段会话相互独立，可以放心一段聊正事、一段做试验。

**接下来该学什么？**
回到[学习路径](./learning-path.md)，对照你的目标挑下一篇即可。
