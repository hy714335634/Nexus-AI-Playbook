# Avatar 空间

Avatar 是你在 Nexus-AI 里的**数字分身**，它有一块专属的空间叫「My Home」。它持续观察你在平台上的行为——你和哪些 Agent 聊过、构建过什么、做了哪些操作——把这些行为映射成一张关于你的知识网络，再从中提炼出提醒、洞察和待办，主动推到你面前。你也可以随时进来和它聊聊、告诉它你的偏好和规矩。

这篇教你从开通 Avatar 开始，认识 My Home 里的每一块区域，学会看提醒、和 Avatar 对话、以及需要时怎么暂停它。

::: tip Avatar 和普通对话有什么不一样？
普通[对话](./chat.md)是你主动去找某个 Agent 问问题。Avatar 反过来——它观察你在平台上的一切行为，把你的工作模式、习惯、偏好都映射成一张知识网络，再主动把发现推给你。它不是帮你跑腿的助手，而是一面**能照见你工作规律的镜子**。
:::

## 打开 My Home

点左侧边栏的「My Home」进入你的 Avatar 空间。

## 第一步：开通 Avatar（仅首次）

第一次进 My Home，你会看到一个开通引导页：

1. 页面中间显示标题「开启你的数字分身空间」，下方有一个「开启 Avatar」按钮。
2. 点「开启 Avatar」。
3. 稍等约 2-3 秒，系统会为你准备好专属空间。
4. 准备完成后，自动跳到「提醒」标签页，你会看到 Avatar 已经为你生成了几张欢迎卡片。

![avatar-onboarding](/images/avatar-onboarding.png)

::: warning 点一下就开通，没有二次确认
点「开启 Avatar」会立即开通，中间不会再问你一遍。开通后即可正常使用；如果之后想停用，见文末的[暂停或注销 Avatar](#暂停或注销-avatar)。
:::

## 认识主界面

开通后，My Home 顶部有一排标签，对应五个区域：

| 标签 | 作用 |
|------|------|
| **提醒** | Avatar 主动推给你的卡片：提醒、洞察、待办、待确认事项。标签上的数字是当前条数 |
| **聊天** | 直接和你的 Avatar 对话 |
| **我的家** | 一个虚拟房间，把 Avatar 观察到并归纳出的各类内容分区摆放 |
| **知识图谱** | Avatar 梳理出来的知识网络，能看到人、事、内容之间的关联 |
| **设置** | 调整 Avatar 的相关选项 |

下面逐个来看。

## 提醒：Avatar 主动推给你的卡片

「提醒」是你进 My Home 最常看的地方。Avatar 把要告诉你的事都做成一张张**卡片**，你可以逐张处理。

![avatar-cards](/images/avatar-cards.png)

### 卡片长什么样

每张卡片有一个标题、一段说明，下方是几个操作按钮。比如刚开通时常见的三张：

- **一条建议**——例如「最近 7 天你有 51 次对话」，问你要不要生成一份本周摘要。按钮有「立即整理」「不用」「提问」「推迟」「完成」。
- **一条引导**——请你写下希望 Avatar 永远记住的事（比如「回答用简体中文」这类长期偏好）。
- **一条引导**——请你写下 Agent 必须遵守的硬性规矩（比如「花钱的操作必须先问我」）。

不同卡片的按钮会不一样，含义都很直白：**立即整理／立即处理**让 Avatar 现在就动手，**推迟**稍后再提醒，**完成**表示这件事已处理好，**提问**可以就这张卡片继续追问，**不用／稍后再说**则是这次先跳过。

### 按类型筛选

卡片列表上方有一排筛选按钮，帮你只看某一类，数字是各类的条数：

| 筛选 | 看什么 |
|------|--------|
| 全部 | 所有卡片 |
| 紧急 | 需要马上处理的 |
| 提醒 | 一般提醒事项 |
| 洞察 | Avatar 总结出的发现和建议 |
| 待确认 | 需要你拍板确认的事项 |
| Agent | 和 Agent 运行相关的卡片 |

### 顶部快捷操作

列表顶部还有三个批量按钮：

- **「⚡ 智能处理建议」**——让 Avatar 一次性帮你处理可自动完成的建议类卡片。
- **「📋 一键确认待办」**——批量确认待办事项。
- **「📅 调度日程」**——把带时间的事项安排进日程。

右上角的「🗑 清理」清掉过期或不再需要的卡片，「刷新提醒列表」重新拉取最新卡片。列表下方可以调每页显示条数（10 / 20 / 50 / 100）并翻页。

::: tip 卡片会自己过期吗？
会。大多数卡片放一阵子会自动过期消失，不用你手动清。需要你确认的卡片时效更短——**如果 24 小时内没回应，它会自动过期**，所以看到「待确认」类卡片尽量早点处理。
:::

## 聊天：直接和 Avatar 说话

想直接问 Avatar，或者随手记点东西，就用「聊天」标签。

![avatar-chat](/images/avatar-chat.png)

1. 第一次进来会提示「这是你和 Avatar 第一次对话，直接说点什么吧」。
2. 在底部输入框（提示「对自己说...」）里输入内容。
3. 点「说」按钮发送（输入框为空时按钮不可点）。
4. Avatar 会结合它对你的了解来回应。

聊天框上方有一排小图标（📬 收件箱、📚 书架、📅 日历、🗄️ 档案等），点一下能快速跳到「我的家」里对应的区域。想从头开始，可以点「清空对话历史」。

::: tip 这个聊天和普通对话是分开的
这里是专门和你的 Avatar 说话的地方，和左侧边栏的[对话](./chat.md)是两套独立的记录，互不干扰。
:::

## 我的家：一个虚拟房间

「我的家」用一个虚拟房间的样子，把 Avatar 从你的行为中归纳出来的各类内容分门别类摆好，比一堆文件夹更直观。

![avatar-my-home](/images/avatar-my-home.png)

进来时上方是一句问候（如「下午好，我整理了 3 条提醒」）和几张快捷卡片，还有「和 Avatar 聊聊」「全部提醒」「图谱」几个按钮，方便你快速跳转。

房间里每个区域对应一类内容，点一下就能进去看：

| 区域 | 放的是什么 |
|------|-----------|
| 📚 书架 | 你的偏好与规则（长期记住的事、硬性规矩） |
| 🔥 壁炉 | Avatar 当前的状态 |
| 🖥️ 工作台 | 笔记和便签 |
| 📋 白板 | Avatar 的反思与总结 |
| 📅 日历墙 | 待办与日程 |
| 🗄️ 档案柜 | 历史会话记录 |
| 🧪 配方 | 常用的工作流与快捷操作 |
| ✉️ 收件箱 | 提醒（同「提醒」标签的卡片） |

区域按钮上的数字是里面的条数（如「📚 2 书架」表示书架里有 2 条内容）。右上角的「换装」按钮可以换房间主题（默认是「古典书房」），纯属外观，不影响内容。

## 知识图谱：看内容之间的关联

「知识图谱」把 Avatar 梳理出来的人、事、内容用一张关系网展示出来，帮你一眼看清它们之间怎么关联。

![avatar-knowledge-graph](/images/avatar-knowledge-graph.png)

- 顶部有搜索框，输入关键词可以定位某个节点。
- 有四种视图可切换：**全景**（默认，看全部）、**我的**、**Avatar**、**路径**。
- 右侧有「刷新」按钮和缩放滑块。

::: info 刚开通时图谱是空的
Avatar 需要先积累一段时间的动态，才能慢慢织出这张网。刚开通时图谱是空的很正常，用一阵子后回来看就会有内容了。
:::

## 真实场景：Avatar 如何帮你发现自己的规律

> 你用了两周平台，先后构建了好几个数据分析类 Agent，每次都给它们装上类似的工具（读取 CSV、做数据清洗、生成图表）。某天打开 My Home，你看到一张洞察卡片：
>
> **「你好像经常做数据分析——要不要把常用的那几个工具打包成一个可复用的 [Skill](./skills.md)？下次建 Agent 时直接一键挂上。」**
>
> 你没有主动去整理，Avatar 自己从你的行为里看出了规律，把建议推到了你面前。

这就是 Avatar 作为数字分身的核心能力：它不等你开口，而是从你的**行为模式**里主动提炼出洞察。普通 Agent 只回答你的问题，Avatar 能告诉你"你自己还没意识到的事"。

## Avatar 多久整理一次？能不能让它马上动手？

Avatar **大约每小时会在后台自动整理一次**，把这段时间的新动态归拢、更新记忆、生成新卡片。这个过程完全在后台进行，你不用一直守着。

如果你等不及，想让它现在就整理，有两个办法：

- 在「提醒」里点某张建议卡片上的**「立即整理」**。
- 打开命令面板（按 `⌘K` / `Ctrl+K`），里面有**「立即激活 Avatar」**和**「Avatar 推理」**两个操作，前者让它立刻整理最近动态，后者让它根据当前情况再生成一批建议卡片。命令面板里还能快速跳到「打开知识图谱」「和 Avatar 对话」等 Avatar 相关入口。

::: tip 整理需要点时间
让 Avatar 立即整理后，它需要一小会儿在后台完成，不是秒出结果。你可以先去做别的，过会儿回「提醒」页刷新一下看新卡片。
:::

## 暂停或注销 Avatar

如果你暂时不想用 Avatar，或想彻底注销，可以在「设置」里操作。有两种方式：

| 方式 | 效果 |
|------|------|
| **保留数据停用** | 暂停 Avatar，不再自动整理和推送，但你的偏好、记忆、历史都留着，随时可以恢复 |
| **完全注销** | 清除你 Avatar 空间里的全部数据，不保留 |

::: warning 完全注销无法找回
「完全注销」会删掉你 Avatar 空间里的所有内容，且**不可恢复**。只是想歇一阵子的话，请选「保留数据停用」。
:::

停用后想再用回来，在「设置」里点恢复即可。选了「保留数据停用」的，恢复后你之前的偏好和记忆都还在。

::: info 只能停用自己的 Avatar
出于隐私，你只能停用或恢复自己的 My Home。（管理员在需要时可以协助处理他人的空间。）
:::

## 常见问题

**我没主动做什么，Avatar 怎么就有卡片了？**
这是它该做的事。Avatar 会在后台留意你最近的动态，自动整理成提醒和建议推给你。看到不需要的卡片，点「不用」或「🗑 清理」清掉即可。

**Avatar 会看到我所有东西吗？安全吗？**
My Home 是你的私人空间，只有你自己（和管理员）能看到。Avatar 整理的都是你自己在平台上的活动。

**我怎么让 Avatar 长期记住某个偏好？**
去「提醒」里回应那张引导卡片，或在「我的家」的**书架**区域写下你的偏好和硬性规矩。写进去之后，Agent 在为你工作时会遵守这些。

**开通 Avatar 后能反悔吗？**
能。去「设置」里选「保留数据停用」先暂停；确定不再需要，也可以「完全注销」清空数据。
