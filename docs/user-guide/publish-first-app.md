# 发布第一个应用

这篇带你从零走完一遍：把一个 Agent 变成一个**可以分享的网页应用**，再发布出去，让别人打开链接就能用——不用登录、不用懂技术。全程大约十几分钟，跟着一步步点就行。

::: info 跟完这篇，你能做到什么？
假设你已经建好了一个合规审查 Agent——它包含公司内部的政策知识库、文档分析工具、以及你定制的审查规则。现在你想让法务团队也能用，但他们不想学新系统。你只需要按本篇把它发布成应用：法务同事打开链接，把合同条款粘进去，点一下提交，就能拿到一份结构化的合规分析报告。不用登录、不用培训、不用找你帮忙。

这就是"发布应用"的价值：把你精心调教的 Agent（定制规则 + 专业工具 + 知识库）变成**任何人都能直接用的自助服务**。
:::

::: tip 开始之前
你需要至少有一个可用的 Agent。如果一个都还没有，先看[创建 Agent](./create-agent.md)；想快点走一遍，直接用界面上现成的「General Assistant」这类通用助手也可以。发布之前建议先在[对话](./chat.md)里测试几轮，确认它回答得像样。
:::

想了解应用的全部功能（版本管理、访问鉴权、使用记录等），可在跑通这一遍之后再看[应用中心](./app-center.md)。如果你要把应用共享给团队内其他人共同管理，另见[资源组与分享](./resource-groups-sharing.md)。

## 全流程一览

| 步骤 | 你要做的事 | 大概耗时 |
|------|------------|----------|
| 1. 新建应用 | 选一个 Agent，起个名字，说清楚你想要什么 | 1 分钟 |
| 2. 生成页面 | 点一下，等系统自动把应用页面做出来 | 几分钟 |
| 3. 发布 | 设好有效期和访问方式，点发布 | 1 分钟 |
| 4. 分享 | 复制链接发给别人 | 1 分钟 |

## 第一步：新建应用

1. 点左侧边栏的「应用中心」进入。
2. 点右上角蓝色的「+ 新建应用」按钮，弹出新建向导。
3. 选一个背后要用的 Agent——它才是真正干活的那个。用顶部搜索框可以按名字找；点卡片选中，**最多选 5 个**。第一次建议只选 1 个。
4. 选一个图标，填上应用**名字**（必填）。
5. 在需求框里用大白话描述你想要什么，比如"输入一段产品介绍，帮我生成一张营销落地页"。说得越具体，做出来越贴合。
6. 点「创建应用」。

![apps-create](/images/apps-create.png)

::: tip 需求怎么写才好？
把三件事说清楚：让用户**填什么**（输入）、你想**得到什么**（输出）、页面**长什么样**（比如"左边填表单，右边显示结果"）。不用写得像技术文档，日常说话就行。
:::

## 第二步：生成应用页面

创建完会自动进入**应用详情页**，顶部有一条流程指示器：**需求 → 生成 → 就绪**。

1. 「需求」这一步的输入框里已经带上了你刚才填的内容，可以再补充或修改。
2. 点「开始设计」，系统就开始自动工作：先理解需求，再生成整个应用页面，中途**不需要你确认**。
3. 生成过程中，界面只显示一个不断增长的字符计数（「已生成 N 字符」），静静等它完成即可。
4. 生成成功后自动进入「就绪」状态，右侧出现应用的**实时预览**——就是它做好后的真实样子。

![apps-builder](/images/apps-builder.png)

在右侧预览里可以直接试着操作一下，还能在 **Desktop（桌面）** 和 **Mobile（手机）** 两种尺寸间切换，看它在电脑和手机上分别长什么样。

::: tip 生成要等多久？
一般几分钟内就好，你会看到字符计数一直在涨。这段时间可以先去泡杯咖啡，回来多半就好了。
:::

::: warning 中途出错怎么办？
如果生成没成功，界面会弹出提示并退回「需求」这一步。多半是需求描述太笼统——把想要的输入、输出、页面样子补充清楚，再点一次「开始设计」重试即可。
:::

## 第三步：发布应用

预览没问题、状态是「就绪」后，就可以发布让别人用了。

1. 点右上角的「发布」按钮，弹出发布设置窗口。
2. **设置有效期**：从下拉里选链接的有效时长，比如 7 天、30 天、90 天，或（如果管理员允许）「无限期」。到期后链接自动失效，访客会看到过期提示页。
3. **选择访问方式**：决定谁能打开你的应用。

| 访问方式 | 效果 |
|----------|------|
| **公开** | 任何拿到链接的人都能直接使用，无需登录 |
| **密码保护** | 你设一个用户名和密码，访客要先输入才能进入 |
| **API Key** | 需要密钥才能访问，主要面向技术调用 |

4. 设好后点「发布」。第一次建议选**公开**，最省事。

![apps-publish](/images/apps-publish.png)

::: warning 想立刻停止对外访问？
点「下线」即可，应用会**立即**停止对外服务，之前发出去的链接也打不开了。想重新对外，再走一次「发布」就行。
:::

## 第四步：分享给别人

发布成功后，页面顶部会出现「复制链接」和「打开应用」两个按钮：

1. 点「打开应用」，自己先在新标签页里看看别人会看到的样子。
2. 点「复制链接」拿到公开地址，把它发给同事、客户或任何人。

对方**不用登录、不用注册**，在浏览器里打开链接就能用：按提示填表单或输入内容，点提交，应用就会调用背后的 Agent，把结果直接显示在页面上。

![apps-public](/images/apps-public.png)

::: tip 访客产生的用量算谁的？
访客免登录使用，所有用量都记在你（应用所有者）名下。为防止被滥用，平台对匿名访问做了限流，正常使用不受影响。
:::

## 做完之后

恭喜，你的第一个应用已经上线了。接下来你可能想：

- **改点东西**：不用重建。在详情页左栏点「版本与更新」，用一句话描述想改什么，系统会自动更新并生成新版本——详见[应用中心](./app-center.md#更新应用与管理版本)。
- **看别人怎么用**：点顶部「调用记录」，能看到每一次访问的完整过程。
- **换个 Agent 或加能力**：在「涉及的 Agent」卡片里点「编辑配置」调整。
- **让团队成员也能管理这个应用**：把应用共享给你的团队——详见[资源组与分享](./resource-groups-sharing.md)。

这些进阶操作都在[应用中心](./app-center.md)里有完整说明。
