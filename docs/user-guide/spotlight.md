# Spotlight 命令面板

Spotlight 是全站通用的搜索和快捷入口。不管你在哪个页面，按一个快捷键就能弹出它：输入几个字，立刻找到某个页面、某个 Agent、某个应用、某段历史对话，或者一键执行「创建 Agent」「刷新页面」这类常用操作。你不用再一层层点菜单去找东西。

**举个场景**：你已经建了 30 个 Agent，现在急着找其中一个——按下快捷键，打两三个字，列表里立刻就只剩它，回车直接进入[对话](./chat.md)。整件事不到两秒，比一层层翻菜单快得多。

::: tip 一个快捷键走遍全站
记住 `⌘K`（Mac）或 `Ctrl+K`（Windows）就够了。想去哪、想找什么、想做什么，先按它。
:::

## 打开 Spotlight

有三种方式，任选一种：

1. 按快捷键 **`⌘K`**（Mac）或 **`Ctrl+K`**（Windows / Linux）——最快。
2. 点左侧边栏上方的搜索框「搜索或提问... ⌘K」。
3. 点页面顶部操作栏的搜索框「搜索... ⌘K」。

弹出后，屏幕会变暗，中间出现一个搜索面板，输入框已经自动聚焦，直接打字即可。

![dashboard](/images/dashboard.png)

## 面板长什么样

面板从上到下分两部分：

- **顶部搜索框**：输入你要找的内容；右边的「ESC」小标签提示你按 Esc 可以关闭。
- **下方结果列表**：按分组显示可跳转的页面、可执行的操作和搜到的内容。

**还没输入任何字**时，列表最上面会有一个「最近访问」分组，把你刚去过的几个页面列出来，方便一键回去。

## 直接搜索想找的东西

在搜索框里输入关键词，列表会**实时过滤**，边打边缩小范围，几乎没有延迟。

- 匹配方式很宽松：只要名称、描述或标签里**包含**你输入的文字就会出现，不区分大小写。
- 比如输入 `agent`，列表就只留下和它相关的项：「创建 Agent」「Agents」「与 Agent 对话」，以及各个 Agent、相关会话和工具等。

![spotlight-search](/images/spotlight-search.png)

## 能搜到、能做的事

Spotlight 把全站内容按分组整理好，一次都能搜到：

| 分组 | 里面是什么 | 回车后 |
|------|-----------|--------|
| 最近访问 | 你最近去过的页面 | 直接回到那个页面 |
| 快捷操作 | 创建、刷新等常用动作 | 立即执行对应操作 |
| 页面 | 工作台、Agents、对话、能力工具等全站导航 | 跳转到该页面 |
| 应用 | 应用中心里的应用 | 打开应用；已发布的还能一键打开公开页 |
| Agents | 你的所有 Agent | 打开该 Agent |
| 会话 | 最近的历史对话 | 回到那段对话 |
| 工作流 / 项目 | 正在进行或已完成的构建任务 | 查看构建状态 |
| 业务集成 | 已连接的连接器 | 打开对应设置 |
| 工具 / MCP 服务器 | 平台内置工具和已接入的服务 | 查看简介或信息 |

::: tip 分组会随你的账号变化
上面这些分组只有在**有内容时才出现**。比如你还没创建过应用，就不会看到「应用」分组；每个分组标题旁的数字是该类内容的数量。
:::

## 快捷操作有哪些

不输入搜索词时，「快捷操作」分组里放着最常用的一键动作：

- **创建 Agent** — 用自然语言描述需求，开始构建一个新 Agent。
- **新建项目** — 启动一次 Agent 构建流程。
- **新建应用** — 进入应用中心创建 AI 应用。
- **刷新页面** — 重新加载当前页面。
- 一组 **Avatar** 相关动作：让 Avatar 立即整理你的活动、根据当前状态生成建议、打开知识图谱、查看推送、浏览空间文件，或直接和 Avatar 对话。

## 用键盘操作

Spotlight 为键盘操作而生，全程可以不碰鼠标：

1. 打字**过滤**结果。
2. 按 **↑ / ↓** 上下选择，被选中的那一项会高亮。
3. 按 **回车** 打开或执行选中项。
4. 按 **Esc** 关闭面板；或者用鼠标点面板外的暗色区域关闭。

::: tip 有些项还有第二个按钮
选中某一项时，右侧可能出现小按钮：应用有「打开发布页」在新标签页打开公开地址，Agent 有「查看简介」和「对话」，工作流有「查看状态」。想执行主操作直接回车，想用这些附加动作就点对应的小按钮。
:::

## 常见问题

**Spotlight 和普通搜索有什么区别？**
它不只是搜索框，还是全站的快捷指挥台：既能搜内容，也能直接跳页面、执行操作。一个入口把「找东西」和「做事情」都包了。

**为什么我看不到某些分组？**
分组只在有内容时才显示。没有应用就没有「应用」分组，没有历史对话就没有「会话」分组——这很正常，随着你使用平台，能搜到的东西会越来越多。

**输入后没有任何结果怎么办？**
说明当前没有匹配项，面板会显示无结果提示。换个更短或更常见的关键词再试，比如只打前几个字。

**关掉面板会丢东西吗？**
不会。Spotlight 只是一个临时的搜索和跳转层，关掉它不影响你正在做的任何事，随时可以再按 `⌘K` 唤起。
