# 登录与界面导览

这是你使用 Nexus AI 的第一步。本篇教你如何登录，并带你认识登录后看到的整个界面：左边的导航栏、顶部的操作区、随时可用的搜索面板，以及中英文切换。看完这一篇，你就能自己找到想去的地方。

## 登录

1. 打开浏览器，访问管理员发给你的网址。如果你之前退出过登录，系统也会自动把你带到登录页。
2. 你会看到写着「Nexus AI」的登录页面，中间是一张登录卡片。
3. 在「用户名」输入框里填写你的账号。
4. 在「密码」输入框里填写你的密码。
5. 点击「登录」按钮。

![login](/images/login.png)

登录成功后，页面会自动跳转到工作台首页，你就可以开始使用了。

::: tip 下次不用重新登录
登录后刷新页面或关掉浏览器再打开，通常还会保持登录状态，不需要每次都重新输入账号密码。
:::

::: warning 登录不成功怎么办
如果账号或密码填错，卡片顶部会出现一条红色提示。请核对后重新输入。这里没有"忘记密码"入口——如果你忘了密码，请联系你们的管理员帮你重置。
:::

::: info 有的单位用统一账号登录
如果你所在的单位启用了"统一登录"，登录页上不会出现用户名和密码框，而是一个直接跳转的登录按钮。点它以后，会带你到单位统一的登录页面输入账号，验证通过后自动回到 Nexus AI。具体以你看到的页面为准。
:::

## 认识主界面

登录后你看到的界面分成两大块：**左侧是导航栏**，用来在不同功能之间切换；**右侧是主内容区**，显示你当前所在页面的内容。

![dashboard](/images/dashboard.png)

### 左侧导航栏

左侧导航栏从上到下依次是：

| 区域 | 内容 | 作用 |
| --- | --- | --- |
| 顶部 | 产品 Logo 与名称 | 点一下随时回到工作台首页 |
| 搜索入口 | 「搜索或提问…」 | 打开全局搜索面板（下一节详细介绍） |
| 主导航 | 工作台、My Home、Agents、对话、工坊、能力中心、业务集成、应用中心、共享资源、任务面板、业务洞察、用量报告、审计追踪、服务状态 | 点击进入对应功能页 |
| 底部 | 设置、用户管理、语言切换、你的账号信息、退出登录 | 账号相关操作与系统设置 |

点击任意一项，右侧主内容区就会切换到对应的页面，当前所在的那一项会以彩色高亮显示。

::: tip 你看到的菜单可能更少
导航栏里显示哪些项目，取决于你的账号权限。像"用户管理""设置""审计追踪"这类通常只对管理员开放。如果某一项你看不到，说明你的账号暂时没有相应权限，属正常现象。
:::

### 收起和展开导航栏

如果你想让主内容区更宽敞：

1. 把鼠标移到导航栏顶部，点击 Logo 右侧的收起按钮。
2. 导航栏会收窄，只剩下一列图标。
3. 想临时看看某个图标是什么，把鼠标停在图标上即可显示名称；把鼠标移到收窄的导航栏上，它还会自动展开预览。
4. 再次点击顶部的按钮，即可把导航栏固定回展开状态。

### 底部的账号区

导航栏最下方是和你账号有关的操作：

- **你的账号信息**：显示当前登录的用户名，点击可进入个人资料页。
- **退出登录**：点击后会退出当前账号并回到登录页。
- **语言切换按钮**：用来在中文和英文之间切换（见后文）。

## 用搜索面板快速跳转

界面里藏着一个很好用的搜索面板，能让你不用一层层点菜单，直接跳到想去的地方或执行常用操作。

1. 按键盘上的 `⌘K`（Mac）或 `Ctrl+K`（Windows），也可以直接点击导航栏里的「搜索或提问…」。
2. 屏幕中间会弹出一个搜索框，输入光标已经自动就位。


3. 不输入任何字时，面板会按分类列出常用去处，比如"工作台""创建 Agent""Agents""对话"等，你可以用键盘上下键选择。
4. 想快速找某样东西，直接输入关键词。比如输入 `agent`，列表会立刻只留下和它相关的项目——包括页面、你的 Agent、相关会话等。


5. 用方向键选中想去的一项，按回车即可跳转；有的项目右侧还有"对话""查看简介"这类小按钮，可以直接点。
6. 想关闭面板，按 `Esc` 键，或点一下面板外面的灰色区域即可。

::: tip 记住一个快捷键就够了
只要记住 `⌘K` / `Ctrl+K`，在任何页面都能随时打开这个搜索面板，是全站最快的跳转方式。
:::

## 切换界面语言

Nexus AI 支持中文和英文两种界面语言，可以随时切换。

1. 在左侧导航栏底部找到语言按钮：中文界面下显示「EN」，英文界面下显示「中」。
2. 点击这个按钮。
3. 页面会自动刷新（大约一两秒），刷新后整个界面的菜单、按钮、标题就都变成了另一种语言。


::: tip 语言选择会被记住
切换后系统会记住你的选择，下次登录仍然是这种语言。注意：像 Agent 名称、项目名称这类你自己创建的内容不会被翻译，会保持原来的文字。
:::
