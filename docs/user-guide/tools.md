# 工具库

工具就是 Agent 的"本领"——比如算数、读文件、抓网页、生成图片、查时间等等。你给 Agent 配上哪些工具，它就能替你做哪些事。**工具库**这个页面，就是让你看清平台里有哪些现成的工具、按需查找，还能构建或导入你自己的工具。

::: tip 谁适合看这篇
市场、运营、分析、客服等业务同学。你只需要会用浏览器点界面，不需要任何技术背景。构建工具也一样——用一句话说清需求，平台替你造。
:::

## 打开工具库

有两种方式进入：

1. 点左侧菜单里的 **能力中心**，在「工具」卡片上点「进入管理」。
2. 或者直接打开工具页面。

进去后，页面标题是「能力工具」，顶部有三个标签页：**工具** / 技能 / MCP 服务。本篇只讲**工具**这个标签页。

![ability-tools](/images/ability-tools.png)

## 看懂工具列表

工具页面从上到下主要有这几块：

- **右上角按钮**：「导入工具」和「构建工具」——分别用来加入现成工具、和让平台帮你造新工具。
- **搜索框**：输入关键词快速找工具。
- **一排类型按钮**：全部 / 内置工具 / 生成工具 / 系统工具 / 模板工具 / 导入工具。
- **分类下拉菜单**：按用途（如文件操作、网络请求等）筛选。
- **工具卡片**：主区域里一张张卡片，每张显示**工具名称**和**一句话描述**，告诉你这个工具是干什么的。
- **数量统计**：页面上会显示工具总数，以及其中有多少是内置的、多少是导入的（例如"255 个工具 · 内置 31 · 导入 0"）。

::: tip 光看卡片就够认出工具
每张卡片上的名称加一句描述，通常就足以判断这个工具是不是你要的，不用逐个点开。
:::

## 工具的几种类型

页面顶部那排按钮，是按工具的**来源**来分的。点任意一种，只看该类工具；点「全部」看所有。

| 类型 | 是什么 |
| --- | --- |
| 内置工具 | 平台自带、开箱即用的基础本领，比如算数、读写文件、抓网页、生成图片、查时间 |
| 生成工具 | 之前通过「构建工具」让平台帮你造出来的工具 |
| 系统工具 | 平台运转所依赖的内部工具 |
| 模板工具 | 可作为样板参考、供构建时借鉴的工具 |
| 导入工具 | 你或同事从外部准备好、导进来的工具 |

## 查找一个工具

工具多了以后，用下面几种方式快速定位：

1. **按名字或描述搜索**：在「搜索工具...」框里输入任意片段，列表会实时缩小范围。
2. **按类型筛选**：点上面那排按钮（内置工具、生成工具等），只看某一类。
3. **按用途筛选**：点「全部分类」下拉菜单，选一个用途分类，比如：

| 分类 | 大致用途 |
| --- | --- |
| File Operations | 读写、编辑文件 |
| Web & Network | 访问网页、调用网络服务 |
| Multi-modal | 处理图片、音频、视频 |
| RAG & Memory | 检索知识、记住信息 |
| Code Interpretation | 运行代码做计算 |
| Shell & System | 系统与环境相关操作 |
| AWS Services | 与云服务交互 |
| Browser Automation | 自动操作浏览器页面 |
| Agents & Workflows | 多个 Agent 协作、编排流程 |
| Utilities | 算数、查时间等小工具 |

搜索、类型、分类可以叠加使用，一起把范围缩到最小。

## 构建你自己的工具

现成工具不够用时，你可以用一句话描述需求，让平台帮你造一个专属工具——和造 Agent 一样，全程不用写代码。

1. 在工具页面右上角点「构建工具」，弹出「工具构建」窗口。
2. 在「工具需求描述」框里，用日常话说清你想要一个能做什么的工具。说得越具体越好，例如：「创建一个获取指定时区当前时间的工具，输入时区名称（如 Asia/Shanghai），返回该时区的当前日期和时间」。
3. 「工具名称（可选）」可以填也可以留空，留空时平台会自动起名。
4. 确认无误后点「开始构建」（想放弃就点「取消」）。

![tool-build-dialog](/images/tool-build-dialog.png)

点了「开始构建」后，页面会**立即跳转**到一个项目详情页，你能在这里看到构建一步步推进的进度。

![tool-project-detail](/images/tool-project-detail.png)

::: tip 构建要等多久？
大约几分钟到几十分钟不等，取决于工具的复杂度。这段时间你不用一直盯着，可以先去忙别的，等会儿回来看结果——进度会一直保留。造好后，这个工具会出现在工具列表的**生成工具**里。
:::

## 导入现成的工具

如果你或你的技术同事已经准备好了现成的工具文件，可以直接导进来使用。

1. 在工具页面右上角点「导入工具」。
2. 在弹出的窗口里按提示提供工具文件。
3. 平台会先检查一遍，确认无误后加入工具库，出现在**导入工具**里。

::: tip 这一步偏进阶
导入工具需要先有现成的工具文件，通常由技术同事准备。如果你只是想要一个新工具，用上面的[构建你自己的工具](#构建你自己的工具)更简单——描述需求，平台替你造。
:::

::: warning 有的工具需要"钥匙"才能用
有些导入的工具需要绑定一把**密钥**（相当于访问外部服务的钥匙）才能正常工作。如果某个工具提示"需要密钥"，请到**业务集成**里的密钥管理去绑定对应的密钥。
:::

## 常见问题

**内置工具、生成工具、系统工具……这么多类型有什么区别？**
简单说：**内置工具**是平台自带、直接能用的；**生成工具**是你让平台帮你造的；**导入工具**是从外部加进来的；**系统工具**和**模板工具**偏平台内部使用，日常一般用不到。想找能直接用的，先看内置工具。

**造好的工具会不会丢？**
不会。构建完成的工具会一直留在**生成工具**里，下次登录还在，可以反复使用，也能配给你的 Agent。

**构建失败了怎么办？**
在项目详情页看看是卡在哪一步；如果确实失败，重新发起一次构建，或把需求描述得更清楚些。仍不行就联系管理员。

**这些工具我要怎么用？**
工具本身不单独运行，而是配给 Agent 后由它在干活时自动调用。你只要在创建或编辑 Agent 时选好要用的工具即可，剩下的交给 Agent。
