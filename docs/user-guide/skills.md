# 技能系统

技能（Skill）是一整套"专长打包"——它把一类任务的做法、说明和可能用到的小工具打成一个包。给 Agent 配上一个技能，就等于给它请了个懂行的师傅：比如「做 PPT」「处理 Excel 表格」「写 PDF 文档」，Agent 拿到对应技能后就知道该怎么一步步完成这类活。**技能**这个页面，就是让你看清平台里有哪些现成技能、按需查找，还能构建、导入或把它们组合起来。

::: tip 谁适合看这篇
市场、运营、分析、客服等业务同学。你只需要会用浏览器点界面，不需要任何技术背景。构建技能也一样——用一句话说清需求，平台替你造。
:::

::: info 技能和工具有什么不一样？
简单说：**工具**是单项本领（比如"查时间"这一个动作），**技能**是一整套做法打成的包，往往包含一份说明、几个工具和参考资料，教 Agent 完成一整类任务。想给 Agent 加一个小动作，用[工具](./tools.md)；想让它掌握一整套做事方法，用技能。
:::

## 打开技能页面

有两种方式进入：

1. 点左侧菜单里的 **能力中心**，在「技能」卡片上点「进入管理」。
2. 或者直接打开技能页面。

进去后，页面标题是「Skills 管理」，顶部有三个标签页：工具 / **技能** / MCP 服务。本篇只讲**技能**这个标签页。

![ability-skills](/images/ability-skills.png)

## 看懂技能页面

技能页面从上到下主要有这几块：

- **右上角按钮**：「刷新」「导入 Skill」「组合」「Skills 构建」——分别用来刷新列表、加入现成技能、把多个技能组合成一组、以及让平台帮你造新技能。
- **搜索框**：在「搜索 Skill...」里输入关键词快速找技能。
- **视图切换**：**分组** / 平铺。分组视图把技能按来源归到一个个文件夹里；平铺视图则把所有技能平铺成一片卡片。
- **技能分组**：主区域里一个个文件夹，每个文件夹是一组技能。

## 技能分组

在**分组**视图下，技能被归到几个文件夹里，每个文件夹旁会显示里面有多少个技能。常见的几组是：

| 分组 | 里面装的是什么 |
| --- | --- |
| Community Skills | 平台自带、大家通用的一批现成技能，比如做 PPT、处理 Excel、生成 PDF 等 |
| System Skills | 平台运转所依赖的内部技能 |
| Generated Skills | 之前通过「Skills 构建」让平台帮你造出来的技能 |
| Private Skills | 你自己的私有技能 |
| 从外部导入的分组 | 你或同事从外部整批导进来的技能，会单独成一组（组名通常带来源信息） |

点文件夹这一行就能把它**展开**，看到里面每个技能的卡片——每张卡片显示技能的**名称**、**版本号**和**一句话描述**。再点一次就收起。


::: warning 展开时别点到垃圾桶图标
把鼠标移到分组这一行时，右侧会出现一个**垃圾桶图标**（删除该分组）。想展开分组，请点文件夹名称那一行；只有确实要删除整组时才点垃圾桶。若不小心弹出了「确认删除」窗口，点「返回」关掉即可，不会有任何改动。
:::

## 查看一个技能

点任意一张技能卡片（比如 `skill-creator`），进入这个技能的详情页。页面顶部是技能名称，右上角有「返回」「分享」和「更多操作」按钮。下面一排标签页让你从不同角度了解这个技能：

| 标签页 | 看到什么 |
| --- | --- |
| Skill 详情 | 这个技能的完整说明——它是做什么的、怎么用，图文并茂地展示出来 |
| Files | 这个技能包含的所有文件清单 |
| 工具 | 这个技能会用到的工具 |
| Evals | 这个技能的测评相关内容 |
| Settings | 这个技能的设置项 |

页面上还会显示技能的基本信息：来源（系统 / 社区 / 生成）、分类、版本号、文件数量、大小和标签，帮你快速判断它是不是你要的。


::: tip 光看详情就能判断
打开「Skill 详情」标签页读一遍说明，通常就能明白这个技能能帮你做什么、适不适合你的场景，不用逐个文件去翻。
:::

## 构建你自己的技能

现成技能不够用时，你可以用一句话描述需求，让平台帮你造一个专属技能——和造 Agent、造工具一样，全程不用写代码。

1. 在技能页面右上角点「Skills 构建」，弹出构建窗口。
2. 在需求描述框里，用日常话说清你想要一个能帮 Agent 做什么的技能。说得越具体越好。
3. 确认无误后点开始构建。

点了开始构建后，页面会跳转到一个项目详情页，你能在这里看到构建一步步推进的进度。


::: tip 构建要等多久？
大约几分钟到几十分钟不等，取决于技能的复杂度。这段时间你不用一直盯着，可以先去忙别的，等会儿回来看结果——进度会一直保留。造好后，这个技能会出现在 **Generated Skills** 分组里。
:::

## 导入现成的技能

如果你或你的技术同事已经准备好了现成的技能，可以直接导进来使用。

1. 在技能页面右上角点「导入 Skill」。
2. 在弹出的窗口里按提示提供技能来源。
3. 平台会先检查一遍，确认无误后加入技能库，单独归到一个分组里。

::: tip 这一步偏进阶
导入技能需要先有现成的技能来源，通常由技术同事准备。如果你只是想要一个新技能，用上面的[构建你自己的技能](#构建你自己的技能)更简单——描述需求，平台替你造。
:::

## 把技能组合起来

如果你经常一起用到好几个技能，可以把它们打成一个**组合**，方便统一管理和调用。

1. 在技能页面右上角点「组合」，弹出「创建组合」窗口。
2. 填写组合的**名称**和**描述**。
3. 在技能列表里勾选你想放进这个组合的技能（可以用搜索框快速找），选好后确认创建。

组合可以自由挑选来自不同分组的技能，不受来源限制。

## 常见问题

**技能和工具到底有什么区别？**
工具是单项本领，一个动作（比如"查时间"）；技能是一整套做法的打包，通常包含说明、几个工具和参考资料，教 Agent 完成一整类任务。要给 Agent 加个小动作用工具，要它掌握一套方法用技能。

**这些技能我要怎么用？**
技能不单独运行，而是配给 Agent 后由它在干活时自动参照。你只要在创建或编辑 Agent 时选好要用的技能即可，剩下的交给 Agent。

**造好的技能会不会丢？**
不会。构建完成的技能会一直留在 **Generated Skills** 分组里，下次登录还在，可以反复使用，也能配给你的 Agent。

**System、Community、Generated 这几种标签是什么意思？**
它们标的是技能的**来源**：**System** 是平台运转所依赖的内部技能；**Community** 是平台自带、大家通用的一批；**Generated** 是你让平台帮你造出来的。想找能直接用的，先看 Community。

**展开分组时怎么弹出了删除窗口？**
分组这一行右侧的垃圾桶图标是"删除分组"，和展开区域挨得比较近，容易点岔。弹出「确认删除」窗口时点「返回」即可关掉，不会有任何改动；再点一次分组名称那一行就能正常展开。
