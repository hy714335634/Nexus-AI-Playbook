# 对话

对话是你日常和 Agent 打交道的地方：选一个 Agent，开一段会话，像聊天一样把问题或任务发给它，它一段段地实时回你。这篇教你从零开始完成一次完整对话，并认识对话界面上每个按钮是干什么的。

::: tip 开始之前
你需要至少有一个可用的 Agent。如果一个都还没有，先看[创建 Agent](./create-agent.md) 把它造出来；只想快速走一遍，可以直接用界面上现成的「General Assistant」这类通用助手。
:::

## 打开对话页

点左侧边栏的「对话」，进入对话页。页面分成三块：

| 区域 | 位置 | 作用 |
|------|------|------|
| Agent 与会话列表 | 左栏 | 选择要对话的 Agent，以及它下面的历史会话 |
| 对话区 | 中间 | 你和 Agent 一来一回的消息都显示在这里 |
| 配置面板 | 右栏（默认收起） | 查看当前 Agent 的说明、可用工具等信息 |

刚进来时还没选 Agent，中间会提示「从左侧选择一个 Agent 开始对话」。

![chat](/images/chat.png)

## 第一步：选择一个 Agent

左栏顶部有几个**快速启动**的通用助手，点一下就能直接用：

- **General Assistant** — 多功能通用助手
- **Deep Research** — 联网做深度资料研究
- **Data Analyzer** — 数据分析
- **Content Creator** — 内容创作

如果要用你自己造的 Agent，点左栏的「选择 Agent」下拉，从列表里挑一个。选中后，左栏会列出这个 Agent 下的**会话列表**。

::: tip Agent 和 APP 两个标签
下拉选择器上有「Agent」和「APP」两个标签。平时选 Agent 就行；APP 标签是用来和已经发布上线的**应用**对话的，用法见[应用中心](../guides/apps.md)。
:::

## 第二步：创建一个会话

一段**会话**就是一次独立的聊天记录。同一个 Agent 你可以开好几段会话，各自的上下文互不干扰——比如一段聊工作、一段做测试。

1. 选好 Agent 后，中间会提示「选择或创建会话」。
2. 点「创建新会话」。
3. 左栏会立刻出现一条新会话，系统自动用**创建时间**给它命名（如「会话 2026/7/12 15:08:09」）。
4. 中间切换成对话界面，显示空状态提示「开始与 xxx 对话吧」。

以后要回到某段会话，点左栏对应的那一条即可，之前的消息都还在。

## 第三步：发送消息

在底部输入框里输入你的问题或任务，然后发送。

::: warning 发送快捷键是 Shift + Enter
和大多数聊天软件相反：**按 Enter 只是换行，不会发送**。要发送，请按 **Shift + Enter**，或直接点右下角的发送按钮。发送按钮上也写着「Shift+Enter 发送」提醒你。输入框为空时发送按钮不可点。
:::

1. 点击底部输入框（提示文字「输入消息...」），输入内容。
2. 按 **Shift + Enter** 或点发送按钮。
3. 你的消息立刻出现在对话区上方。
4. Agent 开始作答，文字会**一段段实时显示**出来——这是正常的，说明它正在边想边写。回复里可能包含加粗、标题、表格等排版，会自动渲染成好看的样式。

![chat-streaming](/images/chat-streaming.png)

::: tip 回复要等多久？
简单问题通常十几到二十秒就答完。如果任务复杂、需要查资料或调用工具，会久一些；这期间界面会显示它当前在做什么（比如「正在调用工具…」），你不用担心它卡住了。
:::

## 回复过程中你能做什么

Agent 正在作答时，原来的发送按钮会变成 **「停止生成」**。如果发现方向不对、或者答案已经够了，点它就能中断——**已经写出来的部分会保留下来**，你可以接着补充或换个问法。回复正常写完后，按钮会自动变回发送状态。

## 对话工具条

对话界面顶部有一排按钮，常用的如下：

| 按钮 | 作用 |
|------|------|
| 「文件管理」 | 打开文件面板，查看这段对话里用到和生成的文件 |
| 「压缩上下文」 | 对话很长时，让系统把早前的内容整理收拢，好继续流畅作答 |
| 「收藏」 | 把这个 Agent 收藏起来，方便下次快速找到 |
| 「全屏沉浸模式」 | 隐藏其他区域、放大对话区，专注聊天（按 Esc 退出）|
| 「清空对话并重建 Agent」 | 清空当前对话、让 Agent 从干净状态重新开始 |

::: warning 「清空对话并重建」会清掉当前对话
点它之后这段会话的内容会被清空、Agent 回到初始状态。确实想重来再点；只是想换个话题的话，新建一段会话更稳妥。
:::

工具条上还有「动态配置」「技能蒸馏」等进阶功能，日常对话用不到，可以先不管。

## 上传和查看文件

对话时可以带上文件，让 Agent 结合文件内容来回答。

1. 点输入框旁的**附件按钮**（提示「Attach files (or paste screenshot)」）。
2. 选择要上传的图片、表格、文档等文件，也可以直接**粘贴截图**。
3. 连同你的问题一起发送即可。

点顶部「文件管理」可以打开文件面板，里面分「附件」和「工作空间」两部分：**附件**是你上传的文件，**工作空间**是 Agent 在处理过程中生成的文件。点目录树里的文件名就能预览。


## 管理多段会话

- **新建**：随时点「创建新会话」开一段新的，和旧会话互不影响。
- **切换**：点左栏任意一条会话即可切过去，消息记录都还在。
- **删除**：每条会话旁有「删除会话」按钮，不需要的可以删掉。

::: tip 会话怎么命名？
新会话默认用创建时间命名。列表按最近使用的顺序排在最上面，方便你找回刚聊过的那段。
:::

## 常见问题

**为什么回复是一个字一个字冒出来的？**
这是实时作答的正常表现，说明 Agent 正在边想边写，不是卡住了。等它写完，按钮会自动恢复。

**为什么按 Enter 没发出去？**
Enter 在这里是换行。发送请用 **Shift + Enter** 或点发送按钮。

**关掉页面或切走了，正在生成的回复会丢吗？**
不会。回来重新打开这段会话，还能看到它继续或已经写完的内容。

**同一个 Agent 开好几段会话，它们会互相串吗？**
不会。每段会话的上下文相互独立，你可以放心地一段聊正事、一段做试验。

**上传的文件安全吗？会被别人看到吗？**
会话是你的个人资源，只有你自己（和管理员）能看到你的会话和其中的文件。
