# 应用中心

应用中心让你把一个（或几个）Agent 包装成一个**可以分享的网页应用**：别人不用登录、不用懂技术，打开一个链接就能填个表单或聊两句，直接用上你的 Agent。这篇教你从零建一个应用、发布出去，并管好它的版本。

::: tip 开始之前
你需要至少有一个可用的 Agent。如果一个都还没有，先看[创建 Agent](./create-agent.md) 把它造出来；想快点走一遍，也可以直接用界面上现成的「General Assistant」这类通用助手。
:::

## 打开应用中心

点左侧边栏的「应用中心」进入。页面标题是「应用中心」，副标题写着「把 Agent 包装成可分享的 Web 应用」。右上角有一个蓝色的「+ 新建应用」按钮。

页面中间以卡片形式列出你已经建好的应用，每张卡片显示：

| 卡片上的信息 | 含义 |
|------|------|
| 图标 + 名称 | 应用的图标和名字 |
| 状态标签 | 草稿、就绪、已发布、已下线等当前状态 |
| 版本号（如 v4） | 当前对外服务的版本 |
| Agent 数、访问量 | 用了几个 Agent、被访问过多少次 |

把鼠标移到卡片底部，会出现一排图标按钮：**编辑**、**发布 / 下线**、**复制链接**、**打开应用**、**删除**。

![apps-list](/images/apps-list.png)

::: tip 还一个应用都没有？
页面会显示一个空状态提示，直接点中间的「+ 新建应用」开始建第一个。
:::

## 第一步：新建应用

点右上角「+ 新建应用」，弹出新建向导，一共三步。

### 选择创建方式

第一步先选一种创建方式：

| 方式 | 适合谁 | 大致过程 |
|------|--------|----------|
| **快速创建** | 大多数场景，想快点看到成品 | 选 Agent、填个名字和需求，几分钟内自动生成一个应用页面 |
| **完整创建** | 需求复杂、想更精细地打磨 | 用一段话描述需求，系统在后台分阶段完整搭建，耗时较长 |

选好后点「下一步」。

### 选择 Agent

第二步挑选应用背后要用的 Agent——它才是真正干活的那个。

1. 列表里既有平台内置的**推荐 Agent**（带星标），也有你自己造的 Agent。
2. 用顶部搜索框可以按名字查找。
3. 点卡片即可选中，**最多选 5 个**；再点一次取消选中。
4. 快速创建至少要选 1 个；完整创建这一步可以先不选（系统会自动挑）。

选好点「下一步」。

### 填写信息 / 描述需求

最后一步根据你前面选的方式略有不同：

- **快速创建**：选一个图标、填应用名字（必填），再在需求框里用大白话描述你想要的场景和界面样子（比如"输入一段产品介绍，生成一张营销落地页"）。填完点「创建应用」。
- **完整创建**：填应用名字（可选）和详细的需求描述（必填），点「开始完整构建」。系统会在后台自动搭建，你会被带到「工坊」里看进度。


::: tip 快速创建和完整创建怎么选？
拿不准就选**快速创建**——它更快，而且建好后你随时能继续调整、重新生成。完整创建适合你已经想得很清楚、需求比较复杂的时候。
:::

## 第二步：生成应用页面（快速创建）

快速创建完，你会自动进入**应用详情页**。页面顶部有一条流程指示器：**需求 → 生成 → 就绪**。

1. 在「需求」这一步，需求框里已经带上了你刚才填的内容，可以再补充或修改。
2. 点「开始设计」，系统就开始自动工作：先理解需求，再生成整个应用页面，中途**不需要你确认**。
3. 生成过程中，界面只显示一个不断增长的字符计数（「已生成 N 字符」），你静静等它完成即可。
4. 生成成功后自动进入「就绪」状态，右侧会出现应用的实时预览。

![app-detail](/images/app-detail.png)

::: tip 生成要等多久？
快速创建的生成通常几分钟内完成。完整创建（以及后面讲的"按新需求重做"）要在后台跑完整套搭建流程，**约 20–40 分钟**，可以先去做别的，回来再看。
:::

::: warning 中途出错怎么办？
如果生成没成功，界面会弹出提示并退回「需求」这一步。检查一下需求描述是不是太笼统，补充清楚后再点「开始设计」重试即可。
:::

## 认识应用详情页

进入「就绪」状态后，详情页分成左右两栏。

**左栏——应用信息与设置：**

- 应用图标、名称、描述和当前状态。
- 关键属性：绑定的 Agent 数量、访问量、访问方式、有效期（发布后才显示）。
- 已发布时，这里会显示可复制的**公开链接**。
- 「涉及的 Agent」卡片：列出应用用到的每个 Agent，可以逐个编辑（见下一节）。
- 「版本与更新」折叠区：更新应用、查看和切换历史版本（见后文）。

**右栏——实时预览：**

- 顶部写着「实时预览」，可以在 **Desktop（桌面）** 和 **Mobile（手机）** 两种尺寸间切换，看应用在不同设备上的样子。
- 如果应用支持双语，右上角还有 **EN / 中** 语言切换。
- 预览区就是应用的真实界面，你可以直接在里面试着操作。


顶部工具条上还有「调用记录」「复制链接」「打开应用」以及「发布 / 下线」等按钮。

## 调整应用背后的 Agent

在左栏「涉及的 Agent」卡片里，每个 Agent 都有一个「编辑配置」按钮，点开可以做这些调整：

| 可调整项 | 说明 |
|------|------|
| **标签** | 给这个 Agent 在应用里起个业务名字（比如"文案助手"） |
| **基础 Agent** | 更换真正干活的 Agent。换的时候页面结构不变，只换执行体 |
| **运行模式** | 一般保持默认即可，不用动 |
| **能力** | 通过搜索 + 勾选，给这个 Agent 配上工具、技能、数据连接器 |
| **版本** | 如果这个 Agent 有多个版本，可以在这里切换 |

改完点「保存」。


::: warning 更换基础 Agent 要留意
换成另一个 Agent 后，它给出的结果格式**可能和原来对不上**，页面上会提示你核对一下。换完记得在右侧预览里试一次，确认应用还能正常出结果。
:::

::: tip 「API」按钮是给开发人员的
每个 Agent 卡片旁还有一个「API」按钮，那是留给技术同事在自己的程序里调用这个 Agent 用的。如果你不做开发，忽略它就好，不影响正常使用。
:::

## 第三步：发布应用

应用生成好、状态是「就绪」后，就可以发布让别人使用了。点顶部（或列表卡片上）的「发布」按钮，弹出发布设置窗口。

**设置有效期。** 从下拉里选应用链接的有效时长，比如 7 天、30 天、90 天，或（如果管理员允许）「无限期」。到期后链接会自动失效，访客看到的是过期提示页。

**选择访问方式。** 决定谁能打开你的应用：

| 方式 | 效果 |
|------|------|
| **公开** | 任何拿到链接的人都能直接使用，无需登录 |
| **密码保护** | 你设一个用户名和密码，访客要先输入才能进入 |
| **API Key** | 需要密钥才能访问，主要面向技术调用 |

设好后点「发布」。发布成功后，用顶部的「复制链接」拿到公开地址发给别人，或点「打开应用」自己先看看效果。

<!-- SCREENSHOT: apps-publish -->

::: warning 想立刻停止对外访问？
点「下线」即可，应用会**立即**停止对外服务，之前发出去的链接也打不开了。想重新对外，再走一次「发布」就行。
:::

## 别人怎么使用你的应用

把公开链接发给同事、客户或任何人，他们**不用登录、不用注册**，在浏览器里打开就能用：

1. 页面顶部是应用的图标和名字；支持双语的应用右上角有 **EN / 中** 切换。
2. 按页面提示填写表单，或像聊天一样输入内容。
3. 点提交 / 生成按钮，应用就会调用背后的 Agent，把结果直接显示在页面上。

<!-- SCREENSHOT: apps-public -->

::: tip 访客产生的用量算谁的？
访客免登录使用，所有用量都记在你（应用所有者）名下。为防止被滥用，平台对匿名访问做了限流，正常使用不受影响。
:::

## 更新应用与管理版本

应用发布后还想改？不用重建。在左栏点「版本与更新 vN」（vN 是当前版本号）展开版本面板。

### 用一句话更新应用

面板顶部可以**用大白话描述你想改什么**，系统会自动帮你改并生成一个新版本。有两种模式：

- **在当前版本上修改**（默认）：在现有页面基础上做小改动，适合微调。
- **按新需求重做**：按新描述把应用重新做一遍，改动大时用。

在输入框里填改动要求（例如"结果区增加一个导出按钮""把主题色换成暗色系"），点「AI 更新应用」。更新会在后台进行，完成后会多出一个新版本。

<!-- SCREENSHOT: apps-versions -->

### 查看和切换版本

面板下半部是**版本历史**，每一条显示版本号、这一版的来源和变更说明。你可以：

- 点**预览**图标，先看看某个历史版本长什么样（不影响当前对外的版本）。
- 点某个历史版本的「切换到此版本」，把它设为当前对外服务的版本——相当于**一键回滚**。老版本不会被删掉，随时能再切回来。
- 当前正在服务的版本会标着「当前」徽标。

::: tip 改坏了不怕
每次更新都会保留成一个独立版本，历史版本一直都在。万一新版本不满意，随时「切换到此版本」回到之前的任意一版。
:::

## 查看使用记录

想知道应用被怎么用的？点顶部的「调用记录」，打开使用记录窗口：

- 左栏是**访问列表**，一次访问就是某个人的一次完整使用，按时间倒序排列。
- 点某条访问，右栏会按时间线展开这次访问的**完整过程**——用户说了什么、Agent 做了什么、生成了什么，一目了然。

这对了解真实用户怎么用你的应用、排查问题很有帮助。

## 删除应用

不需要的应用可以删除：在应用中心列表页，点卡片底部的**删除**图标，确认后即可删除。

::: warning 删除不可恢复
删除会连同应用的所有版本一起清掉，无法找回。如果只是暂时不想对外，用「下线」而不是删除。
:::
