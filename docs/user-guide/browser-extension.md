# 浏览器扩展（Nexus Bridge · Browser 模式）

**Nexus Bridge** 面板提供两种连接模式：

| 模式 | 标签 | 用途 |
| --- | --- | --- |
| **远程服务器（Remote Server）** | 「远程服务器」 | 让 Agent 在你的服务器上执行命令、读写文件（见[连接服务器执行任务](./bridge-server.md)） |
| **浏览器（Browser）** | 「Browser」 | 让 Agent 直接在你的 Chrome 浏览器里操作网页（本篇） |

本篇介绍 **Browser 模式**——浏览器扩展让 Nexus 助手可以**直接在你的 Chrome 浏览器里帮你做事**：打开网页、读取页面内容、点击按钮、填写表单。你在对话里说清楚要做什么，助手就会在一个专门的浏览器标签里一步步操作，遇到需要你亲自处理的环节（比如验证码、登录）会停下来问你。

装好并连接扩展后，你随时可以在设置里查看有哪些浏览器连着你的账号，并在不想用时把它们断开。

::: tip 什么时候用得上
适合"帮我在这个网站上把这批表单填了""打开这几个页面对比价格""到后台把今天的订单导出来"这类需要真人在浏览器里点点点的重复活儿。
:::

## 扩展能帮你做什么

- 打开你指定的网页
- 读取当前页面上有哪些按钮、链接、输入框
- 帮你点击、输入、提交
- 同时开多个标签页，跨页面对比或批量处理
- 碰到验证码、二次验证、登录墙时，停下来交给你手动完成，你处理完回一句它就继续

## 开始之前

你需要：

1. 一台装了 **Chrome 浏览器**的电脑
2. 已经能正常登录 Nexus（用你平时的账号）
3. 安装好 Nexus 的 Chrome 浏览器扩展（如果还没有，向你的管理员索取安装包或安装指引）

## 连接扩展

扩展装好后，要把它和你的 Nexus 账号连起来，助手才能用它。

1. 打开任意一个**对话页面**（左侧进入「对话」）。
2. 在对话页找到 **「Nexus Bridge」** 面板，点里面的 **「Browser」** 标签。
3. 按面板提示点击连接。连接成功后，扩展就会和你当前登录的账号绑定。

![chat](/images/chat.png)

::: tip 连不上怎么办
先确认 Chrome 里的 Nexus 扩展已启用，并且你在同一个浏览器里登录了 Nexus。仍连不上就刷新一下对话页再试。
:::

## 首次授权

第一次让助手在你的浏览器里执行操作时，浏览器可能会弹出一个**授权提示**，问你是否允许助手操作。点「允许」即可，助手才会继续。

::: warning 授权提示别放太久
授权提示大约一分钟内不点，这次操作就会超时失败。看到提示尽快确认，如果错过了，让助手再试一次即可。
:::

## 管理已连接的扩展

你可以在设置里看到哪些浏览器正连着你的账号，并随时断开。

1. 进入 **「设置」→「配置管理」**，点顶部的 **「浏览器扩展」** 快捷入口（也可以直接进「设置 · 浏览器扩展」页）。
2. 页面顶部显示 **「已连接的扩展 (N)」**，N 是当前连接数量。
3. 每个连接会列出它所在的浏览器信息和最近使用时间。

![settings-browser-extension](/images/settings-browser-extension.png)

页面上的几个操作：

| 操作 | 作用 |
| --- | --- |
| 「刷新」 | 重新拉取最新的连接状态 |
| 「显示已撤销」 | 勾选后连已经断开的历史连接也一并列出 |

::: tip 还没连过任何扩展
如果你从没连接过，这里会显示 **「尚无已连接的扩展」**，并提示你「在对话页 Nexus Bridge 面板中点 Browser 标签连接扩展」——按上面《连接扩展》一节操作即可。
:::

### 断开一个扩展

不想再让某个浏览器操作你的账号时，把它断开：

1. 在列表里找到那个连接。
2. 点它的「撤销」操作。
3. 断开后，这个浏览器上正在进行的浏览器任务会立即停止，助手也不能再用它操作。

### 恢复一个断开的扩展

1. 勾选 **「显示已撤销」**，让已断开的连接显示出来。
2. 找到要恢复的连接，点「恢复」。
3. **恢复后不会自动重连**——你需要按《连接扩展》一节，重新在对话页的 Nexus Bridge 面板里连一次。

## 让助手在浏览器里帮你做事

连接好之后，回到对话里直接用大白话安排任务，比如：

> 帮我打开公司后台的订单页面，把今天的订单筛出来。

助手会在一个专门的**浏览器标签**里操作，你能看到它一步步在做什么。

::: tip 需要跨多个页面
你可以让助手同时开几个标签页（比如一边留着搜索结果、一边逐条打开详情）。每个浏览器任务能开的标签数量有上限，见下方《使用限制》。
:::

## 遇到验证码或登录

助手不会替你解验证码，也不会替你输账号密码。碰到这类情况时：

1. 助手会**停下来**，在对话里告诉你需要你做什么（例如"请在浏览器里完成验证码"）。
2. 你切到那个浏览器标签，手动完成验证 / 登录。
3. 回到对话里回一句"好了 / 继续"，助手就接着往下做。

::: tip 人不在也不占用
助手停下来等你的时候不会一直占用资源。你什么时候回来回复，它什么时候接着继续。
:::

## 使用限制

为避免占用过多资源，浏览器操作有两个上限（具体数值由管理员配置，下面是默认值）：

| 限制 | 默认值 | 说明 |
| --- | --- | --- |
| 同时进行的浏览器任务 | 5 个 | 超过后需要先结束一个才能开新的 |
| 每个任务的标签页 | 10 个 | 达上限后让助手先关掉用完的标签，再开新的 |

## 常见问题

::: tip 扩展会看到我别的网页吗
助手只在它自己打开的浏览器标签里操作，够不到你其他窗口或标签里的内容。
:::

::: warning 连接会过期
连接有有效期，过期后助手就用不了它了。如果发现助手连不上浏览器，回对话页的 Nexus Bridge 面板重新连一次即可。
:::

::: tip 用完记得断开
在公用电脑上用完，或不再需要时，到「设置 · 浏览器扩展」把连接撤销掉，更放心。
:::
