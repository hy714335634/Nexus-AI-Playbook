# Agent 管理

创建好的 Agent 都会集中放在 **Agents 列表页**。这里是你日常查找、整理、使用和维护 Agent 的地方——找到某个 Agent、看看它的运行情况、和它对话、分享给同事，或者不再需要时删掉它，都从这个页面开始。

::: tip 谁适合看这篇
市场、运营、分析、客服等业务同学。你只需要会用浏览器点界面，不需要任何技术背景。
:::

## 打开 Agent 列表

点击左侧菜单里的「Agents」，就进入列表页。

页面顶部会显示标题「Agents」和副标题「管理和监控您的智能 Agent」。右上角是几个常用按钮：「交互网络」「导入 Agent」，以及蓝色的「+ 创建 Agent」（创建流程详见[创建 Agent](./create-agent.md)）。

![agents-list](/images/agents-list.png)

## 看懂列表页

进入列表页后，从上到下你会看到三块内容。

**顶部统计条**——一眼掌握全局：

| 统计项 | 含义 |
| --- | --- |
| Agent | 你一共有多少个 Agent |
| 运行中 | 当前可以正常使用的 Agent 数量 |
| 总调用 | 所有 Agent 被使用过的总次数 |
| 近 7 天活跃 | 最近一周内被用过的 Agent 数量 |

**Agent 卡片**——每个 Agent 一张卡片，上面写着：

- 名称
- 状态标签（如「运行中」）和版本号
- 一句话描述
- 「本地」或「生成」等来源标签
- 它会用到的工具标签（想给 Agent 添加更多工具？见[为 Agent 添加工具](./extend-agent-with-tools.md)）
- 被调用的次数和最近使用时间

## 查找、筛选和排序

Agent 多了以后，用列表中间的这排工具快速定位你要的那一个。

1. **搜索**：在「搜索 Agent 名称...」框里输入名字的任意片段，列表会实时缩小范围。
2. **排序**：点「名称」下拉框，可以改成按「调用量」「最近活跃」或「创建时间」排列。
3. **按状态筛选**：点「运行中」「离线」或「异常」，只看某种状态的 Agent；点「全部」取消。
4. **按类型筛选**：点「本地」或「云端」，按 Agent 的部署位置筛选。
5. **按分类筛选**：点「分类」按钮展开标签面板，勾选一个或多个标签，只看带这些标签的 Agent。
6. **清除**：设置了任何筛选条件后，右侧会出现「清除」，一键回到完整列表。

::: tip 找不到刚创建的 Agent？
新 Agent 需要先构建完成才会出现在列表里，且状态为「运行中」。如果它还在构建，可以到[构建进度](./build-progress.md)页面查看进度。
:::

## 打开一个 Agent 查看详情

点击任意一张 Agent 卡片，进入它的详情页。详情页顶部有几个标签页，可以切换查看不同内容：

- **概览**：这个 Agent 的描述、版本信息，以及被调用次数、用量等统计数据。
- **对话**：直接在这里和该 Agent 对话，随时试试它的效果（对话功能详见[与 Agent 对话](./chat.md)）。
- **文件**：查看这个 Agent 的相关文件。

详情页还提供**导出**功能，可以把整个 Agent 打包下载，方便备份或分享。


## 对 Agent 的更多操作

在列表页，**在一张卡片上点右键**（手机或触摸屏则是**长按**卡片），会弹出一个操作菜单：

| 菜单项 | 作用 |
| --- | --- |
| 查看详情 | 打开这个 Agent 的详情页 |
| 编辑 | 打开详情页，修改它的信息 |
| 分享 | 把这个 Agent 分享给同事一起使用 |
| 创建应用 | 以这个 Agent 为基础，快速创建一个应用（详见[发布你的第一个应用](./publish-first-app.md)） |
| 移动到文件夹 | 把它归类到某个文件夹里，方便整理 |
| 删除 | 删除这个 Agent（见下方[删除 Agent](#删除-agent)） |

### 分享给同事

点菜单里的「分享」，会弹出分享设置窗口。在这里选择要分享给谁、给多大权限，确认后对方就能看到并使用这个 Agent。

### 移动到文件夹

Agent 越来越多时，可以用文件夹分门别类。点菜单里的「移动到文件夹」，选择目标文件夹即可。

## 导入 Agent

如果你有别人导出的 Agent 文件，可以直接导进来使用。

1. 在列表页右上角点「导入 Agent」。
2. 在弹出的窗口里选择要导入的 Agent 文件。
3. 按提示确认，导入完成后它就会出现在你的列表里。

## 删除 Agent

不再需要某个 Agent 时，可以把它删掉。

1. 在卡片上点右键（或长按），选「删除」。
2. 弹出确认窗口，会告诉你删除后会清除哪些内容（该 Agent 的记录、历史对话等相关数据）。
3. 窗口里有可勾选的额外选项：
   - **删除本地文件**：连同这个 Agent 的相关文件一起清除。
   - **删除云端资源**：仅对「云端」类型的 Agent 显示，勾选后会一并清理它在云端占用的资源。
4. 确认无误后点「确认删除」。想反悔就点「取消」。

::: warning 删除无法撤销
删除后这个 Agent 和相关数据就找不回来了。删之前请确认你不再需要它。如果只是暂时不用，可以留着不管——闲置的 Agent 不会产生额外操作。
:::

## 交互网络

想直观地看看你的这些 Agent 和它们用到的工具之间是什么关系，可以用交互网络。

1. 在列表页右上角点「交互网络」。
2. 页面会用一张关系图，展示各个 Agent、版本和工具之间的调用与依赖关系。
3. 上方的筛选栏可以按分类、标签、工具类型过滤，也能勾选是否「显示工具」「显示版本」。
4. 点图上的任意节点，右侧面板会显示它的详情。

![agents-network](/images/agents-network.png)

::: tip 图上是空的？
如果你的 Agent 之间还没有互相调用的关系，网络图会显示为空。这属于正常情况，随着使用增多，关系会逐渐出现。
:::

## 常见问题

::: tip 「运行中」「离线」「异常」分别是什么意思？
「运行中」表示这个 Agent 一切正常，可以直接使用；「离线」表示它当前不可用；「异常」表示它出了点问题。看到「异常」时，可以打开详情页了解情况，或重新构建一次。
:::

::: tip 分享出去的 Agent，对方能改动吗？
取决于你分享时给的权限。分享窗口里可以设置对方是只能查看使用，还是能进一步编辑。
:::

::: warning 删错了能恢复吗？
不能。删除是永久性的，且相关数据会一并清除。重要的 Agent 建议删除前先用详情页的「导出」功能做个备份。
:::
