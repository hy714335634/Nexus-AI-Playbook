# 构建进度

当你[提交一个创建需求](./create-agent.md)后，系统会在后台一步步把它做出来。构建进度页就是你观看这个过程的地方——你可以在这里看到项目走到了哪一步、每一步花了多久，以及构建是否顺利完成。如果你还没有创建过 Agent，建议先阅读[快速上手](./quickstart.md)了解整体流程。

![project-detail-stages](/images/project-detail-stages.png)

## 如何打开构建进度页

有三种方式进入某个项目的构建进度页：

1. **刚提交完需求时**：点击「构建」后，系统会**自动跳转**到该项目的构建进度页，你无需做任何操作。
2. **从工作台进入**：在工作台的「构建进度」区域，点击任意一个项目卡片。
3. **从项目列表进入**：打开项目列表页，点击你想查看的项目。

::: tip 页面刚打开时是空白的？
项目页面需要几秒钟加载。如果一打开看到的是空白或加载动画，请稍等片刻，页面会自动显示完整内容。
:::

## 页面顶部：项目名称与操作按钮

页面最上方显示这个项目的名称（例如「中英互译助手」），右侧有几个操作按钮：

| 按钮 | 作用 |
| --- | --- |
| 返回 | 回到上一个页面 |
| 暂停 | 暂时停下正在进行的构建 |
| 删除 | 删除这个项目（红色按钮，请谨慎使用） |

## 关键数据一览

项目名称下方有四张数据卡片，帮助你快速了解这次构建的整体情况：

| 卡片 | 含义 |
| --- | --- |
| 总耗时 | 从开始到现在一共花了多长时间 |
| 输入 Tokens | 系统在过程中读入的文字量 |
| 输出 Tokens | 系统在过程中生成的文字量 |
| 工具调用 | 过程中调用外部能力的次数 |

::: info
「输入 Tokens」和「输出 Tokens」是衡量文字处理量的单位，数字越大表示处理的内容越多。你无需关注具体数值，它们只是帮助你了解这次构建的规模。
:::

## 看懂构建阶段时间轴

页面主体是一条**自上而下的阶段时间轴**，把整个构建过程拆成若干步骤依次呈现。系统会从第一步做到最后一步，你可以实时看到当前进行到哪里。

每个阶段卡片上都会显示：

- 阶段序号和名称（例如「意图识别」「需求深度分析」「系统架构设计」）
- 当前状态标签
- 这一步花了多久
- 这一步处理的文字量

阶段状态一共有四种，含义如下：

| 状态 | 含义 |
| --- | --- |
| 已完成 | 这一步已经顺利做完 |
| 运行中 | 系统正在做这一步 |
| 等待中 | 这一步还没轮到，正在排队 |
| 失败 | 这一步没能完成（见下方「如果某个阶段失败了」） |

::: info
不同类型的项目步骤数量和名称各不相同。比如构建一个 Agent 会经过意图识别、需求分析、架构设计等多个步骤，而构建一个工具则是另一套步骤。你不需要记住每一步的名字，只要顺着时间轴看它们逐个变成「已完成」即可。
:::

## 构建要等多久？

::: tip
一次完整构建通常需要约 20–40 分钟。你不需要一直守在页面前——可以先去做别的事，稍后回来查看结果。整个过程在后台自动进行，即使你关掉页面，构建也会继续。
:::

## 暂停与恢复构建

如果你想临时停下构建：

1. 点击页面右上角的「暂停」按钮。
2. 当前正在进行的步骤会停下来，项目状态变为「已暂停」。
3. 想继续时，回到这个页面即可恢复构建。恢复后，系统会从停下的地方接着做，**已完成的步骤不会重来**。

## 如果某个阶段失败了

万一某一步没能完成，那一步的状态标签会变成「失败」，项目顶部也会提示失败信息。

1. 阅读页面上的失败提示，了解大致原因。
2. 你可以让系统**从失败的那一步重新开始**，前面已经完成的步骤会被保留，不用从头再来。
3. 如果多次尝试仍然失败，请检查你最初填写的需求描述是否清晰完整，必要时重新创建一个项目。

::: warning
「删除」按钮会永久移除这个项目及其构建记录，删除后无法恢复。只有在确认不再需要这个项目时才使用它。
:::

## 常见问题

**构建过程中可以关掉页面吗？**
可以。构建在后台自动进行，关掉页面或退出登录都不会中断它。稍后重新打开这个项目即可继续查看进度。

**为什么时间轴上有的步骤一直显示「等待中」？**
系统一次只做一步，后面的步骤会排队等待。等前面的步骤完成后，它们会自动开始。

**构建完成后去哪里查看成果？**
当所有步骤都变成「已完成」、项目状态显示为「已完成」后，你就可以在对应的列表页（如 Agent 列表）找到并使用刚刚构建好的成果了。关于如何管理已构建的 Agent，请参阅[管理 Agent](./manage-agents.md)。
