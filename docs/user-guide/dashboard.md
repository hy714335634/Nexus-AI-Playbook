# 工作台

工作台是你登录后看到的第一个页面，也是你日常使用 Nexus AI 的起点。在这里，你可以一句话创建新的 Agent、查看正在进行的构建任务、快速打开常用功能，并一眼掌握平台的整体运行情况。

![dashboard](/images/dashboard.png)

## 如何打开工作台

1. 登录成功后，系统会**自动跳转**到工作台，你无需做任何操作。
2. 如果你在其他页面，点击左侧边栏最上方的「工作台」，随时可以回到这里。

::: tip
左侧边栏可以收起。点击边栏顶部的收起按钮，边栏会缩成一列小图标，给主内容区留出更多空间；再次点击即可展开。
:::

## 页面区域一览

工作台从上到下分为几个区域，各自的作用如下：

| 区域 | 作用 |
| --- | --- |
| 顶部快速构建区 | 用一句话描述需求，直接创建一个新的 Agent |
| 数据卡片 | 一眼看到运行中的 Agent、构建中的项目、今日使用次数、构建成功率 |
| 构建进度 | 查看最近创建的项目及其完成状态 |
| 快速操作 | 一键跳转到「创建 Agent」和「能力工具库」 |
| 运行中 Agent | 查看当前可用的 Agent 及各自被使用的次数 |

## 关键数据一览

页面上方有四张数据卡片，帮助你快速了解平台现状：

| 卡片 | 含义 |
| --- | --- |
| 运行中 Agent | 当前正在运行的 Agent 数量（以及 Agent 总数） |
| 构建中项目 | 正在构建、尚未完成的项目数量（以及项目总数） |
| 今日使用次数 | 今天 Agent 被使用的总次数 |
| 构建成功率 | 构建任务成功完成的比例 |

::: info
这些数字是实时更新的。如果暂时看到的是灰色占位方块，说明数据还在加载，稍等片刻即可显示。
:::

## 用一句话创建你的第一个 Agent

工作台顶部的彩色卡片是最常用的功能——你只要用日常语言描述想做什么，系统就会帮你把它变成一个 Agent。

1. 在标题为「从想法到 Agent 自动化构建」的卡片中，找到中间的输入框。
2. 在输入框里**用一句话描述你的需求**，例如：「帮我创建一个能够分析股票数据的智能助手」。
3. 输入内容后，右侧的「构建」按钮会自动变亮。点击「构建」。
4. 页面会自动跳转到该项目的详情页，你可以在那里查看构建进度。

如果一时想不到怎么描述，可以点击输入框下方的快捷示例，系统会帮你把示例文字填进输入框，你再按需修改：

- 「医学文献」
- 「AWS 报价」
- 「新闻简报」

::: tip 构建要等多久？
创建后系统会在后台自动完成一系列工作，通常需要约 20–40 分钟。你可以先去做别的事，稍后回到「构建进度」区域查看结果。
:::

::: warning
如果构建没能启动，卡片下方会出现一条红色提示，说明失败原因。请检查描述是否填写完整，然后重新点击「构建」。
:::

## 查看构建进度

「构建进度」区域列出你最近创建的项目，方便你随时了解进展。

1. 找到标题为「构建进度」的区块。
2. 列表中每一项都会显示：项目名称、当前所处的阶段、更新时间，以及右侧的状态标签和进度条。
3. 点击任意一项，即可进入该项目的详情页查看完整信息。
4. 想看全部项目？点击区块右上角的「查看全部」。

::: info
如果这里显示「暂无项目」，说明你还没有创建过任何项目。点击提示中的链接即可创建你的第一个 Agent。
:::

## 快速操作

「快速操作」区域提供两个常用入口，点一下即可跳转：

| 入口 | 作用 |
| --- | --- |
| 创建 Agent | 用自然语言描述业务需求，创建新的 Agent |
| 能力工具库 | 浏览和管理平台可用的各种能力 |

## 运行中的 Agent

「运行中 Agent」区域展示当前可用的 Agent，以及每个 Agent 已被使用的次数。

1. 找到标题为「运行中 Agent」的区块。
2. 列表中每一项显示 Agent 名称和使用次数；名称前的小圆点为绿色并闪动时，表示该 Agent 正在运行。
3. 点击任意一个 Agent，进入它的详情页。
4. 想查看全部 Agent？点击区块右上角的「全部」。

## 顶部操作栏

页面最上方的操作栏还提供了几个常用按钮：

- **搜索框**：点击后可以搜索或直接提问（也可以随时按快捷键唤起）。
- **「创建 Agent」按钮**：蓝色高亮，点击后进入创建 Agent 页面。
- **通知按钮**：查看系统提醒。
- **头像**：点击展开你的账户菜单。

::: tip
「创建 Agent」在页面上会出现在多个位置（顶部操作栏、快速构建区、快速操作区）。它们的作用相同，点哪个都可以，方便你随手创建。
:::
