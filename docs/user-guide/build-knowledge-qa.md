# 构建知识问答 Agent

有一堆资料——产品手册、规章制度、常见问题、培训文档——同事一遍遍来问里面的内容？这篇教你做一个**知识问答 Agent**：把资料交给它，它就照着资料回答问题，不用你再一条条翻、一遍遍解释。全程用日常语言描述，不写任何代码。

::: tip 谁适合看这篇
市场、运营、客服、HR、行政等业务同学。你只需要会用浏览器点界面，会把资料整理成文件，就够了。
:::

::: tip 开始之前
建议先看过[创建 Agent](./create-agent.md)和[对话](./chat.md)，了解怎么造一个 Agent、怎么和它聊天。这篇会把这两件事串起来，专门做一个"照着资料答题"的助手。
:::

## 什么是知识问答 Agent

普通的通用助手，回答问题靠的是它自己"学过"的通用知识，遇到你公司内部的东西（比如"我们的退货政策是几天"）它并不知道。

**知识问答 Agent** 不一样：你先把相关资料喂给它，它回答时**优先照着你给的资料来**。这样它就能准确回答那些只有你们内部才知道的问题，而不是自己瞎编。

举几个常见的用法：

| 想解决的问题 | 你交给它的资料 |
| --- | --- |
| 客服反复被问同样的问题 | 产品说明、常见问题清单 |
| 新同事总来问流程怎么走 | 员工手册、操作规范 |
| 政策条款太多记不住 | 制度文件、合同模板 |
| 一份长报告想快速问细节 | 报告、数据说明文档 |

### 真实场景：内部制度自助问答

假设你是 HR，公司有 200 页内部制度文档，每季度会修订一次。以前同事有任何制度相关的问题——年假怎么算、报销流程、调岗规定——全都跑来问你，一天能回几十条。

现在你可以这样做：

1. 把制度文档上传，构建一个知识问答 Agent。
2. 把它[发布成应用](./publish-first-app.md)，链接发到全员群里。
3. 500 个同事随时打开链接就能自助查制度细节，7x24 小时不用等你回复。
4. 下个季度制度更新了？把新文件通过"更新"交给它，它马上就能回答最新版的问题。

这就是知识问答 Agent 最适合的场景：**资料有定期变动 + 多人需要反复查同样的内容**。你维护一个 Agent，省下整个团队重复沟通的时间。

## 全流程一览

| 步骤 | 你要做的事 | 大概耗时 |
| --- | --- | --- |
| 1. 准备资料 | 把要让它"看懂"的内容整理成文件 | 看你资料多少 |
| 2. 创建 Agent | 描述需求，并把资料一起交上去 | 几分钟 |
| 3. 等它构建 | 系统自动把 Agent 做出来 | 10–40 分钟 |
| 4. 试问几句 | 在对话里验证它答得准不准 | 几分钟 |
| 5. 调整完善 | 答不好就补资料、改要求 | 按需 |

## 第一步：准备好你的资料

先把你想让 Agent "看懂"的内容整理成文件。资料整理得越清楚，它答得越准。

- **支持常见格式**：文档、表格、图片等日常文件都可以。
- **一次最多 10 个文件**：内容多就挑最重要的，或把零散内容合并成几份。
- **内容要清楚**：标题分明、条目清晰的资料，效果比一大段密密麻麻的文字好。
- **只放该放的**：涉及机密或个人隐私的内容，先确认可以放进来再上传。

::: tip 没有现成文件也能开始
如果暂时没整理好文件，也可以先用文字把关键信息直接写进需求描述里（见下一步）。等以后资料齐了，再更新给它补上。
:::

## 第二步：创建 Agent 并交上资料

现在来造这个 Agent。关键有两点：**在需求里说清楚"照资料答题"**，以及**把资料作为附件一起交上去**。

1. 打开创建页面（侧边栏底部的「创建 Agent」按钮，或首页顶部的创建卡片，任选其一）。
2. 在需求框里描述你要的助手。把这几件事说清楚：它服务谁、回答哪方面的问题、答不出时怎么办。例如：

   > 创建一个客服知识助手：根据我上传的产品手册和常见问题文档回答客户提问。回答要简洁、口语化；如果资料里没有相关内容，就明确告诉用户"资料里没有找到"，不要自己猜。

3. 点需求框旁的「添加附件」（回形针图标），把[第一步](#第一步-准备好你的资料)整理好的资料选进来。
4. 上传后每个文件旁会显示"解析中 → 已解析"，**等全部显示"已解析"**再继续。
5. 点「构建」按钮，页面会跳转到构建进度页。

![quick-create](/images/quick-create.png)

::: warning 一定要等文件"已解析"
文件还在"解析中"时点构建，系统会提示你稍等。等所有文件都变成"已解析"再提交，Agent 才能真正读到里面的内容。如果某个文件显示"解析失败"，把它移除后换一个文件或重试。
:::

::: tip 需求里为什么要写"答不出就说没有"
这一句很关键。加上它，Agent 遇到资料里没写的问题时会老实说"没找到"，而不是编一个听起来像模像样、实际却是错的答案。对知识问答来说，"不知道"比"答错"更安全。
:::

## 第三步：等它构建完成

提交后进入**构建进度页**，你能实时看到系统正在做什么。每个阶段前的图标表示进度：✅ 已完成、🔄 进行中、⏳ 排队等待。

![project-detail-stages](/images/project-detail-stages.png)

::: tip 要等多久？
一般 10 到 40 分钟。这段时间你可以去忙别的——构建在后台进行，随时回到这个页面就能看到最新进度。构建完成后，这个 Agent 会出现在你的 Agents 列表里。
:::

关于构建进度页的更多细节，见[创建 Agent](./create-agent.md#看着-agent-构建完成)。

## 第四步：试着问它几句

构建完成后，就该验证它答得准不准了。

1. 点左侧边栏的「对话」，进入对话页。
2. 在左栏的「选择 Agent」下拉里，找到你刚做好的这个 Agent，点选它。
3. 点「创建新会话」开一段新对话。
4. 在底部输入框里问一个**资料里确实写了**的问题，按 **Shift + Enter** 发送。
5. 它会一段段实时回答。对照资料看看答得对不对。

![chat](/images/chat.png)

建议按下面几种情况都测一遍，心里更有底：

| 测试问题 | 期待的表现 |
| --- | --- |
| 资料里明确写了的 | 答得准确，和资料一致 |
| 资料里没写的 | 老实说"资料里没找到"，不瞎编 |
| 换个说法问同一件事 | 依然能答对，不因为措辞变了就答不上 |

::: tip 临时补充资料
如果聊天中想让它临时参考一份新文件，点输入框旁的**附件按钮**把文件传上去，连同问题一起发送即可。详见[对话](./chat.md#上传和查看文件)。这适合"就这一次"的场景；如果这份资料以后要长期用到，建议按[第五步](#第五步-答不好就这样调整)把它正式补进 Agent。
:::

## 第五步：答不好就这样调整

如果试问下来发现它答得不够好，不用推倒重来。对照下表找原因：

| 症状 | 多半是因为 | 怎么办 |
| --- | --- | --- |
| 某个问题答不上来 | 资料里根本没有这块内容 | 补一份包含该内容的资料 |
| 答案和资料对不上 | 资料太乱或有过时内容 | 整理资料、删掉旧版本，再更新给它 |
| 明明写了却答错 | 那段资料表述含糊 | 把该部分改写清楚，标题、条目分明 |
| 回答太啰嗦 / 太生硬 | 没说清楚语气要求 | 在更新要求里补一句，如"回答控制在三句话内、口语一点" |

调整的方式是**更新这个 Agent**：在它的详情页用一句话描述你想改什么（比如"再补充这份最新的价目表""回答时附上对应的条款编号"），系统会自动帮它更新。具体操作见[管理 Agent](./manage-agents.md)。

::: tip 资料更新了怎么办
资料有变动（比如政策改版、价目表更新）时，把新文件通过"更新"补给它、并让它以新资料为准即可。Agent 不会自动知道你线下改了文件，需要你把新版交给它。
:::

## 让更多人用上它（可选）

自己用顺手之后，你可以把这个知识问答 Agent 做成一个网页应用发布出去，让同事甚至客户打开链接就能问——不用登录、不用懂技术。做法见[发布第一个应用](./publish-first-app.md)。发布后在[应用中心](./app-center.md)管理它的版本和访问权限。

::: tip 资料源头很多、想自动同步？
如果你的资料存在 Confluence、飞书文档、Google Drive 等平台上，可以用[集成中心](./integration-center.md)连接数据源，省去手动上传的步骤。
:::

## 常见问题

**它会把我上传的资料泄露给别人吗？**
你的 Agent 和资料是你的个人资源，只有你（和管理员）能看到。只有当你主动把它[发布成应用](./publish-first-app.md)或[分享](./resource-groups-sharing.md)出去，别人才能使用。

**资料很多、一次传不完怎么办？**
一次最多 10 个文件。内容多时，先挑最常被问到的做第一版，其余的之后通过"更新"分批补进去。也可以把零散内容合并成几份更完整的文件。

**它有时还是会答错，正常吗？**
知识问答 Agent 优先照资料回答，但并非 100% 不出错。所以两件事很重要：一是在需求里让它"资料没写就说没找到"；二是重要结论自己再核对一下资料原文。

**我要手动告诉它用哪个"查资料"的工具吗？**
不用。你只要在需求里说清楚"根据我上传的资料回答"，平台会在构建时自动帮它配好需要的本领。想了解 Agent 的本领从哪来，可看[用工具扩展 Agent](./extend-agent-with-tools.md)。

**换个说法问，它就答不上来了？**
先确认资料里确实有这块内容。如果有却答不上，多半是那段资料表述太含糊——把它改写得更清楚，再更新给 Agent（见[第五步](#第五步-答不好就这样调整)）。
