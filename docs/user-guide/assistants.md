# 内置助手

Nexus 在多个页面内置了一批 AI 小助手，统称「Nexus 助手」。它们随页面待命，你用大白话提问或说出想做的事，它们就直接帮你查数据、给建议、生成内容——不用你懂任何技术、不用记参数名。

不同页面的助手擅长不同的事：

| 助手 | 出现在哪里 | 帮你做什么 |
|------|-----------|-----------|
| 运维助手 | 服务状态页 | 查各项服务运行是否正常、排查故障、生成排查报告 |
| 配置助手 | 配置管理页 | 用大白话找配置项、解释某项配置的作用与调整影响、给优化建议 |
| 审计助手 | 审计追踪页 | 查谁在什么时候改了什么、有无异常登录、生成合规报告 |
| 应用生成助手 | 应用中心「新建应用」 | 根据你的描述自动生成一个可发布的应用页面 |
| 任务发布助手 | 任务发布入口 | 把一句话目标变成可执行的任务方案 |

::: tip 都不用你动手写东西
所有内置助手都是「你说需求、它出结果」。你只管用自然语言描述，剩下的交给它。
:::

![settings-config](/images/settings-config.png)

## 助手长什么样、怎么打开

在支持助手的页面，右下角会有一颗会轻轻发光的**圆点**，这就是 Nexus 助手的入口。

- **打开**：点一下圆点，右侧弹出对话框。
- **移动**：按住圆点拖动，松手后它会自动吸附到屏幕最近的左边或右边。
- **固定成按钮**：在圆点上点右键，选择「固定为按钮」，它就变成页面上的常规按钮；再点右键选「变为浮动圆点」可以变回去。

对话框打开后你会看到：

1. 顶部一个「切换到居中大窗」按钮——屏幕小或内容多时，点它把对话框放到屏幕正中放大看。
2. 几个**推荐问题**按钮——不知道问什么时，直接点一个最省事。
3. 底部输入框——自己打字提问，输入内容后「发送」按钮才可点。

## 通用用法

无论哪个助手，用法都一样：

1. 点开右下角的助手圆点。
2. 点一个推荐问题，或在输入框里用大白话打出你的问题，点「发送」。
3. 助手的回答会一点点显示出来（它在后台边想边答，稍等片刻即可）。
4. 有些回答下方会带**可点击的按钮**（如「查看今日登录记录」），点它就能直接跳到对应页面或执行对应动作。

::: warning 回答基于当前页面的真实数据
助手只根据你当前查看的范围（如所选时间段、当前系统状态）作答，不会凭空编造。如果它说「当前范围内无相关记录」，多半是换个时间段或换个说法再问就好。
:::

## 运维助手

在**服务状态页**（管理员：服务状态）右下角打开，帮你了解系统各项服务是否运行正常、排查故障。

**它能帮你做**：

1. 点开助手，会看到几个常见问题，例如「worker 为什么没在消费消息？」「哪个服务最近在报错？」。
2. 也可以直接问「当前各服务运行状态如何？」。
3. 助手会返回一张**服务状态表**，逐项列出每个服务是否在运行、占用的资源等，一眼就能看出哪里不对。

![ops-helper](/images/ops-helper.png)

::: warning 重启服务要你亲自确认
如果你让助手重启某个服务，它不会直接动手，而是给你一个**待确认按钮**——你点确认后才真正重启。这是为了防止误操作。部分关键服务不支持通过助手重启，助手会礼貌说明原因。
:::

::: tip 排查报告可以下载
让助手「生成排查报告」，它会整理好一份完整报告，回答下方出现下载按钮，点一下就能存到本地。
:::

## 配置助手

在**配置管理页**（设置：配置管理），配置助手集成在页面上方的「想调什么，直接说」区域，也可以点右下角的助手圆点展开对话。

**它能帮你做**：

1. 在「想调什么，直接说」的输入框里，用大白话描述你的目标，比如「降低使用成本」「对话总丢上下文」「哪些改了要重启」（这几个也是现成的推荐按钮，点一下即可）。
2. 点「AI 搜索」，助手会帮你找出相关的配置项，并解释每一项是做什么的、当前值合不合适、改了会有什么影响。
3. 每个配置项旁边还有一个「问 AI：作用与调整影响」按钮，专门就这一项给你讲清楚。

![config-helper](/images/config-helper.png)

::: tip 搜不到就换个说法
如果提示「命中 0 个相关的参数」，说明没有匹配到——换个关键词或换种说法再问一次通常就有了。
:::

## 审计助手

在**审计追踪页**（设置：审计追踪）右下角打开，帮你快速看清「谁、在什么时候、做了什么」，以及有没有异常。

**它能帮你做**：

1. 点开助手，可以直接问「今天有哪些登录记录？」「这段时间谁改了配置？」「有没有失败登录或越权尝试？」。
2. 助手会给你一段**清晰的总结**：比如今天有多少条登录、都是谁、来自哪些来源，并主动提示有没有异常。
3. 总结下方常带一个按钮（如「查看今日登录记录」），点它直接跳到筛选好的记录列表。

面板上方还有三个快捷按钮，帮你一键完成常见工作：

- **区间总结**：对当前时间范围内的活动做一份简明总结。
- **生成合规报告**：生成一份正式的合规审计报告。
- **发送到 SNS**：把结果发送出去通知相关人。

![audit-helper](/images/audit-helper.png)

::: tip 结果跟着你选的时间范围走
这三个快捷动作都按你在页面上选的时间范围（近 7 天 / 30 天 / 90 天）来处理，先选好范围再点。
:::

## 应用生成助手

应用生成助手不是浮动圆点，而是**应用中心「新建应用」快速创建**背后的引擎。你描述想要什么样的应用，它就自动生成一个可发布的页面。

1. 在应用中心点「新建应用」，选择「快速创建」，点「下一步」。
2. 选一个要用的 Agent，点「下一步」。
3. 填「应用名称」，在「场景与 UI 需求」里用大白话描述这个应用给谁用、要哪些输入项、想要什么样的界面，点「新建应用」。
4. 点「开始设计」，页面会实时显示「正在自动生成应用 已生成 N 字」，稍等即可。
5. 生成完成后应用变成「就绪」，你能看到实时预览，之后就可以发布。

::: tip 大概要等几分钟
自动生成通常需要几分钟，期间可以先去做别的。完整的创建与发布步骤见「应用中心」章节。
:::

## 其他内置助手

还有几个助手在你完成特定操作时自动出手，你不必单独去找它们：

- **任务发布助手**：在任务发布入口，你说一句目标（如「每天帮我检查数据源有没有异常」），它会先用选择题跟你确认几个关键点，再帮你生成一份完整的任务方案供你确认。
- **工具审查助手**：当你上传脚本注册为工具时，它会自动帮你审查这些脚本、整理成一份工具清单和改进建议。
- **技能沉淀助手**：当你把一段对话沉淀为可复用技能时，它会自动帮你提炼出技能内容，供你确认后保存。

::: tip 方案和结果都要你确认才生效
这些助手给出的都是**草案**——任务方案、工具清单、技能内容都会先展示给你，你核对无误、点确认后才会真正创建或保存。放心大胆地让它先给建议。
:::
