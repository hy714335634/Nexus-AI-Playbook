# 事件任务

事件任务让你的 Agent **按计划自动干活**，不用你守在电脑前。你设定好"什么时候做、做什么"，到点它就自己跑起来，把结果整理好等你查看。

常见用法：

- 每天早上自动汇总昨天的数据，生成一份日报
- 每周一上午自动检查一次待办事项并提醒
- 让 Agent 持续盯着某个目标，自己一步步推进，直到完成

## 真实场景：自动生成云成本周报

想象一下：每周一早上 9 点，你的 Agent 自动登录到云成本控制台，拉取本周和上周的费用数据，对比变化，然后生成一份简洁的成本分析报告，放在你的工作区里等你查看。你只需要设置一次，之后它每周都会自动跑。

这个场景把三件事串在一起——按计划自动执行 + 连接远程服务器拉数据 + 生成报告——是只有这个平台能做到的组合。

**设置步骤：**

1. 先[创建一个能分析成本数据的 Agent](./create-agent.md)——用自然语言描述它的能力即可。
2. 如果 Agent 需要登录到远程服务器拉取数据，先在[服务器连接](./bridge-server.md)里设置好连接。
3. 在[对话](./chat.md)里和这个 Agent 聊一次，确认它能正确分析数据、输出你想要的报告格式。
4. 一切就绪后，回到这个页面，点「新建任务」，输入类似"每周一早上 9 点，连接成本控制台，对比本周和上周的费用，生成一份成本变化报告"。

设置完成。从此每周一你打开工作区，报告已经在那了。

::: tip 更多组合玩法
这个模式（定时 + 服务器连接 + 报告生成）在[编排方案](./orchestration-recipes.md)的方案 3 中有更详细的讲解。
:::

## 三种任务类型

| 类型 | 什么时候执行 | 适合场景 |
|------|------------|---------|
| **一次性任务** | 在你指定的某个时间点，只执行一次 | "下周三上午 10 点帮我生成一份季度报告" |
| **周期性任务** | 按固定节奏反复执行（每天、每周、每小时……） | "每天早上 8 点汇总一次销售数据" |
| **自主运行任务** | 持续运行，Agent 自己决定下一步做什么，直到目标达成 | "帮我持续跟进这个项目，有进展就整理出来" |

::: tip 不用记复杂的时间格式
你只需要用日常语言描述"什么时候做"，系统会自动理解并安排好节奏。
:::

## 打开任务面板

1. 在左侧导航点「任务面板」。
2. 页面标题显示"任务面板"，右上角有「新建任务」和「Refresh」（刷新）两个按钮。
3. 如果你还没建过任务，页面会显示空状态，提示你创建第一个任务。


## 新建任务

Nexus-AI 用**对话式**的方式帮你建任务——你只要描述目标，系统会帮你匹配合适的 Agent 并生成可执行的方案。

1. 点右上角「新建任务」。
2. 弹出"自然语言创建任务"对话框，上面写着"描述目标，助手帮你匹配资源并生成可执行方案"。
3. 在"任务目标"输入框里，用一两句话描述你想让系统持续或一次性完成的目标。**信息越具体，方案越准确**，例如：
   - "每天早上 9 点，帮我整理前一天的客服工单，生成一份摘要。"
   - "下周一上午 10 点，生成一份上个月的销售汇总。"
4. 描述好之后，点「开始分析」（没输入内容时这个按钮是灰的、点不了）。
5. 系统会分析你的描述，帮你挑选合适的 Agent、确认执行节奏并生成方案。按提示确认后，任务就建好了。


::: tip 建好之后会自动开始
任务建立后会按你设定的时间自动进入排队。到点前你什么都不用做，系统会在后台安排执行。
:::

## 查看任务和执行记录

任务面板支持三种查看方式，可以在页面上切换：

- **列表** —— 一行一个任务，信息一目了然
- **看板** —— 按状态分列，看整体进度很方便
- **时间线** —— 按时间顺序排列，适合回顾执行历史

每一次执行都会留下一条记录，状态含义如下：

| 状态 | 含义 |
|------|------|
| **等待中** | 已排好队，还没到执行时间 |
| **运行中** | 正在执行，请稍候 |
| **已完成** | 执行成功，可以查看结果 |
| **失败** | 执行没成功，可点开看原因 |
| **已跳过** | 本次没有执行（比如任务已被暂停） |

## 管理已有的任务

把鼠标移到某个任务上，会出现一排操作按钮：

- **暂停 / 启用** —— 暂停后任务不再自动执行；重新启用后恢复
- **立即执行** —— 不想等到下一个时间点，可以手动触发一次马上执行

  ::: warning 先启用再手动执行
  如果任务处于暂停状态，需要先重新启用，才能手动触发执行。
  :::
- **编辑** —— 修改执行时间、提示词、描述等设置
- **删除** —— 删除任务本身，同时清空它的所有执行记录（无法撤销，请谨慎操作）

::: tip 一次性任务跑完会自动暂停
一次性任务执行完成后会自动停用，不会重复触发，你不用手动关掉它。
:::

## 查看执行结果和生成的文件

1. 在任务面板里点开某一次执行记录。
2. 详情面板会显示这次执行的**结果摘要**、完整输出内容，以及执行过程中生成的所有文件。
3. 支持直接预览多种文件：文档、表格、图片、网页、演示文稿等，图片和图形还可以放大缩小查看。
4. 需要把结果发给别人时，可以对某个文件生成一个**分享链接**，对方点链接就能查看（分享链接会在一段时间后自动过期）。

::: tip 执行需要一点时间
Agent 执行任务可能需要几分钟到几十分钟，取决于任务复杂度。你可以先去做别的，稍后回来点「Refresh」刷新查看最新进度。
:::

## 关于自主运行任务

自主运行任务比较特别：它会持续运行，每一轮结束后自己规划下一步该做什么。

- 当系统判断**目标已经达成**时，任务会自动停下来。
- 如果你想让它接着做新的事情，可以在任务详情里给它下达**新的指令**，任务会重新启动并按新指令继续。
- 你也可以给自主任务设一个**最多执行次数**，达到上限后它会自动暂停，避免无限制运行。

## 常见问题

::: tip 任务到点了却没执行？
先检查任务是不是处于"暂停"状态——暂停的任务不会自动执行。确认已启用后，可以用「立即执行」手动触发一次试试。
:::

::: tip 我能看到别人建的任务吗？
默认只能看到自己创建的任务。如果别人把任务通过共享资源分享给你，你也能看到。管理员可以看到全部任务。
:::

::: warning 删除任务不可恢复
删除任务会连同它的全部执行记录一起清除，且无法找回。如果只是暂时不需要，建议用"暂停"而不是"删除"。
:::
