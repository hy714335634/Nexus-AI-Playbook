# 学习路径

用户手册一共有二十多篇文档。你不用一次读完——这一篇会把它们串成一条循序渐进的路线，告诉你**先学什么、再学什么**，每一步跳到哪篇文档去。

跟着走，你会从"第一次登录"一路到"为团队搭好一套能干活的 Agent"。全程不需要任何技术背景，看到操作照着点就行。

![dashboard](/images/dashboard.png)

## 先按你的目标选一条路

不想从头读？先看看你属于哪种情况，直接跳到对应阶段：

| 你想做的事 | 建议路线 |
| --- | --- |
| 只想快速试用，感受一下平台能干什么 | 阶段一 |
| 从零搭出一个自己能用的 Agent | 阶段一 → 阶段二 → 阶段三 |
| 让 Agent 接上公司的资料和系统、变得更能干 | 学完阶段三后，继续阶段四 |
| 让 Agent 定时自动跑、随身帮你干活 | 阶段五 |
| 给团队分配 Agent、共享成果 | 阶段六 |
| 跟着完整例子从头做一遍 | 直接看"动手教程" |

::: tip 建议
第一次用的话，按阶段顺序走最省事。每个阶段大约花几十分钟，学完就能上手做真事，不用担心"学了用不上"。
:::

## 阶段一 · 入门（约 30 分钟）

先把账号登进去，认识界面，再花五分钟做出第一个成果，建立信心。

| 顺序 | 文档 | 你会学到 |
| --- | --- | --- |
| 1 | [登录与界面导览](./first-login.md) | 怎么登录，各个区域分别是干什么的 |
| 2 | [5 分钟快速上手](./quickstart.md) | 用一句话描述需求，快速跑出第一个成果 |
| 3 | 学习路径（本页） | 规划接下来的学习顺序 |

## 阶段二 · 建立你的第一个 Agent

Agent 就是替你干活的"数字助手"。这一阶段带你从描述需求，到看着它一步步被造出来，再到和它对话。

| 顺序 | 文档 | 你会学到 |
| --- | --- | --- |
| 1 | [创建 Agent](./create-agent.md) | 用自然语言描述你想要什么，发起构建 |
| 2 | [构建进度](./build-progress.md) | 构建过程里会看到什么，大概要等多久 |
| 3 | [对话](./chat.md) | 和 Agent 聊天、上传文件、管理多轮对话 |

::: tip 构建要等多久？
从你描述需求到 Agent 建好，平均约 20–40 分钟。这段时间你可以先去忙别的，系统会在后台自动完成，好了再回来看。
:::

## 阶段三 · 管好你的 Agent 和成果

有了 Agent，接下来学会在哪儿找到它们、怎么归类整理、怎么把好用的 Agent 变成一个人人可用的应用。

| 顺序 | 文档 | 你会学到 |
| --- | --- | --- |
| 1 | [工作台](./dashboard.md) | 你的主页：一眼看到最近的动态和常用入口 |
| 2 | [工坊管理](./projects.md) | 把相关的工作归到一起，分门别类地管理 |
| 3 | [Agent 管理](./manage-agents.md) | 查看、启用、停用、调整你的 Agent |
| 4 | [应用中心](./app-center.md) | 把 Agent 变成一个开箱即用的应用，分享给别人 |

## 阶段四 · 让 Agent 更能干

给 Agent 加上"工具"和"技能"，再接上公司已有的系统，它就能查真实数据、办真实业务。

| 顺序 | 文档 | 你会学到 |
| --- | --- | --- |
| 1 | [工具库](./tools.md) | 给 Agent 装上能查资料、能算数的本领 |
| 2 | [技能系统](./skills.md) | 把一套做事方法教给 Agent，复用到不同场景 |
| 3 | [业务集成中心](./integration-center.md) | 把 Agent 接到你公司已有的业务系统上 |
| 4 | [连接服务器执行任务](./bridge-server.md) | 让 Agent 到你的服务器上运行命令、收集信息 |

## 阶段五 · 自动化与随身能力

让 Agent 不用你盯着也能干活：定时自动运行、随时召唤的小助手、装进浏览器随手可用。

| 顺序 | 文档 | 你会学到 |
| --- | --- | --- |
| 1 | [事件任务](./events.md) | 让 Agent 按时间自动跑，比如每天早上出一份报告 |
| 2 | [内置助手](./assistants.md) | 界面里随身的 AI，帮你查数、答疑、指路 |
| 3 | [Spotlight 命令面板](./spotlight.md) | 一个快捷入口，快速找到任何功能或内容 |
| 4 | [浏览器扩展](./browser-extension.md) | 在任意网页上随手调用你的 Agent |
| 5 | [Avatar 空间](./avatar-space.md) | 你的"数字之家"：帮你整理信息、沉淀记忆、主动提醒 |

## 阶段六 · 团队协作与共享
