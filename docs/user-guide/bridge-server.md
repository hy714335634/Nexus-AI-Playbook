# 连接服务器执行任务（Nexus Bridge）

有些任务光在对话里回答不够，需要 AI **真的到你的服务器上去操作**——跑一套检查、收集日志、装个环境、执行一段流程。**Nexus Bridge** 就是干这个的：它在你和目标服务器之间架一座桥，让对话里的 Agent 能在你授权的服务器上执行命令、读写文件、生成结果。

::: warning 只操作你授权的服务器
Bridge 会让 Agent 在目标服务器上执行真实命令。**只连接你本人拥有或已获书面授权的服务器**，并善用下面的「命令规则」限制可执行范围。用最小权限的账号来连接。
:::

## 它是怎么工作的（一句话）

你在平台点一下生成一条命令，**复制到目标服务器的终端里粘贴运行**，服务器就会主动"连回"平台。之后对话里的 Agent 就能在这台服务器上干活了。

关键点：**始终是服务器主动连回平台**，不是平台去连服务器。所以哪怕你的服务器在**内网、防火墙或 NAT 后面**，只要它能访问外网，就能连上——你不用开放任何入站端口，也不用在平台里填服务器的 IP、账号或密码。

## 建立连接：三步

1. **打开 Bridge 面板**。进入[对话](./chat.md)页，点顶部的 **「Nexus Bridge」** 按钮，切到 **「远程服务器」** 标签。
   ![chat](/images/chat.png)
2. **生成连接指令**。（可选）选连接方式：
   - **HTTPS**（默认，推荐）——兼容 CDN、企业代理，通用性最好。拿不准就用它。
   - **WebSocket**——需要服务器能与平台直连，适合要低延迟长连接的场景。

   点 **「Generate Bridge Command（生成 Bridge 指令）」**，平台生成一条形如 `curl ... | python3 -` 的命令。
3. **在服务器终端粘贴运行**。把命令复制到**目标服务器的终端**里执行。它会下载一个零依赖的小脚本（只用 Python 标准库）并运行，终端显示"连接成功"后，平台面板会自动变成"已连接"。**保持这个终端开着**（`Ctrl+C` 断开）。

::: tip 需要准备什么
目标服务器上有 `python3`、能访问外网即可。不需要 SSH、不需要在平台填任何服务器凭证——身份用的是平台签发的一次性令牌（默认约 10 分钟内有效、用一次即失效）。
:::

一个会话最多可连 **5 台**服务器，面板上「Add Server」逐台添加。

::: tip 想让连接断了自动恢复
在面板「高级设置」里打开 **自动重连**。服务器重启或网络抖动后，脚本会自动连回，不用你重新生成指令。
:::

## 让 Agent 在服务器上干活

连接建立后，平台会**自动**给当前对话的 Agent 装上远程操作能力，并把服务器的基本信息（系统、用户、目录等）告诉它。你不用做额外配置，直接在对话里下指令即可，例如：

- "在服务器上看看磁盘占用和最近的错误日志，总结一下"
- "按这个清单在测试机上装好环境，装完告诉我版本"
- "对我授权的这个 Web 应用做一轮标准安全检查，把结果整理成报告"

Agent 会分步执行：每一步在服务器上跑对应命令，过程你都看得见，可以随时[停止](./chat.md#停止生成)。耗时长的操作它会转成后台任务、定时回来看进度。做完让它把结果整理成报告存进[工作空间](./chat.md)，你下载即可。

## 划定 Agent 能做什么：命令规则

这是安全的关键。在 Bridge 面板「高级设置 → 命令规则」里，你可以限制 Agent 在服务器上能执行哪些命令：

| 模式 | 效果 | 适用 |
|------|------|------|
| **不限制**（默认） | 放行所有命令 | 完全信任、隔离的测试环境 |
| **白名单** | 只有匹配你列出的命令才放行 | 只想让它做特定几类操作时最安全 |
| **黑名单** | 挡掉你列出的命令，其余放行 | 想禁掉危险操作、其余放开 |

还有两个一键预设：
- **只读命令**：只放行 `ls`/`cat`/`grep`/`ps`/`df`/`systemctl status` 等查看类命令——想让 Agent"只看不动"时用它。
- **屏蔽危险命令**：挡掉 `rm -rf`、格式化磁盘、关机重启、`chmod 777` 等破坏性操作。

被规则挡下的命令会执行失败，Agent 会告诉你"该命令被规则限制"，你可回面板调整。

::: warning 命令规则不是操作系统级沙箱
命令规则是一层软性防护，能挡住绝大多数误操作和明显危险命令，但**不能替代服务器本身的权限控制**。真正的安全底线是：**用一个最小权限的系统账号去运行连接命令**——Agent 拿到的权限，就是那个账号的权限。
:::

## 常见问题

**连接一直没成功？** 确认那条命令是在**目标服务器**的终端里运行的、服务器能访问外网、`python3` 可用；令牌有时效（约 10 分钟），太久没执行就重新生成一条。

**关掉终端会怎样？** 连接会断开。想长期保持，运行前在面板打开「自动重连」，并让终端在后台持续运行（如用 `nohup`、`tmux` 或 `screen`）。

**Agent 说命令被限制了？** 说明命中了你设的命令规则。去 Bridge 面板「高级设置 → 命令规则」放宽对应规则，或换个符合规则的做法。
