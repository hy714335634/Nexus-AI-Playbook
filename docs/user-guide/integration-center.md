# 业务集成中心

业务集成中心是你给 Agent 准备"外部支援"的地方。你的 Agent 光有本事还不够，很多时候还需要：一份现成的 PPT/Word 模板去套、一批公司里的业务数据去读、一个访问口令去登录第三方服务、以及一套你们团队定好的做事规矩。这四件事，就分别对应这里的四个板块。

这篇教你认识这四个板块，并独立完成每个板块里最常用的操作。

## 打开业务集成中心

点左侧边栏的「业务集成」进入。页面顶部是四张卡片，每张卡片上有一个数字，表示该板块目前有多少条内容。点任意一张卡片就切换到对应板块：

| 卡片 | 作用 | 一句话说明 |
|------|------|-----------|
| 资产模版 | 存放各种模板文件 | 让 Agent 生成文档时有现成样式可套 |
| 数据连接 | 接入外部业务数据 | 让 Agent 能读取你们的表格、文件、系统数据 |
| 密钥管理 | 保管账号口令 | 把访问第三方服务的口令安全地存起来 |
| 业务指示 | 定义做事规矩 | 给 Agent 一套统一的目标、约束和流程 |

![integration-connectors](/images/integration-connectors.png)

::: tip 数字代表什么
卡片上的数字是实时统计。比如「密钥管理」显示 2，就表示你目前能看到 2 个密钥；下面还有一行小字提示状态（如"2 个已绑定"）。
:::

## 资产模版

### 这是什么

资产模版就是你上传的**模板文件**——一份漂亮的 PPT、一个排好格式的 Excel、一份 Word 或网页模板。上传后，Agent 在帮你生成文档时就能套用这些模板，产出的东西直接符合你们的样式规范，不用每次从头排版。

支持的文件类型分成几类：PPT、Excel、文档（Word / PDF / 文本）、HTML 网页、图片等。

### 上传一个模板

1. 切到「资产模版」板块。
2. 中间有一大块**拖拽上传区**，写着"拖拽文件或文件夹到此处上传"。你有两种上传方式：
   - 直接把文件（或整个文件夹）拖进这块区域；
   - 或点区域里的「选择文件」挑单个/多个文件，点「选择文件夹」上传整个文件夹。
3. 选好后，文件会出现在上传区下方的列表里，逐个上传：
   - 转圈图标 = 正在上传；
   - 绿色对勾 = 上传成功；
   - 红色感叹号 = 失败（右侧会显示失败原因）。

![integration-templates](/images/integration-templates.png)

::: tip 上传后还要等一会儿
文件传完后，系统会在后台自动为它生成预览图和摘要。稍等片刻，卡片上的预览就会显示出来，先去做别的事也没关系。
:::

### 查找和筛选模板

左侧有一列筛选栏，帮你在模板多的时候快速定位：

- **范围**：「全部」/「我创建的」/「共享给我」，切换看谁的模板。
- **类别**：「全部类别」/「PPT」/「Excel」/「文档」/「HTML」/「其他」。
- 右侧顶部的搜索框可以按关键词搜模板名。

### 用 AI 搜索

搜索框右边有个 **✨ AI** 按钮。点亮它之后，搜索框会变成"用自然语言描述你想要的模板"，你可以直接输入一句话（比如"季度业绩汇报的蓝色商务风 PPT"），系统会按意思帮你找，而不是只按名字匹配。再点一次 ✨ AI 就切回普通搜索。

### 查看和管理某个模板

点任意一张模板卡片，右侧会滑出**详情面板**，在这里可以看预览、下载、管理版本，以及分享或删除。

想对模板做操作，也可以**右键点击**（手机上长按）卡片，弹出菜单：

- **查看详情** — 打开上面的详情面板；
- **分享** — 把模板分享给其他同事或团队；
- **移动到文件夹** — 归类整理；
- **删除** — 删掉这个模板（会先弹出确认）。

::: warning 删除要谨慎
删除后模板就不在列表里了。如果它正被某些 Agent 当模板用，删掉后那些 Agent 就套不到样式了。
:::

### 把模板归入集合

左侧筛选栏底部可以在「资产视图」和「集合视图」之间切换。**集合**相当于文件夹，把相关模板放一起方便管理：

1. 切到「集合视图」。
2. 点「+ 新建集合」。
3. 输入集合名称，点「保存」即可。

## 数据连接

### 这是什么

数据连接让 Agent 能读取你们公司的**业务数据**——比如在线表格里的销售记录、云端存放的报表文件、或公司内部系统里的客户名单。接好之后，你在对话里问 Agent"上个月华东区卖了多少"，它就能自己去查数据回答你。

::: info 场景举例：让 Agent 直接查询 CRM 里的销售数据
你的 Agent 需要读取公司 CRM 里的销售数据来回答业绩问题。在业务集成中心，你新建一条「数据连接」，指向你们 CRM 系统的数据接口，再绑上一份事先存好的访问凭证。连好后，你在对话里问"本季度谁签单最多"，Agent 就能实时查到数据回复你——不用写代码，也不用找 IT 帮忙跑报表。
:::

::: warning 建议请技术同事帮忙填写
新建数据连接时要填一些连接信息（地址、账号等），这部分通常需要懂技术的同事协助。你负责说清楚"要连哪份数据、给谁用"，让 IT 同事把具体参数填对即可。
:::

### 新建一个数据连接

1. 切到「数据连接」板块。
2. 点搜索框右侧的加号按钮，打开新建表单。
3. 选择**数据源类型**（列表里涵盖在线表格、云端文件、网络接口、业务系统等多种）。
4. 填写名称、描述，以及该类型需要的连接信息。
5. 保存后，这个连接会出现在左侧列表里。


### 测试连接是否通

连接建好后，最好确认一下它能不能正常访问：

1. 在左侧列表点选一个连接，右侧显示详情。
2. 点右上角的「测试连接」。
3. 稍等片刻，成功会提示连接正常，失败会提示错误——失败多半是地址或账号口令没填对，回到配置里改一改再测。

左侧卡片上的小图标也会跟着显示状态：绿色对勾表示正常，红色叉表示出错。

### 给连接绑定一个密钥

如果访问这份数据需要账号口令，你可以把提前存好的**密钥**绑上来，而不用把口令直接写在连接里：

1. 在连接详情里切到「密钥绑定」标签。
2. 从下拉里选一个已有的密钥（选"No key"则表示用默认身份访问，无需口令）。
3. 选好后点保存。

密钥怎么创建见下面的[密钥管理](#密钥管理)。

### 浏览数据里有什么

连接详情里还有一个「Schema」标签，点进去能让系统帮你**列出这个数据源里有哪些内容**（比如有哪些表格、字段），方便你确认连对了地方。

### 删除连接

在连接详情右上角点垃圾桶图标，确认后即可删除。

## 密钥管理

### 这是什么

密钥管理是一个**安全保险箱**，专门存放各种访问口令——第三方服务的访问口令、云服务的凭证、登录令牌等等。存进来之后，工具和数据连接需要用时会自动取用，而口令本身始终藏在保险箱里，不会明文暴露。

走查环境里已有两个真实密钥示例：`dashscope_api_key` 和 `ark_api_key`，都是文生图工具在用的访问口令。

### 新建一个密钥

1. 切到「密钥管理」板块。
2. 点右上角「新建密钥」。
3. 选择**密钥类型**，不同类型要填的字段不一样：

   | 类型 | 用途 | 主要填写内容 |
   |------|------|-------------|
   | 「API 密钥」 | 第三方服务的访问口令 | 一段 API Key |
   | 「数据库凭证」 | 连接业务数据 | 主机地址、端口、用户名、密码 |
   | 「Bearer Token」 | 令牌方式认证 | 一段 Token |
   | 「AWS 凭证」 | 访问云服务 | Access Key ID、Secret Access Key |
   | 「GCP 服务账号」 | 访问在线表格/数据仓库 | 一段服务账号信息 |
   | 「OAuth 2.0」 | 授权登录 | 客户端 ID、客户端密钥 |
   | 「自定义密钥」 | 以上都不合适时 | 自己添加字段 |

4. 填好名称、描述，以及所选类型要求的字段。
5. 选择**可见性**（私有 / 共享），保存即可。

![integration-keys](/images/integration-keys.png)

::: tip AWS 凭证可以留空
如果你的系统已经配好了默认访问身份，创建「AWS 凭证」时把字段留空即可——系统会自动用默认身份访问，不必手填口令。
:::

### 查看和修改密钥内容

点选一个密钥，右侧详情面板默认在「基本信息」标签，显示名称、类型、可见性、创建时间等。

- 想看实际存的口令值，点「查看值」（口令平时是隐藏的，点一下才显示明文）。
- 想改口令，先「查看值」再点「编辑」，改完点「保存」。

### 把密钥绑定到工具

有些工具需要口令才能干活。你可以在密钥详情的「绑定管理」标签里，把这个密钥指定给相应的工具用，工具运行时就自动取用，不必每次手输。

### 分享密钥给同事

在密钥详情的「分享设置」标签，可以把密钥分享给指定的同事或团队。

::: warning 密钥不能公开给所有人
出于安全考虑，密钥只能分享给指定的人或团队，**不能设为对所有人公开**。
:::

### 看看密钥被用了多少

「使用统计」标签会显示这个密钥被调用了多少次、有多少人/多少 Agent 用过、最近一次使用时间，方便你判断它是否还在用、能不能删。

### 删除密钥

在密钥详情右上角点垃圾桶图标，确认后删除。

::: warning 别删还在用的密钥
如果密钥卡片上显示有绑定数量（一个链条图标 + 数字），说明还有工具或连接在用它，删掉会导致它们无法正常访问，请先解除绑定。
:::

## 业务指示

### 这是什么

业务指示是你给 Agent 定"做事规矩"的地方。你可以按**组织 → 部门 → 具体指示**的层级搭一棵树，在每条指示里写清楚：这件事的目标是什么、有哪些红线不能碰、按什么规范来做、什么算做得好。定好之后，把它应用到对话，Agent 就会照着这套规矩办事，全团队口径统一。

### 三种工作模式

每条指示可以选一种模式，决定 Agent 有多大的自由度：

| 模式 | 特点 | 适合场景 |
|------|------|---------|
| 引导 | 给方向和建议，Agent 自行发挥 | 大多数日常任务 |
| 严格 | 按你排好的步骤一步步执行 | 有固定流程、不容出错的事 |
| 开放 | 约束最少，最大自由 | 探索性、创意性任务 |

### 认识这个页面

- 页面**右上角**有一排按钮：「新建节点」「自然语言创建架构」「从文档导入」「刷新」。
- **右下角**还有两个浮动按钮：「手动创建」和「AI 智能创建」。
- 左侧是**组织树**，右侧是选中节点后的**编辑区**。
- 在树上的节点上**右键点击**会弹出菜单（重命名、发布、预览、分享、删除等）。

![integration-directives](/images/integration-directives.png)

### 手动新建一个节点

1. 点右上角「新建节点」（或右下角「手动创建」）。
2. 选择节点类型：**组织**、**部门**或**指示**。组织和部门是用来分层归类的骨架，真正写规矩的是**指示**节点。
3. 填名称，选好放在树的哪个位置，创建。
4. 新建的节点会在树上高亮几秒，方便你找到它。

### 用一句话生成整套组织架构

嫌一个个建太慢？点「自然语言创建架构」，用大白话描述你们的组织和职责（比如"市场部负责活动策划和内容，客服部负责售后答疑"），系统会帮你**自动搭出整棵树**。可以先勾选"仅预览"看看效果，满意了再正式创建。

### 从文档导入

如果你已经有一份写好的制度或流程文档，点「从文档导入」，把文档内容贴进去，系统会帮你**从文档里提炼出指示节点**。

### 编辑一条指示

在树上点选一个**指示**节点，右侧编辑区会分几个标签让你填写：

- **基本** — 写清这条指示的**目标**（要达成什么），选工作模式。
- **规则** — 填**约束红线**（绝对不能做的事）、**指导方针**（建议怎么做）、**质量标准**（怎样算合格）。每一项都可以点"添加"加多条。
- **协作** — 设置需要跨部门配合的环节。
- **资源** — 指定这条指示可以用到的技能、工具、数据连接、密钥等。

改完记得点保存。

::: tip 让 AI 帮你填
写不出约束和标准？在编辑区找到 **AI 智能填充**，只要写好"目标"，系统就能根据目标自动帮你生成一套约束、指南和质量标准，你再在此基础上微调即可。
:::

### 预览 Agent 会看到的规矩

想知道这条指示最终会给 Agent 传达成什么样？用节点右键菜单里的「预览」，可以看到系统根据你填的内容整理出的完整说明。

### 发布、下架与归档

一条指示要先**发布**才能被正式使用。在指示节点上右键：

- **发布** — 让草稿正式生效（发布前状态是"草稿"）。
- **取消发布** — 撤回到可编辑状态。
- **归档** — 暂时收起不用；需要时还能**重新启用**。

### 应用到对话

指示发布后，就可以把它应用到某段对话上，让接下来的对话都遵循这套规矩。

### 版本管理

改动比较大时，可以给当前状态**存一个版本快照**。以后想反悔，能查看历史版本列表并**恢复**到某个版本，不怕改坏。

## 常见问题

::: tip 四个板块之间什么关系？
它们是各自独立又互相配合的：**密钥**存口令，**数据连接**用密钥去连数据，**资产模版**提供样式，**业务指示**统一规矩。你可以只用其中一两个，不必四个都配。
:::

::: tip 上传的模板/数据/密钥别人看得到吗？
默认是私有的，只有你自己能看。想给同事用，就用对应的「分享」功能指定分享对象。注意密钥出于安全不能对所有人公开。
:::

::: warning 找不到刚创建的内容？
点右上角的「刷新」，或重新进入一次该板块。列表是实时统计的，偶尔需要手动刷新一下。
:::
