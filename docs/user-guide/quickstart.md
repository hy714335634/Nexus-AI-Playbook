# 5 分钟快速上手

这篇教你走完最核心的一条路：**用一句话描述你想要的 AI 助手，平台替你把它造出来，然后你就能和它对话干活。** 全程只用浏览器点界面，不需要写任何代码。

::: tip 开始之前
你只需要一个能登录的账号。如果还没有，找你们的管理员要**网址**和**账号密码**。想先熟悉界面，可以看[登录与界面导览](./first-login.md)。
:::

## 你将完成的三件事

| 步骤 | 你做什么 | 大概耗时 |
|------|----------|----------|
| 1. 登录 | 打开网址、输入账号进入工作台 | 半分钟 |
| 2. 描述需求 | 用一句话说清你想要一个能做什么的助手 | 一两分钟 |
| 3. 等待并对话 | 平台在后台把助手造好，然后你和它对话 | 构建约 20–40 分钟，对话即时 |

真正需要你动手的只有前两步，加起来 5 分钟就够。第 3 步的构建由平台在后台自动完成，你可以先去忙别的。

## 第一步：登录

1. 在浏览器地址栏输入管理员给你的网址，回车。
2. 在登录页填入你的**账号**和**密码**，点「登录」。
3. 登录成功后，你会进入**工作台**首页——这是你每天的起点。

![dashboard](/images/dashboard.png)

::: warning 登录不进去？
先确认网址、账号、密码没输错（注意大小写）。如果提示账号无效或被停用，联系管理员确认你的账号是否已开通。更多说明见[登录与界面导览](./first-login.md)。
:::

## 第二步：用一句话描述你想要的 Agent

Nexus-AI 最特别的地方，就是你**不用自己搭建**——只要把想法说清楚，平台会像一支专业团队那样，自动帮你设计、编写、测试并上线一个可用的 AI 助手（这里叫 **Agent**）。

1. 在工作台上找到**新建 Agent** 的入口，点进创建页。
2. 在描述框里，用日常话把你的需求说清楚。说得越具体，造出来的 Agent 越贴合你的需要。
3. 确认无误后，点「开始构建」。

![agents-new](/images/agents-new.png)

一句好的需求描述通常包含三点：**给谁用、要它做什么、希望的结果长什么样**。参考下面的例子：

| 不够清楚 | 更好的说法 |
|----------|------------|
| 帮我处理文档 | 创建一个能读取 PDF 合同、提取关键条款并列成清单的助手 |
| 分析数据 | 创建一个能分析每月销售表格、找出增长和下滑并写成简短总结的助手 |
| 做个客服 | 创建一个能根据我们的产品说明回答常见客户问题的助手 |

::: tip 想不好怎么描述？
先照着上面的例子改一句就行。造好后如果不满意，随时可以让它重新调整，不用一次到位。完整技巧见[创建 Agent](./create-agent.md)。
:::

## 第三步：等待构建完成

点了「开始构建」后，平台就开始在后台工作了。你会看到一个**构建进度**页面，显示当前进行到哪一步。

![project-detail-stages](/images/project-detail-stages.png)

1. 进度页会一步步更新，直到显示**构建完成**。
2. 完成后，这个 Agent 就会出现在你的 Agent 列表里，随时可用。

::: tip 构建要等多久？
平均约 **20–40 分钟**。这段时间你不用一直盯着页面，可以关掉去做别的事，等会儿再回来看结果——进度会一直保留。详细的进度解读见[构建进度](./build-progress.md)。
:::

## 第四步：和你的 Agent 对话

构建完成后，就能像聊天一样使用你的 Agent 了。

1. 打开刚造好的 Agent，点「开始对话」。
2. 在底部输入框里输入你的问题或任务，回车发送。
3. Agent 会开始回答，文字会一段段地显示出来——这是正常的，说明它正在实时作答。

![chat](/images/chat.png)

试着让它做一件你最初描述的事情，看看结果是否符合预期。如果不满意，直接在对话里告诉它怎么改就行。

::: tip 还能上传文件
对话时可以上传图片、Excel、Word、PDF 等文件，让 Agent 结合文件内容来回答。更多用法见[对话](./chat.md)。
:::

## 下一步

你已经走完了从"想法"到"能用的 Agent"的完整一圈。接下来可以：

- 顺着[学习路径](./learning-path.md)由浅入深了解各项功能；
- 深入学习[创建 Agent](./create-agent.md) 的进阶技巧，把需求描述得更精准；
- 熟悉[工作台](./dashboard.md)，看清每天该从哪里开始。

## 常见问题

**造好的 Agent 存在哪里？会不会丢？**
不会。它会一直留在你的 Agent 列表里，下次登录还在，可以反复使用。

**造错了或不想要了怎么办？**
可以随时删除，也可以让它重新调整。造 Agent 不是一锤子买卖，尽管多试。

**构建卡住或失败了怎么办？**
先刷新进度页看看是不是已经继续了；如果确实失败，重新发起一次构建，或把需求描述得更清楚些。仍不行就联系管理员。

**我描述得不够专业，能造出来吗？**
能。用你平时说话的方式描述就行，不需要任何技术词汇——这正是平台的设计目的。
