# 资源组与共享

「共享资源」让你把自己创建的东西——智能体、技能、项目等——放进一个个「文件夹」，然后一次性分享给同事或整个部门。同事无需你逐个转发，打开文件夹就能看到里面的全部资源。

::: tip 什么时候用它？
当你想把一组相关的资源统一交给别人使用时。比如把「客服助手」和它用到的几个技能放进一个文件夹，分享给客服组，全组立刻都能用。
:::

## 打开「共享资源」

1. 在左侧导航栏点击「共享资源」。
2. 进入后页面标题为「共享资源」。

<!-- SCREENSHOT: resource-groups-list -->

如果你还没有创建过任何文件夹，页面中间会显示一个空状态，并提供「创建第一个文件夹」按钮。

## 页面上有什么

页面顶部是一条概览条，用数字告诉你当前情况：

| 项目 | 含义 |
| --- | --- |
| 文件夹 | 你能看到的文件夹总数 |
| 资源数 | 这些文件夹里资源的总数量 |
| 已共享 | 已经分享给别人的文件夹数量 |

概览条右侧还有三个权限说明标签（查看者、编辑者、拥有者），把鼠标停在上面可以看到每种权限的解释。

下方的文件夹分成两组显示：

- **我创建的** — 你自己新建的文件夹。
- **共享给我的** — 别人分享给你的文件夹。

每个文件夹以卡片形式展示，卡片上会标明：

- 右上角标签：「已共享」（绿色，表示分享给了别人）或「私有」（灰色，只有你自己）。
- 一排小图标，预览文件夹里有哪些类型的资源。
- 底部：资源数量、成员数量；如果你是创建者，会有一个「拥有者」标记。

## 新建文件夹

1. 点击右上角的「新建文件夹」按钮（空状态时是「创建第一个文件夹」）。
2. 在弹出的「创建新文件夹」窗口中填写：
   - **文件夹名称**（必填）。
   - **文件夹描述**（可选，一句话说明这个文件夹是做什么的）。
3. 点击「创建」。窗口关闭后，新文件夹会立刻出现在「我创建的」一组里。

<!-- SCREENSHOT: resource-group-create -->

::: tip
文件夹刚创建时是空的。接下来你可以往里面添加资源，再决定分享给谁。
:::

## 添加资源到文件夹

把资源放进文件夹时，请注意两条规则：

::: warning 只能添加自己创建的资源
你只能把**自己创建的**资源加进文件夹。别人创建的资源不能替他们添加。
:::

::: warning 应用不能加入
「应用」不支持放进共享文件夹，其余类型（智能体、技能、项目、连接器、密钥、指令、工具、服务器、模板等）都可以。
:::

## 查看文件夹里的资源

在文件夹列表里点击任意一张卡片，进入文件夹详情页。

<!-- SCREENSHOT: resource-group-detail -->

详情页顶部显示文件夹名称、描述，以及资源数量。往下是文件夹里的资源，按类型分成一排「标签页」（例如智能体、技能各占一个标签），点击标签可切换查看不同类型。

你可以用两个工具快速找东西：

- **搜索框**：输入关键词，在当前文件夹里筛选资源。
- **排序菜单**：可选「手动 / 名称 / 类型 / 添加时间」四种排序方式。

::: tip 调整资源顺序
当排序方式为「手动」、没有输入搜索词、且资源数量不太多时，你可以直接拖动卡片来调整顺序。列表很长或正在搜索时，拖动会自动关闭，改用排序菜单即可。
:::

如果你对这个文件夹有管理权限，把鼠标停在资源卡片上时，右上角会出现一个「移除」按钮，点击即可把该资源移出文件夹（资源本身不会被删除，只是不再属于这个文件夹）。

## 把文件夹分享给别人

只有文件夹的创建者（或管理员）能进行分享。

1. 在文件夹详情页点击右上角的「分享」按钮。
2. 在弹出的窗口里搜索你想分享的对象——可以是**某个人**，也可以是**某个部门/用户组**。
3. 为对方选择一个权限级别（查看者 / 编辑者 / 拥有者）。
4. 确认后，对方就会在自己的「共享给我的」里看到这个文件夹。

<!-- SCREENSHOT: resource-group-share -->

### 权限级别说明

| 权限 | 对方能做什么 |
| --- | --- |
| 查看者 | 只能查看文件夹里的资源 |
| 编辑者 | 查看，并能调整文件夹内容 |
| 拥有者 | 完全管理，包括再分享给别人 |

::: tip
分享给一个**部门/用户组**后，组里的每个人都会自动获得这个文件夹的访问权，新加入该组的人也会自动获得——不用逐个添加。
:::

## 管理谁能访问

如果你是创建者或管理员，详情页会有一块「访问权限」区域，列出所有被授权的人和用户组，以及各自的权限。

- 每一行显示对方的名字（或用户组）和权限标记。
- 想收回某人的权限时，把鼠标停在对应行上，点击出现的「移除」按钮即可。创建者本人（拥有者）无法被移除。

::: info
被分享的普通成员看不到「访问权限」区域，也看不到还有谁能访问——他们只能看到文件夹里的资源本身。
:::

## 删除文件夹

1. 在文件夹卡片上（或有删除权限的位置）把鼠标停上去，点击「删除」图标。
2. 系统会弹出确认提示，确认后文件夹被删除。

::: warning
只有创建者或管理员能删除文件夹。删除只是移除这个「文件夹」本身，里面各个资源仍然保留，不会被一并删掉。
:::

## 常见问题

::: tip 我把资源加进文件夹后，同事看得到吗？
只有在你把文件夹**分享**给对方（或对方所在的部门）之后，他们才能看到。仅仅加进文件夹、没有分享，别人是看不到的。
:::

::: tip 为什么我看不到别人文件夹里"还有谁被分享"？
出于隐私考虑，只有文件夹的创建者和管理员能看到完整的访问名单。被分享的人只能看到资源，看不到其他访问者。
:::

::: tip 分享出去后还能改权限吗？
可以。再次分享同一个人时，选择新的权限级别即可覆盖旧的；或在「访问权限」区域移除后重新分享。
:::
