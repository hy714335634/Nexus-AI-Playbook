# Learning Path

The user guide has more than twenty documents. You don't have to read them all at once—this page strings them into a step-by-step route that tells you **what to learn first and what comes next**, and which document to jump to at each step.

Follow along and you'll go from "signing in for the first time" all the way to "setting up a working set of agents for your team." No technical background needed anywhere—just point and click as you go.

![dashboard](/images/dashboard.png)

## First, pick a route by your goal

Don't want to read from the top? Find the situation that fits you and jump straight to that stage:

| What you want to do | Suggested route |
| --- | --- |
| Just try it out and get a feel for what the platform can do | Stage 1 |
| Build an agent you can actually use, from scratch | Stage 1 → Stage 2 → Stage 3 |
| Connect agents to your company's data and systems to make them more capable | Finish Stage 3, then continue with Stage 4 |
| Have agents run automatically on a schedule and help you on the go | Stage 5 |
| Assign agents to a team and share your work | Stage 6 |
| Follow a complete example end to end | Jump to "Hands-on tutorials" |

::: tip Recommendation
If this is your first time, going stage by stage is the easiest path. Each stage takes about half an hour, and by the end of each one you can do real work—so nothing feels like "learning I'll never use."
:::

## Stage 1 · Getting started (about 30 minutes)

Sign in, get familiar with the screen, then spend five minutes producing your first result to build confidence.

| Order | Document | What you'll learn |
| --- | --- | --- |
| 1 | [Sign In & UI Tour](./first-login.md) | How to sign in and what each area of the screen is for |
| 2 | [Quickstart](./quickstart.md) | Describe what you need in one sentence and get your first result fast |
| 3 | Learning Path (this page) | Plan the order to learn everything else |

## Stage 2 · Build your first agent

An agent is a "digital helper" that does work for you. This stage takes you from describing what you want, to watching it get built step by step, to chatting with it.

| Order | Document | What you'll learn |
| --- | --- | --- |
| 1 | [Creating an Agent](./create-agent.md) | Describe what you want in plain language and start the build |
| 2 | [Build Progress](./build-progress.md) | What you'll see during the build and roughly how long to wait |
| 3 | [Chat & Sessions](./chat.md) | Chat with your agent, upload files, and manage multi-turn conversations |

::: tip How long does building take?
From describing what you need to the agent being ready takes about 20–40 minutes on average. You can go do something else in the meantime—the platform finishes the work in the background, and you come back when it's done.
:::
