# 系统设置

设置页面用于管理你的账户信息和应用配置。通过左侧导航栏的 **「系统配置」** 进入。

![系统设置](/images/settings.png)

## 个人信息

管理你的账户基本信息。

| 字段 | 说明 | 可修改 |
|------|------|--------|
| **用户名** | 你的登录用户名 | ✅ |
| **邮箱** | 关联的邮箱地址 | ✅ |

### 修改方法

1. 点击对应字段右侧的 **编辑图标**
2. 输入新的信息
3. 点击 **「保存」** 确认修改

::: tip
用户名修改后，下次登录需要使用新的用户名。请确保记住修改后的用户名。
:::

## API 配置

配置 Nexus-AI 后端服务的连接信息。

| 字段 | 说明 | 示例 |
|------|------|------|
| **API 基础 URL** | Nexus-AI 后端服务地址 | `http://localhost:8000` |
| **API 密钥** | 用于身份验证的 API 密钥 | `sk-xxxx...` |

### API URL 说明

API 基础 URL 指向 Nexus-AI 的后端 API 服务。这个地址在系统部署时由管理员配置。通常情况下你不需要修改此项。

以下情况可能需要修改 API URL：
- 后端服务迁移到了新的地址
- 需要切换到不同的环境（如从测试环境切换到生产环境）
- 使用代理服务器访问后端

### API 密钥说明

API 密钥用于前端与后端之间的身份验证。如果系统启用了 API 密钥验证，你需要在此配置正确的密钥。

::: warning 谨慎修改
修改 API 配置可能导致系统无法正常连接后端服务。如果修改后出现问题：
1. 检查 URL 是否正确（包括协议 http/https 和端口号）
2. 检查 API 密钥是否有效
3. 联系管理员获取正确的配置信息
:::

## 通知设置

配置系统通知的开关，控制你接收哪些类型的通知：

| 通知类型 | 说明 | 默认状态 | 建议 |
|----------|------|----------|------|
| **构建完成通知** | 当 Agent 构建成功完成时发送通知 | 开启 ✅ | 建议保持开启 |
| **构建失败通知** | 当 Agent 构建失败时发送通知 | 开启 ✅ | 建议保持开启 |
| **Agent 调用通知** | 当 Agent 被调用时发送通知 | 关闭 ❌ | 调用频繁时可能产生大量通知 |

### 操作方法

点击通知项右侧的 **开关按钮** 即可切换启用/关闭状态。

### 通知建议

- **构建完成通知** — 强烈建议保持开启。构建过程可能需要几分钟到十几分钟，开启通知后你可以去做其他事情，完成时会收到提醒
- **构建失败通知** — 强烈建议保持开启。及时了解构建失败，以便查看错误日志和重新构建
- **Agent 调用通知** — 根据需要选择。如果 Agent 被频繁调用，开启后可能收到大量通知

::: tip 不打扰工作
如果你不想被频繁的通知打扰，可以只保留「构建完成」和「构建失败」两项通知，关闭「Agent 调用通知」。
:::

## 设置最佳实践

1. **首次使用时** — 确认 API 配置正确，如果不确定请联系管理员
2. **保持通知开启** — 至少保持构建相关的通知开启，方便跟踪构建进展
3. **定期检查** — 如果遇到系统连接问题，首先检查 API 配置是否正确
4. **修改密码** — 如果需要修改密码，联系管理员在 [用户管理](/admin/users) 页面操作
