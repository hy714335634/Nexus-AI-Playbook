# 用户管理

用户管理页面用于管理平台的用户账号和权限。通过左侧导航栏的 **「用户管理」** 进入。

![用户管理](/images/users.png)

::: info 权限要求
用户管理功能仅对 **Admin（管理员）** 角色可用。普通用户无法看到此菜单。
:::

## 角色与权限体系

Nexus-AI 采用 **基于角色的访问控制（RBAC）** 模型，提供两种用户角色：

### 角色权限对比

| 功能模块 | Admin（管理员） | User（普通用户） |
|----------|:-:|:-:|
| **创建 Agent** | ✅ | ✅ |
| **管理自己的 Agent** | ✅ | ✅ |
| **对话测试** | ✅ | ✅ |
| **查看工具库** | ✅ | ✅ |
| **构建新工具** | ✅ | ✅ |
| **MCP 服务器管理** | ✅ | ✅ |
| **系统配置** | ✅ | ✅ |
| **查看业务洞察** | ✅ | ✅ |
| **用户管理** | ✅ | ❌ |
| **创建/禁用/删除用户** | ✅ | ❌ |
| **修改他人密码** | ✅ | ❌ |
| **更改用户角色** | ✅ | ❌ |

### 角色说明

**Admin（管理员）：**
- 拥有平台的全部管理权限
- 可以管理所有用户的账号和权限
- 负责系统的整体配置和维护
- 建议每个组织至少设置 2 名管理员，互为备份

**User（普通用户）：**
- 拥有 Agent 构建、管理和使用的完整权限
- 可以管理自己的个人设置
- 不能访问用户管理页面
- 适合日常使用 Agent 功能的团队成员

## 用户列表

用户列表以表格形式展示所有已注册的用户：

| 列名 | 说明 | 示例 |
|------|------|------|
| **User** | 用户名（当前登录用户旁标注 "you"） | admin (you) |
| **Email** | 用户邮箱地址 | admin@example.com |
| **Role** | 用户角色 | Admin / User |
| **Status** | 账号状态 | Active（活跃）/ Disabled（已禁用） |
| **Last Login** | 最后一次登录时间 | 2025-01-15 10:30 |
| **Actions** | 可执行的操作按钮 | Disable / Enable / Edit |

### 用户状态说明

| 状态 | 说明 | 影响 |
|------|------|------|
| **Active（活跃）** | 正常状态 | 用户可以正常登录和使用系统 |
| **Disabled（已禁用）** | 临时禁用 | 用户无法登录，但数据和历史记录保留 |

## 用户操作

### 创建用户

为新团队成员创建平台账号。

**操作步骤：**

1. 点击页面右上方的 **「创建用户」** 按钮
2. 在弹出的对话框中填写用户信息：

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| **用户名** | 登录时使用的用户名 | 必填 |
| **邮箱** | 用户的邮箱地址 | 必填 |
| **初始密码** | 用户首次登录使用的密码 | 必填 |
| **角色** | Admin 或 User | 必填 |

3. 点击 **「确认」** 完成创建

::: tip 创建建议
- 用户名建议使用英文，便于系统识别
- 初始密码建议设置为临时密码，并通知用户首次登录后及时修改
- 除非必要，建议将新用户的角色设为 User
:::

### 编辑用户

修改已有用户的信息。

**操作步骤：**

1. 在用户列表中找到要编辑的用户
2. 点击 **Actions** 列的编辑按钮（或点击用户名）
3. 可修改的信息：

| 字段 | 说明 |
|------|------|
| **邮箱** | 更新用户的邮箱地址 |
| **角色** | 更改用户角色（Admin ↔ User） |
| **密码** | 重置用户密码 |

4. 点击 **「保存」** 确认修改

### 禁用用户

临时禁止用户登录系统。

**操作步骤：**

1. 在用户列表中找到要禁用的用户
2. 点击 **Actions** 列的 **「Disable」** 按钮
3. 确认操作

**禁用的效果：**
- 用户立即无法登录系统
- 用户的所有数据和历史记录 **保留**
- 用户构建的 Agent **保持原状态**（不会自动停止）
- 可以随时重新启用

**适用场景：**
- 员工离职或调岗
- 临时冻结账号
- 安全事件响应

### 启用用户

恢复已禁用用户的访问权限。

**操作步骤：**

1. 在用户列表中找到状态为 Disabled 的用户
2. 点击 **Actions** 列的 **「Enable」** 按钮
3. 用户即可使用原有的用户名和密码重新登录

### 重置密码

为用户重置登录密码。

**操作步骤：**

1. 编辑对应用户
2. 在密码字段输入新密码
3. 保存修改
4. 通知用户使用新密码登录

::: warning 安全提醒
重置密码后，请通过安全渠道（如当面或加密消息）将新密码告知用户。避免通过不安全的渠道（如普通邮件）发送密码。
:::

## 安全注意事项

### 管理员账号安全

- 系统初始管理员账号请及时修改默认密码
- 建议启用 SSO 单点登录，使用企业统一的身份认证体系
- 定期审查管理员列表，移除不再需要管理权限的用户

### 账号管理规范

| 操作 | 建议 |
|------|------|
| 新员工入职 | 创建 User 角色账号，分配初始密码 |
| 员工离职 | 及时禁用账号（而非删除，保留审计记录） |
| 权限变更 | 根据职责调整角色 |
| 密码重置 | 通过安全渠道传递新密码 |
| 定期审查 | 每月检查一次用户列表，清理不活跃账号 |

### SSO 集成

如果你的组织使用了 SSO（单点登录），用户管理会更加简便：

- 用户通过企业身份系统统一认证
- 离职员工在企业系统中禁用后，自动无法登录 Nexus-AI
- 支持 SAML 协议，兼容主流身份提供商

::: info
SSO 集成需要管理员在系统部署时进行配置。如果你的组织需要启用 SSO，请联系系统管理员或运维团队。
:::

## 自身账号限制

::: warning
管理员无法禁用或删除自己的账号。如需修改自己的个人信息（用户名、邮箱），请在 [系统设置](/admin/settings) 页面操作。
:::
