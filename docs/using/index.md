# 使用 Nexus-AI

本章节带你走完 Nexus-AI 的日常使用流程：从登录后的工作台出发，创建 Agent、观察构建过程、把 Agent 拉出来对话，再到后续的项目管理、Agent 管理、工具库和 MCP 服务器配置。每一页都对应控制台里的一个主功能区，按顺序读完就能掌握整个平台的操作面板。

如果你刚完成「快速开始」，建议从「工作台」读起；如果你已经有具体任务，直接跳到对应页面即可。

## 本章节文档

| 文档 | 简介 |
|------|------|
| [工作台](./dashboard) | 登录后的首页与控制中心：快速构建入口、最近项目、Agent 概览和平台状态。 |
| [创建 Agent](./create-agent) | 两种创建模式——快速创建与引导创建——的适用场景和完整操作流程。 |
| [构建进度](./build-progress) | 实时追踪 Agent 构建的 9 个阶段，看清每个 Builder Agent 在做什么。 |
| [对话](./chat) | 独立的多轮对话界面：选择 Agent、开启会话，验证功能与业务场景。 |
| [项目管理](./projects) | 构建项目的列表与状态管理，追踪从需求到上线的完整生命周期。 |
| [Agent 管理](./manage-agents) | 查看、搜索、筛选、启停和删除所有已构建 Agent 的操作中心。 |
| [工具库](./tools) | 浏览与管理平台中所有可供 Agent 调用的能力工具。 |
| [MCP 服务器](./mcp) | 通过 MCP 协议接入外部工具与服务，扩展 Agent 能力边界。 |
