# 项目管理

项目管理页面展示所有构建项目的列表和状态，是你追踪 Agent 构建全生命周期的管理中心。通过左侧导航栏的 **「构建项目」** 进入。

![项目管理](/images/projects.png)

## 什么是项目

在 Nexus-AI 中，**项目（Project）** 是 Agent 构建任务的管理单元。每次你创建 Agent 时，系统都会自动创建一个对应的构建项目。

一个项目完整记录了从你提交需求到 Agent 最终部署上线的全过程，包括：

- 你的原始需求描述
- 每个阶段的执行状态和产出物
- Builder Agent 的工作日志
- 最终构建的 Agent 关联信息

::: info 项目与 Agent 的关系
一个项目产出一个 Agent。项目记录了"如何构建"，Agent 则是"构建的结果"。你可以从项目跳转到对应的 Agent，也可以从 Agent 详情页跳转回关联的项目。
:::

## 项目列表

### 状态筛选

页面顶部提供 **状态筛选标签**，每个标签后面的数字表示该状态的项目数量：

| 标签 | 说明 | 颜色标识 |
|------|------|----------|
| **全部** | 显示所有项目 | — |
| **构建中** | 正在构建的项目（流水线正在执行） | 蓝色 |
| **已完成** | 构建成功的项目（Agent 已部署） | 绿色 |
| **失败** | 构建过程中出错的项目 | 红色 |
| **已暂停** | 被手动暂停的项目 | 灰色 |

点击标签即可快速切换视图。例如，点击「失败」可以快速找到所有需要关注的失败项目。

### 构建状态说明

项目在其生命周期中可能经历以下状态：

```
创建项目 → Pending（等待开始）→ Running（构建中）
                                      ↙     ↓     ↘
                             Completed   Failed   Paused
                             （已完成）  （失败）  （已暂停）
```

| 状态 | 说明 | 你需要做什么 |
|------|------|-------------|
| **Pending** | 项目已创建，等待系统分配资源 | 稍等片刻，系统会自动开始 |
| **Running** | 8 个 Builder Agent 正在协作构建 | 可以查看实时进度 |
| **Waiting Human** | 引导创建模式下，等待你回答问题 | 去构建进度页面回答 AI 的提问 |
| **Completed** | 所有 9 个阶段成功完成 | 可以开始使用 Agent 了 |
| **Failed** | 某个阶段执行失败 | 查看错误日志，可能需要修改需求后重试 |
| **Paused** | 你手动暂停了构建 | 可以恢复或放弃 |

### 搜索和排序

- **搜索框** — 输入关键词，按项目名称搜索
- **排序方式** — 默认按最近更新排序，可选创建时间等其他排序方式

### 项目卡片

每个项目以卡片形式展示，包含丰富的信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| **项目名称** | 基于需求自动生成的名称 | "医学文献研究助手" |
| **状态标签** | 当前构建状态 | 已完成（绿色）/ 构建中（蓝色）/ 失败（红色） |
| **创建时间** | 项目创建的时间 | "17天前"、"2小时前" |
| **当前阶段** | 正在执行或最后执行的 Builder Agent | "agent_deployer"、"tools_engineer" |
| **阶段进度** | 9 个阶段的完成情况 | 用 ✅ / ⏳ / ❌ 标记每个阶段 |
| **进度条** | 总体完成百分比 | 0% - 100% |
| **完成比例** | 精确的百分比数字 | "100%"、"86%"、"44%" |

### 阶段图标含义

每个项目卡片上会显示 9 个小图标，对应 9 个构建阶段：

| 图标 | 状态 | 说明 |
|------|------|------|
| ✅ 绿色对勾 | 已完成 | 该阶段成功执行完毕 |
| ⏳ 黄色进行中 | 执行中 | 该阶段正在执行 |
| ❌ 红色叉号 | 失败 | 该阶段执行出错 |
| ⬜ 灰色空白 | 未开始 | 该阶段尚未执行 |

通过这些图标，你可以一目了然地看到项目的构建进展。

## 查看项目详情

点击项目卡片右侧的 **`>`** 箭头，进入项目的详情页面。详情页面等同于 [构建进度](/using/build-progress) 页面，展示：

- 每个阶段的详细执行信息
- 阶段产出物和资源文件
- Builder Agent 的执行日志
- Token 消耗和耗时统计

## 项目操作

### 新建项目

点击页面右上角的 **「+ 新建项目」** 按钮，可以直接创建新的构建项目。这等同于进入 [创建 Agent](/using/create-agent) 页面。

### 其他操作

| 操作 | 说明 |
|------|------|
| **查看详情** | 进入项目构建进度页面，查看各阶段产出 |
| **查看 Agent** | 构建完成后，跳转到关联的 Agent 详情页 |
| **刷新列表** | 手动刷新项目列表获取最新状态 |

::: tip
项目完成后，关联的 Agent 会自动出现在 [Agent 管理](/using/manage-agents) 页面。你可以从项目列表直接跳转过去。
:::

## 项目管理最佳实践

### 关注失败项目

构建失败的项目值得特别关注。点击失败项目查看详情，常见的解决策略：

| 失败阶段 | 常见原因 | 建议操作 |
|----------|----------|----------|
| 需求分析 | 需求描述过于模糊 | 使用引导创建模式重新创建 |
| 工具开发 | 需要的 API 不可用 | 确认 API 服务状态，或修改需求移除相关功能 |
| 代码开发 | 需求过于复杂 | 尝试简化需求，分步构建 |
| 开发管理 | 代码质量未达标 | 系统通常会自动重试，如持续失败请简化需求 |
| 部署上线 | 部署环境问题 | 联系管理员检查部署环境 |

### 利用已完成项目

已完成的项目是宝贵的参考资源：

- 查看各阶段产出物，了解平台是如何将你的需求转化为 Agent 的
- 通过查看需求文档和架构设计，学习如何更好地描述需求
- 比较不同项目的构建时间和 Token 消耗，了解复杂度与资源的关系
