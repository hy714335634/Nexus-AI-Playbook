# Using Nexus-AI

This chapter walks through the everyday flow of working with Nexus-AI: from the Dashboard you land on after signing in, to creating an agent, watching it being built, chatting with it, and finally managing projects, agents, tools, and MCP servers. Each page maps to a main area of the console, so reading them in order gives you a full tour of the platform.

If you have just finished "Getting Started", begin with the Dashboard. If you already have a specific task in mind, jump straight to the relevant page.

## Docs in this chapter

| Doc | What it covers |
|-----|----------------|
| [Dashboard](./dashboard) | The home page and control center after you sign in: quick-build entry, recent projects, agent overview, and platform status. |
| [Creating an Agent](./create-agent) | The two creation modes — Quick Create and Guided Create — when to use each, and the full step-by-step flow. |
| [Build Progress](./build-progress) | Live tracking for the 9 stages of an agent build, so you can see exactly what each Builder Agent is doing. |
| [Chat & Sessions](./chat) | A standalone multi-turn chat interface: pick an agent, start a session, and validate its behavior against real scenarios. |
| [Project Management](./projects) | The list and status view for build projects — track the full lifecycle from requirement to deployed agent. |
| [Managing Agents](./manage-agents) | The operations hub for viewing, searching, filtering, starting, stopping, and deleting every agent you have built. |
| [Tools](./tools) | Browse and manage every capability tool registered on the platform that your agents can call. |
| [MCP Server](./mcp) | Integrate external tools and services via the Model Context Protocol to extend what your agents can do. |
