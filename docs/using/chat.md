# 对话测试

对话页面提供独立的对话界面，让你与任意 Agent 进行多轮交互。这是验证 Agent 功能、测试业务场景的主要入口。通过左侧导航栏的 **「会话」** 进入。

![对话页面](/images/chat.png)

## 开始对话

### 第 1 步：选择 Agent

页面左上方的 **「选择 Agent」** 下拉框列出了所有处于运行状态的 Agent。

![选择 Agent](/images/chat-select-agent.png)

选择你要对话的 Agent 后，右侧会显示对话区域。下拉框中每个 Agent 会显示名称和简要描述，帮助你快速辨识。

::: tip 只有运行中的 Agent 可以对话
如果你在下拉框中没有看到想要的 Agent，可能是该 Agent 处于离线或异常状态。请到 [Agent 管理](/using/manage-agents) 页面检查其状态。
:::

### 第 2 步：创建或选择会话

选择 Agent 后：
- 系统自动创建一个 **新会话**
- 也可以点击左侧会话列表旁的 **「+」** 按钮手动创建新会话
- 或者点击已有的历史会话继续之前的对话

每个会话都有独立的上下文。在同一会话中，Agent 会记住之前的对话内容。

### 第 3 步：发送消息

1. 在底部 **输入框** 中输入你的消息
2. 按 **Enter** 键或点击 **发送按钮**
3. Agent 会实时生成并显示响应（流式输出，你可以看到文字逐步出现）

## 智能对话路由

Nexus-AI 的对话系统不仅仅是简单的"人对 Agent"一问一答。平台内置了 **Magician Agent（对话魔术师）** 来智能管理对话过程：

### Magician Agent 的工作原理

当你发起对话时，Magician Agent 在后台执行三步操作：

1. **Agent 匹配** — 根据你的问题、场景和关键词，从已有 Agent 列表中找到最相关的 Agent
2. **动态构建对话 Agent** — 基于匹配结果和当前问题，动态构建最合适的对话 Agent
3. **问题响应** — 由构建好的对话 Agent 进行多轮对话响应

这意味着系统会自动为你的问题找到或构建最合适的 Agent 来回答，而不需要你手动判断该找哪个 Agent。

### 三种对话模式

根据问题的复杂度和涉及的 Agent 数量，系统支持三种对话模式：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **Single Agent** | 由单个 Agent 独立处理 | 问题清晰、属于单一领域 |
| **Multi-Agent Swarm** | 多个 Agent 以"群体智能"方式协作 | 问题涉及多个领域，需要多个 Agent 动态协商 |
| **Multi-Agent Graph** | 多个 Agent 按预定义的图结构流程协作 | 复杂的多步骤流程，有明确的处理顺序 |

::: info
对话模式由系统自动判断和选择，你无需手动设置。系统会根据你的问题复杂度和可用 Agent 情况，自动选择最合适的模式。
:::

## 多轮对话

Nexus-AI 的对话支持完整的多轮上下文管理：

### 上下文保持

在同一个会话中：
- Agent 会记住所有之前的对话内容
- 你可以基于前面的回答继续追问
- 上下文信息在整个会话中保持连贯
- 上传的文件也会保持在上下文中

**对话示例：**

```
你: 请分析我上传的这份销售数据
Agent: 好的，我已分析完毕。数据包含 1,200 条记录，涵盖 5 个产品类别。
      其中 A 类产品销售额最高，占比 35%...

你: A 类产品的月度趋势是怎样的？
Agent: 基于数据分析，A 类产品的月度销售趋势如下：
      1月: ¥120,000  2月: ¥98,000 ...
      整体呈上升趋势，平均月增长率为 8.2%。

你: 帮我把这个趋势做成折线图
Agent: 好的，以下是 A 类产品月度销售趋势折线图：
      [Mermaid 图表]
```

### 新建会话

当你想开始一个全新的对话主题时，建议创建新会话：

- 新会话 = 全新的上下文 = 不受之前对话影响
- 旧会话仍然保留，可以随时切换回来

::: tip 何时该创建新会话
- **换主题时** — 不同的分析任务建议分在不同会话
- **重新开始时** — 如果之前的对话走偏了，不如重新来
- **上下文过长时** — 过长的上下文可能影响 Agent 的响应质量
:::

## 文件上传（多模态交互）

Nexus-AI 支持 **多模态交互** —— 你可以在对话中上传文件，让 Agent 分析和处理文件内容。

### 上传步骤

1. 点击输入框旁的 **📎 附件按钮**
2. 选择要上传的文件（可选择多个）
3. 等待文件上传完成（进度条显示上传状态）
4. 在输入框中输入你的问题或指令，例如：
   - "请分析这份 Excel 的数据"
   - "总结这份 PDF 的核心内容"
   - "这张图片中有什么信息？"
5. 点击发送，Agent 会结合文件内容进行分析

### 支持的文件格式

| 格式 | 文件类型 | 典型用途 |
|------|----------|----------|
| **JPG / PNG** | 图片文件 | 图表分析、OCR 识别、图像描述 |
| **PDF** | 文档文件 | 文档摘要、内容提取、信息查询 |
| **Excel (.xlsx)** | 电子表格 | 数据分析、统计计算、趋势分析 |
| **Word (.docx)** | 文档文件 | 内容摘要、文档编辑、格式转换 |
| **CSV** | 数据文件 | 数据分析、数据清洗、可视化 |
| **TXT** | 纯文本文件 | 文本分析、信息提取 |

### 文件限制

| 限制项 | 限额 |
|--------|------|
| **单个文件大小** | 最大 **50 MB** |
| **每条消息附件数** | 最多 **5 个文件** |

::: warning
超过大小限制的文件无法上传。如果文件过大，建议分割成小文件或压缩后上传。
:::

### 文件使用技巧

| 场景 | 推荐做法 |
|------|----------|
| 分析 Excel 数据 | 上传文件 + "请分析这份数据的主要特征和异常值" |
| 总结 PDF 文档 | 上传文件 + "请用 300 字总结这份文档的核心内容" |
| 对比多份文件 | 上传多个文件 + "请对比这两份文件的差异" |
| 提取图片信息 | 上传图片 + "请描述图片中的内容并提取关键信息" |

## Agent 响应格式

Agent 的回复支持丰富的格式化内容展示：

### Markdown 格式

Agent 可以返回完整的 Markdown 格式内容：

- **标题层级** — 用于组织结构化回复
- **列表** — 有序和无序列表
- **表格** — 数据表格展示
- **链接** — 引用和参考链接
- **引用** — 引用段落
- **粗体/斜体** — 重点标记

### 代码块

Agent 返回的代码会以 **语法高亮** 方式展示：

- 支持 Python、JavaScript、SQL 等多种语言
- 代码块可以一键复制

### Mermaid 图表

Agent 可以生成 **可视化图表**，通过 Mermaid 语法渲染：

- **流程图** — 展示业务流程或决策逻辑
- **架构图** — 展示系统架构或组件关系
- **时序图** — 展示交互序列
- **甘特图** — 展示计划和进度

::: info
Mermaid 图表会在对话中实时渲染为可视化图形，无需额外工具。
:::

## 会话管理

左侧面板用于管理你的所有会话：

| 操作 | 方法 | 说明 |
|------|------|------|
| **创建新会话** | 点击 **「+」** 按钮 | 开始一个全新的对话上下文 |
| **切换会话** | 点击会话列表中的项 | 切换到其他会话，查看历史对话 |
| **查看历史** | 点击已有会话 | 回顾完整的对话历史 |
| **继续对话** | 在历史会话中发送消息 | 在之前的上下文基础上继续交互 |

每个会话显示：
- **会话标题** — 通常是第一条消息的摘要
- **最后更新时间** — 最近一次对话的时间
- **消息数** — 会话中的消息总数

## 从其他入口发起对话

除了在「会话」页面对话，你还可以从以下入口快速发起对话：

| 入口 | 位置 | 说明 |
|------|------|------|
| **工作台** | "运行中的 Agent" 区域 | 点击 Agent 卡片的"对话"按钮 |
| **Agent 详情页** | 页面底部对话区域 | 在 Agent 详情页内直接对话 |

## 对话最佳实践

### 提问技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| **问题要具体** | 越具体的问题，Agent 回答越准确 | ✅ "2024年Q3的销售额同比增长了多少？" ❌ "给我看看数据" |
| **善用附件** | 上传文件让 Agent 直接分析 | 上传 Excel + "请按月份汇总销售数据" |
| **分步提问** | 复杂问题拆成多步 | 先"总结数据概况" → 再"分析异常值" → 再"给出改进建议" |
| **提供上下文** | 说明背景信息帮助理解 | "我是产品经理，需要准备下周的产品评审报告..." |
| **明确输出格式** | 说明期望的输出形式 | "请用表格形式对比这两个方案的优缺点" |

### 常见问题处理

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| Agent 回复不准确 | 问题不够具体或缺少上下文 | 提供更详细的问题和背景信息 |
| Agent 无法处理文件 | Agent 没有文件处理相关的工具 | 检查 Agent 的工具列表，可能需要创建新的 Agent |
| 响应时间过长 | 处理内容量大或模型负载高 | 尝试减小文件体积或拆分请求 |
| 上下文混乱 | 会话太长导致上下文过载 | 创建新会话重新开始 |
| Agent 离线无法对话 | Agent 未启动 | 到 Agent 管理页面启动 Agent |
