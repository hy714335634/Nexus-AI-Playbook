# 工作台

工作台是你进入 Nexus-AI 后的首页，它是整个平台的控制中心，提供全局概览、快捷创建入口和状态监控。

![工作台](/images/dashboard.png)

## 快速构建

工作台最核心的功能是顶部的 **快速构建区域**，让你无需离开首页即可开始创建 Agent。

### 使用方法

1. 在文本框中输入你的需求描述，例如：

   > 创建一个能查询天气信息并给出穿衣建议的 Agent

   > 帮我创建一个医学文献研究助手，能在 PubMed 搜索论文并生成 APA 引用

2. 点击右侧的 **发送按钮**（或按 Enter 键）
3. 系统自动创建构建项目，页面跳转到 [构建进度](/using/build-progress) 页面
4. 8 个专业 Builder Agent 开始自动协作构建你的 Agent

::: tip 多模态输入
除了文字描述，你还可以在创建时上传附件（PDF、Excel、图片等）来补充需求说明。附件能帮助 AI 更准确地理解你的数据格式和业务场景。
:::

### 快捷模板

输入框下方提供快捷模板，点击即可一键启动构建：

| 模板 | 用途 | 说明 |
|------|------|------|
| **医学文献** | 创建医学文献研究助手 | 集成 PubMed API，支持论文搜索、PDF 解析、引用生成 |
| **AWS 报价** | 创建 AWS 服务报价顾问 | 集成 AWS Pricing MCP 服务器，支持服务推荐和费用估算 |
| **新闻简报** | 创建每日新闻摘要 Agent | 支持多源新闻采集、摘要生成、分类整理 |

::: info
快捷模板的需求描述是预设的，会直接触发快速创建流程。如果你想自定义需求描述或使用引导创建模式，请使用 [创建 Agent](/using/create-agent) 页面。
:::

### 需求描述最佳实践

在快速构建区域输入需求时，以下技巧能帮你获得更好的结果：

**推荐写法 — 具体、结构化：**

> 创建一个数据分析 Agent，能够：
> 1. 读取上传的 CSV 和 Excel 文件
> 2. 自动识别数据类型和缺失值
> 3. 生成数据摘要报告（包含均值、中位数、分布等）
> 4. 根据用户问题进行数据查询和筛选
> 5. 用中文回复

**不推荐写法 — 过于简单：**

> 帮我做个分析数据的东西

好的需求描述应包含：**Agent 做什么**、**处理什么数据**、**输出什么结果**、**有什么特殊要求**。

## 数据概览

工作台中间区域显示 **4 张统计卡片**，让你一目了然地掌握平台状态：

| 指标 | 说明 | 意义 |
|------|------|------|
| **运行中 Agent** | 当前处于运行状态的 Agent 数 / Agent 总数 | 了解有多少 Agent 可供使用。如果数值为 0，说明还没有可用的 Agent |
| **构建中项目** | 正在进行中的构建任务数量 | 了解当前后台有多少构建正在进行。如果有多个，说明系统正在并行处理 |
| **今日业务处理** | 今天所有 Agent 累计处理的业务请求次数 | 反映 Agent 的日活跃度。数值越高说明使用越频繁 |
| **构建成功率** | 历史构建任务的成功百分比 | 反映整体构建质量。正常情况下应维持在较高水平 |

### 如何理解这些指标

- **运行中 Agent 数为 0** — 你还没有创建 Agent，或者已创建的 Agent 都处于离线状态
- **构建成功率低于预期** — 可能是需求描述不够清晰，建议使用引导创建模式让 AI 帮你完善需求
- **今日业务处理量高** — 说明 Agent 使用频繁，可以关注 Agent 的响应质量和性能
- **构建中项目数多** — 系统支持并行构建，多个项目同时进行不会互相影响

## 最近项目

展示你最近创建或更新的构建项目，方便快速跟踪进展：

| 字段 | 说明 |
|------|------|
| **项目名称** | 基于需求描述自动生成，点击可跳转到项目详情 |
| **构建进度** | 进度条展示完成百分比（0-100%） |
| **当前阶段** | 显示正在执行的 Builder Agent（如 agent_designer、tools_engineer 等） |
| **状态标签** | 构建中（蓝色）/ 已完成（绿色）/ 失败（红色）/ 已暂停（灰色） |
| **更新时间** | 最后一次状态变更的时间（如 "17天前"、"2小时前"） |

**快捷操作：**
- 点击项目名称 → 跳转到 [构建进度](/using/build-progress) 详情页
- 对于已完成的项目 → 可以直接跳转到关联的 Agent

## 运行中的 Agent

展示当前正在运行的 Agent，提供快速对话入口：

| 字段 | 说明 |
|------|------|
| **Agent 名称** | Agent 的名称 |
| **简要描述** | Agent 的功能简介 |
| **调用次数** | 累计被调用的次数 |
| **快捷操作** | 「对话」按钮 — 直接发起对话测试 |

::: tip 快速对话
这里是发起对话测试的最快方式。点击 Agent 卡片上的「对话」按钮，即可打开对话窗口开始交互。
:::

## 快捷操作入口

工作台还提供以下快捷入口：

| 操作 | 说明 |
|------|------|
| **创建 Agent** | 跳转到 [创建 Agent](/using/create-agent) 页面，使用完整的创建模式 |
| **查看全部项目** | 跳转到 [项目管理](/using/projects) 页面，查看所有构建项目 |
| **查看全部 Agent** | 跳转到 [Agent 管理](/using/manage-agents) 页面，管理所有 Agent |

## 使用技巧

1. **善用快捷模板** — 如果你不确定怎么描述需求，从模板开始是个好选择
2. **关注构建成功率** — 如果成功率较低，尝试使用引导创建模式来获得更精确的需求描述
3. **定期查看最近项目** — 构建过程可能需要几分钟，你可以先做其他事情，稍后回来查看进展
4. **利用快速对话** — 在"运行中的 Agent"区域可以最快速地测试 Agent
