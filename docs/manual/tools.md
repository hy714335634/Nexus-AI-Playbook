# 工具库

能力工具页面展示平台中所有已注册的工具。通过左侧导航栏的 **「能力工具」** 进入，默认显示 **「工具列表」** 标签页。

![工具库](/images/tools.png)

## 什么是工具

**工具（Tool）** 是 Agent 的能力扩展。如果说大语言模型是 Agent 的"大脑"，那么工具就是它的"手和脚"——让 Agent 能够与外部世界交互。

每个工具本质上是一个 **Python 函数**，Agent 在对话过程中会根据需要自动调用工具来完成任务。例如：

- 用户上传一个 CSV 文件 → Agent 调用 `file_read` 工具读取文件内容
- 用户问天气 → Agent 调用 `weather_api` 工具查询天气数据
- 用户要求计算 → Agent 调用 `calculator` 工具进行数学运算

**工具的重要性：** 没有工具的 Agent 只能做文字处理（回答问题、总结内容等）。有了工具，Agent 就能执行文件操作、调用 API、运行代码等实际操作。

- **工具总数** — 平台中所有可用工具的数量

## 工具类型详解

Nexus-AI 平台中的工具分为以下五种类型：

### 内置工具 (builtin)

平台出厂预置的基础工具，提供最常用的功能：

| 工具名称 | 功能 | 说明 |
|----------|------|------|
| **calculator** | 数学计算 | 支持各种数学表达式和统计计算 |
| **shell** | 执行命令 | 运行 Shell 命令，执行系统操作 |
| **file_read** | 读取文件 | 读取各种格式的文件内容 |
| **file_write** | 写入文件 | 创建或修改文件 |
| **editor** | 代码编辑 | 在线编辑代码文件 |
| **http_request** | HTTP 请求 | 调用外部 API 接口 |

这些工具是所有 Agent 的基础能力，无需额外开发即可使用。

### 模板工具 (template)

预置的 **功能模板**，提供更高级的能力：

| 模板类型 | 功能 | 适用场景 |
|----------|------|----------|
| **API 调用模板** | 标准化 REST API 调用 | 需要对接外部 API 的 Agent |
| **数据处理模板** | 数据清洗、转换、统计 | 数据分析类 Agent |
| **文件操作模板** | 多格式文件读写 | 需要处理多种文件的 Agent |

### 生成工具 (generated)

在构建 Agent 时由 **Tools Agent** 自动开发的定制工具。这些工具是针对你的需求量身定制的。

**示例：** 如果你要求构建"医学文献研究助手"，Tools Agent 会自动生成：
- `search_pubmed()` — 在 PubMed 搜索论文
- `parse_pdf()` — 解析 PDF 论文全文
- `format_citation()` — 按 APA 格式生成引用

生成工具是 Nexus-AI 的核心能力 —— 平台能自动根据你的需求开发出对应的工具函数。

### 系统工具 (system)

系统级基础工具，提供环境信息和系统操作：

| 工具名称 | 功能 |
|----------|------|
| **environment** | 获取系统环境信息 |
| **current_time** | 获取当前时间 |
| **cron** | 定时任务管理 |

### MCP 工具 (mcp)

通过 **MCP（Model Context Protocol）** 协议从外部 MCP 服务器集成的工具。这些工具由 MCP 服务器提供，无需在平台内开发。

**示例：**
- AWS Pricing MCP 服务器 → 提供 AWS 服务价格查询工具
- AWS Core MCP 服务器 → 提供 AWS 资源管理工具

MCP 工具的详细管理见 [MCP 服务器](/manual/mcp) 页面。

## 浏览工具

### 搜索

在页面顶部的搜索框中输入关键词，可以按 **工具名称** 或 **功能描述** 搜索。

### 筛选

页面提供两个下拉筛选器，可以组合使用：

| 筛选维度 | 可选项 | 说明 |
|----------|--------|------|
| **按类型** | 全部类型 / 内置 / 生成 / 系统 / 模板 / MCP | 按工具来源筛选 |
| **按分类** | 全部分类 / Agents & Workflows / File Operations / Shell & System / Utilities 等 | 按功能领域筛选 |

### 工具列表

左侧面板以列表形式展示所有工具，每个工具显示：
- **工具名称** — Python 函数名（如 `search_pubmed`）
- **功能描述** — 该工具做什么的简要说明
- **分类标签** — 所属功能分类

点击左侧列表中的工具，右侧面板会显示该工具的完整详情。

## 查看工具详情

选择一个工具后，右侧面板展示以下详细信息：

| 字段 | 说明 |
|------|------|
| **名称** | 工具函数名 |
| **类型** | builtin / generated / system / template / mcp |
| **描述** | 详细的功能说明 |
| **参数列表** | 每个参数的名称、数据类型、是否必填、说明 |
| **返回值** | 工具的返回值格式和说明 |
| **源代码** | Python 源代码（语法高亮显示） |
| **分类** | 所属功能分类 |
| **被引用** | 使用此工具的 Agent 列表 |

### 参数说明

工具的参数定义告诉你如何使用这个工具：

```python
# 示例：search_pubmed 工具的参数
参数:
  - query (string, 必填): 搜索关键词
  - max_results (integer, 可选): 最大返回数量，默认 10
  - sort_by (string, 可选): 排序方式，可选 "relevance" 或 "date"

返回值:
  - list: 论文列表，每个论文包含 title, authors, abstract, pmid 等字段
```

### 源代码查看

对于 **内置工具** 和 **生成工具**，你可以查看完整的 Python 源代码，了解工具的具体实现逻辑。

## 测试工具

工具详情页面提供 **在线测试** 功能，让你在将工具分配给 Agent 之前先验证它是否正常工作。

### 测试步骤

1. 在工具详情页中，查看工具的参数定义
2. 在 **参数输入表单** 中填写测试参数
3. 点击 **「执行」** 按钮
4. 查看工具的返回结果

### 测试示例

```
工具: calculator
参数: expression = "2 + 3 * 4"
结果: 14

工具: current_time
参数: timezone = "Asia/Shanghai"
结果: "2025-01-15T10:30:45+08:00"
```

::: tip 测试的价值
- **验证功能** — 确认工具能否正确执行
- **了解格式** — 了解工具的输入输出格式
- **排查问题** — 如果 Agent 的某个功能不正常，可以单独测试对应的工具来定位问题
:::

## 构建新工具

如果你需要独立构建新工具（不关联到特定的 Agent 构建），可以使用 **「构建工具」** 功能。

### 操作步骤

1. 点击页面右上角的 **「+ 构建工具」** 按钮
2. 在弹出的对话框中，用自然语言描述你需要的工具功能
3. 系统会自动生成工具的 Python 代码和文档
4. 新工具出现在工具列表中，可供所有 Agent 使用

### 描述示例

> "创建一个工具，可以调用天气 API 获取指定城市的实时天气信息，返回温度、湿度、风速和天气描述"

> "创建一个工具，可以读取 JSON 文件并按指定的 key 进行数据筛选和聚合"

> "创建一个工具，可以将 Markdown 格式的文本转换为 PDF 文件"

::: info
独立构建的工具存储在工具库中，可以被任何 Agent 引用和使用。当你创建新的 Agent 时，系统也会检查工具库中是否有可复用的工具。
:::

## 工具与 Agent 的关系

理解工具和 Agent 的关系有助于更好地使用平台：

```
Agent = 大脑（LLM + 提示词） + 手脚（工具）

用户对话 → Agent 理解意图 → 选择合适的工具 → 执行工具 → 返回结果

例如：
用户: "帮我分析这份 CSV 文件"
Agent: [理解] 用户想分析数据
       [选择] 调用 file_read 工具读取文件
       [选择] 调用 calculator 工具进行统计计算
       [组合] 将分析结果组织成报告
       [返回] 向用户展示分析报告
```

一个 Agent 可以使用多个工具，同一个工具也可以被多个 Agent 共享使用。
