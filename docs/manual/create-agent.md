# 创建 Agent

Nexus-AI 提供两种创建模式 —— **快速创建**和**引导创建**，适合不同场景的需求。点击左侧导航栏进入创建页面。

![创建 Agent](/images/create-agent.png)

## 创建模式对比

| | 快速创建 | 引导创建 |
|---|---------|---------|
| **适用场景** | 需求明确，知道 Agent 要做什么 | 需求模糊，只有初步想法 |
| **操作流程** | 输入描述 → 直接构建 | 输入描述 → AI 多轮提问 → 完善需求 → 构建 |
| **耗时** | 最快（直接进入构建） | 稍长（需要回答 AI 提问），但需求更精准 |
| **需求质量** | 取决于你的描述质量 | AI 帮你补全缺失信息，通常更完整 |
| **推荐人群** | 有经验的用户、需求明确时 | 初次使用、需求复杂、不确定细节时 |
| **多模态支持** | ✅ 支持上传附件 | ✅ 支持上传附件 |

::: tip 不确定选哪个？
如果你是第一次使用，或者对需求还没有完全想清楚，建议使用 **引导创建**。AI 的智能提问会帮你发现和补充你可能遗漏的需求细节。
:::

## 快速创建

选择 **「快速创建」** 标签后，进入以下界面：

![快速创建](/images/quick-create.png)

### 详细操作步骤

#### 步骤 1：选择模板（可选）

页面顶部提供 **4 个预置模板**，覆盖最常见的 Agent 类型。点击模板卡片会自动填充 Agent 名称和需求描述。

| 模板 | 预置能力 | 适用场景 |
|------|----------|----------|
| **数据分析 Agent** | 读取 CSV/Excel、统计分析、图表生成、数据摘要 | 定期处理数据报表、数据探索、商业分析 |
| **内容创作 Agent** | 文章撰写、文案优化、内容编辑、多语言翻译 | 营销内容生成、技术文档撰写、文案创作 |
| **市场调研 Agent** | 网络搜索、信息整理、竞品分析、报告生成 | 行业调研、竞品监控、市场趋势分析 |
| **技术开发 Agent** | 代码编写、代码审查、架构设计、文档生成 | 辅助开发、代码重构、技术方案评审 |

::: info
模板只是一个起点。你应该在模板基础上修改和补充描述，加入你的具体业务场景和要求。
:::

#### 步骤 2：填写 Agent 名称（可选）

在 **"Agent 名称"** 输入框中为你的 Agent 起一个名字。如果不填，系统会根据需求描述自动生成。

命名建议：
- 使用简洁、有意义的名称（如"医学文献助手"、"AWS 报价顾问"）
- 避免过于通用的名称（如"Agent1"、"测试"）

#### 步骤 3：描述详细需求

在 **"详细业务需求"** 文本框中，用自然语言详细描述你想要的 Agent。这是整个创建过程中最关键的输入。

**需求描述要素：**

| 要素 | 重要性 | 示例 |
|------|--------|------|
| **核心功能** | ⭐⭐⭐ 必写 | "能在 PubMed 搜索论文" |
| **数据/服务来源** | ⭐⭐⭐ 必写 | "连接 PubMed API" |
| **输入格式** | ⭐⭐ 建议 | "用户输入搜索关键词或上传 PDF" |
| **输出格式** | ⭐⭐ 建议 | "生成 APA 格式引用列表" |
| **语言要求** | ⭐ 可选 | "用中文回复" |
| **行为约束** | ⭐ 可选 | "不确定时明确告知，不编造引用" |

**完整需求示例：**

> 创建一个医学文献研究助手，具备以下能力：
>
> 1. 能在 PubMed 数据库上搜索指定主题的论文
> 2. 支持用户上传 PDF 论文，解析全文并提取摘要、结论和关键数据
> 3. 按照 APA 格式自动生成引用列表
> 4. 能根据多篇论文的内容，生成主题综述报告
> 5. 支持中英文对话
> 6. 遇到不确定的信息时明确告知用户，不编造引用

#### 步骤 4：上传附件（可选）

点击输入框旁的 **📎 附件按钮**，可以上传文件来补充说明需求：

| 文件格式 | 用途 | 最佳实践 |
|----------|------|----------|
| **PDF 文档** | 产品规范、业务流程文档 | 上传现有的业务文档，让 AI 理解你的业务背景 |
| **Excel / CSV** | 数据样本 | 上传一份示例数据，让 AI 理解你的数据结构和格式 |
| **图片** (JPG/PNG) | 参考设计、界面截图 | 上传期望的效果图或现有系统的截图 |
| **Word 文档** | 详细需求说明 | 如果需求很长，可以写在 Word 文档中上传 |

::: tip 附件的价值
上传附件能显著提升 Agent 的构建质量。例如，上传一份 CSV 数据样本，Agent 就能自动了解数据的列名、类型和格式，生成针对你实际数据的分析工具。
:::

#### 步骤 5：开始构建

确认所有信息无误后，点击 **「开始构建」** 按钮。系统会：

1. 创建一个新的构建项目
2. 自动跳转到 [构建进度](/manual/build-progress) 页面
3. 8 个 Builder Agent 开始按流水线协作构建
4. 你可以实时查看每个阶段的进展

### 构建提示

快速创建页面底部提供 **「构建提示」** 区域，帮助你写出更好的需求描述：

- 明确说明 Agent 的主要职责和工作场景
- 列出需要处理的具体业务任务
- 说明需要对接的数据源或系统
- 描述期望的输入输出格式和交互方式

## 引导创建

引导创建是 Nexus-AI 的特色功能，通过 AI 与你的多轮对话，帮助你把模糊的想法转化为精确的需求。这个过程由 **Requirements Agent** 驱动。

![引导创建](/images/guided-create.png)

### 详细操作步骤

#### 步骤 1：输入初始需求

选择 **「引导创建」** 标签后，在文本框中描述你的初步想法。不需要很详细，一两句话即可：

> 我想做一个帮助客服团队的 Agent

页面提示："*不需要描述得很详细，AI 会通过提问帮你补充细节*"

你也可以在这里上传附件辅助说明。

#### 步骤 2：AI 智能提问

系统的 **Requirements Agent** 会分析你的描述，然后提出一系列有针对性的问题。这些问题旨在帮你补全遗漏的需求细节。

**提问的方向通常包括：**

| 维度 | 典型问题示例 |
|------|-------------|
| **目标用户** | "谁会使用这个 Agent？内部员工还是外部客户？" |
| **核心功能** | "Agent 需要处理哪些类型的任务？" |
| **数据来源** | "Agent 需要访问哪些系统或数据库？" |
| **输入方式** | "用户会以什么方式提供信息？文字、文件、还是两者都有？" |
| **输出要求** | "你期望 Agent 以什么格式返回结果？" |
| **语言风格** | "Agent 的回复风格应该是什么样的？" |
| **异常处理** | "当 Agent 无法完成任务时，应该如何处理？" |

**回答技巧：**
- 回答可以简短也可以详细，AI 会自动判断信息是否充分
- 如果某个问题你暂时没想好，可以说"暂不确定"，AI 会根据最佳实践给出建议
- 你可以在回答中提出自己的问题，形成双向对话

#### 步骤 3：多轮对话完善

AI 可能会进行 **2-5 轮提问**，每一轮都会基于你的回答进一步深入。直到 AI 认为收集了足够完整的信息，就会进入下一步。

```
第 1 轮：了解基本需求和场景
  ↓
第 2 轮：明确功能细节和数据源
  ↓
第 3 轮：确认行为约束和异常处理
  ↓
（AI 认为信息充分）
  ↓
生成增强需求文档
```

#### 步骤 4：审核增强需求

当信息收集完毕后，AI 会生成一份 **增强需求文档**。这份文档将你的模糊想法转化为了结构化的、可执行的需求规格：

**增强需求文档包含：**
- **Agent 定位** — 名称、目标、使用场景
- **功能清单** — 按优先级排列的功能列表
- **输入输出规格** — 支持的输入格式和输出要求
- **工具和集成需求** — 需要开发或集成的工具
- **行为约束** — Agent 的行为边界和限制
- **语言和风格** — 回复语言、风格要求

#### 步骤 5：编辑并确认

你可以在文本编辑器中 **直接修改** 增强需求文档的内容：

- ✏️ **添加** — 补充遗漏的功能点或要求
- 🗑️ **删除** — 移除不需要的内容
- 🔄 **调整** — 修改优先级、措辞或参数
- ➕ **补充** — 加入更多业务细节

修改完成后，点击 **「确认并开始构建」**，进入自动构建流程。

## 两种创建模式的实际对比

### 同一需求的不同路径

假设你想创建一个"客户数据分析 Agent"：

**快速创建路径：**
```
你输入：
"创建一个客户数据分析 Agent，能读取 CRM 导出的 Excel 文件，
分析客户分布、购买行为、流失风险，生成分析报告。"

→ 直接开始构建（约 5-8 分钟完成）
```

**引导创建路径：**
```
你输入："我想做一个分析客户数据的 Agent"

AI 提问：
- "客户数据的来源和格式是什么？"
- "需要分析哪些维度？"
- "报告需要包含哪些内容？"
- "是否需要预测功能（如流失预测）？"

你逐一回答后，AI 生成增强需求：
- 读取 CRM 导出的 Excel 文件
- 分析维度：客户分布、购买行为、流失风险、RFM 模型
- 输出：数据摘要 + 分析图表 + 可执行建议
- 附加功能：流失预警评分

→ 确认后开始构建（约 8-12 分钟完成）
```

引导创建的 Agent 通常功能更完整（因为 AI 帮你发现了"流失预警评分"这个你可能没想到的功能），但耗时也稍长。

## 构建开始后

无论使用哪种创建模式，点击构建后会发生以下事情：

1. **项目创建** — 系统自动创建一个新的构建项目
2. **页面跳转** — 自动跳转到 [构建进度](/manual/build-progress) 页面
3. **流水线启动** — 8 个专业 Builder Agent 开始按序工作：
   - Orchestrator 分析需求并制定计划
   - Requirements Agent 将需求规格化
   - Architecture Agent 设计技术架构
   - Design Agent 定义行为逻辑
   - Prompt Agent 编写系统提示词
   - Tools Agent 开发所需工具
   - Developer Agent 编写 Agent 代码
   - DevManager Agent 审查代码质量
   - Agent Deployer 完成部署
4. **实时监控** — 你可以在构建进度页面实时查看每个阶段的执行状态
5. **构建完成** — 所有阶段完成后，Agent 立即可用，可以开始对话测试

::: info 构建期间
构建过程中你可以离开页面做其他事情。如果开启了通知设置，构建完成或失败时会收到通知。
:::
