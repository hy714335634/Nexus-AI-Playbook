# Getting Started

This chapter takes Nexus-AI from zero to running: in as little as five minutes you can open the local console and chat with the default agent, then — at your own pace — install the full dependency stack, prepare your AWS account, and understand how upgrades and uninstalls work.

If this is your first encounter with Nexus-AI, read the pages below in order. If you just want to see it in action, jump straight to "Quickstart".
