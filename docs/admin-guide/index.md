# 管理员手册

本手册面向负责部署、配置和运维 Nexus-AI 的管理员。从把平台装进自己的 AWS 账号，到调参数、管账号、控模型、看用量、查审计、盯服务状态——平台管理需要的操作都在这里。

大多数章节对应控制台里的一个管理页面，只有管理员可见。你可以按顺序通读，也可以直接跳到手头要做的那件事。

| 文档 | 简介 |
| --- | --- |
| [部署与升级](./deploy-upgrade) | 用命令行工具 `nexus-cli` 把 Nexus-AI 一键部署到自己的 AWS 账号，并在后续维护中升级计算节点而不动数据。 |
| [配置管理](./config-management) | 在一个界面里字段级调整平台运行参数，每项都标注改完是立即生效还是需要重启服务。 |
| [用户与权限](./users-permissions) | 创建和停用账号、组织部门树、以策略为准分配角色和细粒度权限。 |
| [资源组管理](./resource-group-admin) | 把多个资源打包成文件夹，按团队、项目或用途作为整体分享授权（界面里叫「共享资源」）。 |
| [审计追踪](./audit) | 检索防篡改的操作记录、导出留存、订阅通知，并让 AI 助手协助排查与出合规报告。 |
| [用量与计费](./billing) | 按模型、用户、项目、应用四个维度归因 Token 消耗，并为用户和应用设置配额。 |
| [服务状态监控](./service-status) | 掌握平台整体健康状况，对后端服务做重启 / 停止 / 启动并查看实时日志。 |
| [内置 AI 助手（管理员）](./helper-agents) | 用自然语言在各管理页面完成排障、配置、审计，改动操作先出「待确认提议」再生效。 |
| [模型目录与接入](./model-access) | 决定哪些模型对平台开放、划分档位、控制图片输入，并在保存前测试连通性。 |
| [MCP 服务管理](./mcp) | 登记外部 MCP 服务器，把它们提供的工具接入平台，供 Agent 在运行时调用。 |
| [登录与 SSO](./sso-auth) | 配置本地账号登录，或对接 SAML 2.0 身份提供商启用企业单点登录。 |
| [外部集成管理](./integrations-admin) | 登记并管理平台对接的外部系统，集中维护连接凭据与开关。 |
| [常见问题与排障](./faq-ops) | 汇总管理员常见问题与排查步骤，帮你快速定位并解决运维中的故障。 |
