# 外部集成管理

「业务集成」把平台和外部系统打通的能力集中到一处：接入数据源、集中保管访问凭证、管理可复用的模板资产与业务指示。作为管理员，你在这里为团队登记数据连接、维护密钥、控制谁能看到和使用它们。

页面提供四个子模块：

| 子模块 | 用途 | 当前示例数量 |
|--------|------|--------------|
| **资产模版** | 集中管理 PPT / Word / Excel / HTML / PDF 等可复用模板 | 0（暂无集合） |
| **数据连接** | 登记外部数据源（数据库、数据仓库、对象存储、向量库等） | 0（暂无连接） |
| **密钥管理** | 集中保管 API 密钥、数据库凭证等敏感凭证 | 2（已绑定） |
| **业务指示** | 维护面向 Agent 的全局业务指示节点 | 0（全局） |

## 打开业务集成

侧边栏「业务集成」→ 进入 `/integration`。页面顶部以四张卡片呈现上述子模块，点击任一卡片进入对应的管理页。

![integration-connectors](/images/integration-connectors.png)

## 数据连接

「数据连接」让你把外部数据源登记为**连接器**，绑定访问凭证后供 Agent 在运行时查询。平台对每类数据源都预置了安全默认值（只读、行数上限、危险语句拦截、字段脱敏），无需逐个连接手工加固。


### 支持的数据源类型

| 类别 | 数据源类型 |
|------|-----------|
| 关系型数据库 | MySQL、PostgreSQL |
| 数据仓库（OLAP 分析） | Amazon Redshift、Snowflake、Google BigQuery |
| 在线表格 | Google Sheets |
| 对象存储 | Amazon S3 |
| NoSQL | Amazon DynamoDB |
| HTTP 接口 | HTTP API |
| 向量检索 | Amazon OpenSearch Serverless、Amazon S3 Vectors、Bedrock Knowledge Base |

### 安全默认值

新建连接时，平台会套用一组全局默认参数。以下为查询类数据源最需要关注的几项：

| 项目 | 默认值 | 说明 |
|------|--------|------|
| 单次最大返回行数 | 1000 | 防止一次拉取过多数据 |
| 查询超时 | 30 秒 | 超时自动中断 |
| 写操作 | 关闭 | 默认只读，不允许写入 |
| DDL 操作 | 关闭 | 默认禁止建表 / 改表等结构变更 |
| 危险语句拦截 | `DROP`、`TRUNCATE`、`ALTER` | 命中黑名单关键字的查询会被拒绝 |

**字段脱敏**：查询结果中列名命中以下规则时会自动遮盖，避免敏感值外泄。

| 列名匹配 | 脱敏策略 |
|----------|----------|
| `*password*` | 替换（replace） |
| `*secret*` | 替换（replace） |
| `*token*` | 部分遮盖（partial） |

> 可用的脱敏策略有四种：部分遮盖（partial）、哈希（hash）、整体替换（replace）、置空（null）。

其他默认值：关系型数据库使用连接池（默认 5 个连接、最多溢出 10 个、获取超时 30 秒、每 3600 秒回收）；S3 单文件最大读取 100MB，支持 CSV / JSON / JSONL / Parquet / TXT / XLSX / YAML，预签名下载链接有效期 1 小时；HTTP API 请求超时 30 秒、最多重试 3 次、响应体最大 10MB；向量检索默认返回 Top-10、相似度阈值 0.7。数据连接的审计日志默认开启并保留 90 天。

### 添加数据连接

1. 在「数据连接」页右上角点新增按钮，打开连接器创建表单。
2. 填写连接器**名称**、选择**数据源类型**，并填入该类型所需的连接参数（如数据库主机 / 端口 / 库名、S3 桶与前缀、HTTP Base URL 等）。
3. 在**认证**处绑定一个已保管的密钥（见下文「密钥管理」），或按提示新建凭证。
4. 设置访问控制（可见性），保存。

保存后可用**搜索连接器**框（占位符「搜索连接器...」）按名称检索。

### 测试连接与查看结构

连接建好后，建议先验证再交给 Agent 使用：

- **测试连接** — 尝试实际连上数据源，返回成功或具体错误信息。启用前先测一遍，避免 Agent 运行时才发现连不上。
- **查看结构（Schema）** — 拉取数据源的表 / 字段（S3 为文件列表，向量库为索引列表），确认凭证权限和可见范围符合预期。

### 父子连接器

对 S3 这类有层级结构的数据源，可以在一个父连接器下按子路径建立**子连接器**，把不同目录 / 前缀拆成独立的可授权单元。父连接器的「子连接器」入口可查看其下所有子连接。

### 可见性与权限

数据连接受资源权限约束：

- **管理员**可查看并管理全平台的所有连接器，用于统一治理。
- **普通用户**只能看到自己创建的、共享给全员的，以及通过分享或资源组授权可见的连接器。
- 连接器可**分享**给指定用户或资源组；删除连接器时，其所有分享记录会一并清除。

::: info
创建连接器时，归属人强制取当前登录身份，无法伪造为他人。查看 / 使用连接需要相应的查看权限，修改 / 删除则需要拥有者或编辑权限。
:::

## 密钥管理

「密钥管理」集中保管接入外部系统所需的敏感凭证（API 密钥、数据库账号密码、云凭证等）。密钥登记一次，即可被数据连接和需要凭证的工具**引用**，无需在多处重复填写明文。

![integration-keys](/images/integration-keys.png)

页面右上角为**新建密钥**，列表中每张密钥卡片显示：名称、类型、被引用次数、描述片段；顶部**搜索密钥**框（占位符「搜索密钥...」）按名称检索。

### 密钥类型

平台预置了以下标准密钥类型，新建时按类型自动展示对应字段：

| 类型 | 用途 | 主要字段 |
|------|------|----------|
| **API 密钥** | 第三方 API 的访问密钥 | API Key |
| **数据库凭证** | MySQL / PostgreSQL 等关系型数据库连接 | 主机、端口、数据库名、用户名、密码 |
| **Bearer Token** | OAuth / Bearer Token 认证 | Token |
| **AWS 凭证** | AWS Access Key / Secret Key 认证 | Access Key ID、Secret Access Key、Session Token（可选） |
| **GCP 服务账号** | Google Cloud 服务账号（用于 BigQuery / Google Sheets） | 服务账号 JSON |
| **OAuth 2.0** | OAuth 2.0 客户端凭证认证 | Client ID、Client Secret、Token 端点（可选） |
| **自定义密钥** | 结构不固定的凭证 | 由你动态添加字段 |

### 新建密钥

1. 点右上角**新建密钥**。
2. 选择密钥**类型**，填入该类型要求的字段（密码类字段以掩码输入）。
3. 填写密钥**名称**与**描述**。
4. 设置**可见性**：私有（private）/ 共享（shared）/ 公开（public）。
5. 如需让某个工具自动使用该密钥，可在此绑定对应的工具。
6. 保存。

::: warning
密钥值在保存后即被加密保管，界面不再回显明文。列表和详情只展示元数据（名称、类型、描述、引用次数），不会返回密钥本身。如需更换凭证，编辑密钥重新填入即可。
:::

### 可见性与共享

- **私有** — 只有创建者本人可见可用。
- **共享 / 公开** — 按可见性范围让其他成员只读引用；只读者（viewer）仅能使用，不能修改。
- 修改、删除、再分享等写操作需要编辑（editor）或拥有者（owner）权限。
- **管理员**可查看全平台所有密钥用于治理。

### 密钥与工具绑定

有些工具运行时需要外部凭证。可在密钥的绑定项里关联需要密钥的工具，工具调用时便自动使用该密钥——无需把明文写进工具配置。密钥卡片上的「引用次数」即反映当前有多少处在使用它。

### 密钥存储与安全

密钥默认存储在 AWS Secrets Manager（密钥名带统一前缀 `nexus-ai/keys/`），支持指定区域与自定义 KMS 密钥加密。仅在开发环境才可切换为本地存储。

::: warning
密钥等同访问凭证。生产环境务必使用 Secrets Manager 存储；删除密钥前先确认没有连接器或工具仍在引用它（看「引用次数」），以免引用方运行时失败。
:::

## 资产模版

「资产模版」集中管理可复用的模板文件（PPT / Word / Excel / HTML / PDF、图片等），供生成类任务套用。左侧可按归属（全部 / 我创建的 / 共享给我）和类别（PPT / Excel / 文档 / HTML / 其他）过滤，中央为拖拽上传区（**选择文件** / **选择文件夹**），右上角**✨ AI** 按钮可借助 AI 辅助生成或整理模板。

## 业务指示

「业务指示」维护面向 Agent 的全局业务指示节点。右上角提供**新建节点**、**自然语言创建架构**、**从文档导入**、**刷新**；右下角浮动按钮提供**手动创建**与**AI 智能创建**——用自然语言描述需求即可让 AI 帮你搭建指示结构。

## MCP 服务

外部工具服务器（MCP）的接入与管理是独立的一块能力，入口在侧边栏「能力中心」→「MCP 服务」，详见《MCP 服务管理》。它同样属于外部集成范畴，但登记、启用、测试连接的操作都在能力中心完成，不在本页。

## 注意事项

- 数据连接默认**只读**并拦截 `DROP` / `TRUNCATE` / `ALTER` 等危险语句；如确需放开写权限，务必评估影响后再逐个连接调整。
- 命中脱敏规则的字段（含 `password` / `secret` / `token`）会自动遮盖，排查数据问题时留意这一点。
- 密钥保存后不回显明文，且删除不可撤销；删除前先看「引用次数」确认无人引用。
- 数据连接的审计日志默认保留 90 天，可用于追溯谁在何时查询了哪个数据源。
- 启用新连接前先「测试连接」，避免 Agent 运行时才暴露不可达或凭证错误的问题。
