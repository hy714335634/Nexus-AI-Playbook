# 配置管理

配置管理页让你在一个界面里字段级地调整整个平台的运行参数——模型、对话策略、附件限制、可观测性、消息队列等。每一项都标注了**改完是立即生效还是需要重启服务**，改动先进草稿、确认后统一保存，需重启的项还能一键重启。

::: info
配置以「数据库优先、文件兜底」的方式存储：在本页做的修改保存到平台数据库，不会覆盖服务器上的配置文件。
:::

### 典型场景：切换平台默认模型

> 团队刚获得一款新模型的访问权限，你希望全平台默认使用它。
>
> 1. 打开侧边栏「设置」→「配置管理」。
> 2. 点分类标签「AI 与模型」。
> 3. 找到「标准模型」参数，在下拉框里选择新模型。
> 4. 点「保存」——该项标注为 🟢 热加载，保存即生效。
> 5. 一分钟内，所有用户的新对话都将使用新模型——无需登录服务器、无需编辑配置文件、无需重启任何服务。
>
> 这就是 Web 端配置热加载的核心价值：模型、策略等高频参数的调整在浏览器里完成，实时生效，零停机。

## 打开配置管理

侧边栏「设置」→「配置管理」，或直接访问 `/settings/config`。

页面顶部提供三个相关入口的快捷链接：

- **分享管理** — 文件分享策略与投递通道
- **模型目录** — 编辑可选模型列表（测试后保存立即生效）
- **浏览器扩展** — 管理 Chrome 扩展设备

![settings-config](/images/settings-config.png)

## 界面速览

配置项数量较多（当前约 132 项），页面用两层过滤帮你快速定位：

1. **分类标签**（顶部）：按大类切换，每个标签带数量徽标。
   - 全部
   - AI 与模型
   - 内容与协作
   - 运行与部署
   - 可观测与日志
   - 其他
2. **状态筛选**（分类下方）：
   - 全部
   - 已改
   - 热加载
   - 需重启

每个配置项以卡片形式呈现，包含：中文标签、说明、当前值控件（开关 / 数字 / 下拉 / 模型选择 / 文本），以及一个**生效方式徽标**。

### 生效方式徽标

| 徽标 | 含义 | 保存后 |
|------|------|--------|
| 🟢 **热加载** | 下次读取即生效 | 无需重启，新会话 / 新调用立即采用 |
| 🟠 **需重启** | 需重启受影响服务才生效 | 保存后需重启 `api` 和/或 `worker` |

::: tip
只想看哪些改动需要重启，点状态筛选里的「需重启」即可只显示这类参数。
:::

## 配置分组一览

分类标签把底层分组聚成四大类，便于按目标查找：

| 分类 | 覆盖内容 |
|------|----------|
| **AI 与模型** | 标准 / 轻量 / 高级模型、Prompt 缓存、对话管理策略、多模态解析、向量检索与重排序 |
| **内容与协作** | 附件大小与 URL 有效期、模板 AI 分析、分享与备份策略 |
| **运行与部署** | AgentCore 部署、工作流、运行时重试、消息队列、服务运行时、沙箱环境 |
| **可观测与日志** | 追踪采样率、数据捕获粒度、日志级别、审计与运维告警 |
| **其他** | 未归入上述大类的配置分组 |


## 修改与保存配置

1. 找到目标参数（用分类标签、状态筛选或搜索框，见下文「配置助手」）。
2. 直接在字段控件上修改值。改动后该字段进入「待保存」状态，可用状态筛选里的「已改」集中查看。
3. 点「保存」。
   - 若本次改动**全是热加载项**：直接保存，提示保存成功，立即生效。
   - 若含**需重启项**：弹出确认窗，逐项列出改动内容与受影响服务；可在窗内勾选「保存后自动重启」。
4. 确认保存。若选择了自动重启，平台会保存后自动重启受影响服务；否则保存后会给出「立即重启」的操作按钮，可稍后手动触发。

::: warning
重启 `api` 服务时会有短暂不可用——平台会异步排程重启并自动轮询恢复，恢复后给出提示。建议在业务低峰期操作需重启的改动。
:::

::: tip
改错了想撤销？把值改回原样，该字段会自动退出「待保存」状态（精确追踪，与原值一致即视为未改动）。
:::

## 敏感配置项

密钥、凭证类参数（如管理员密码）标记为敏感项：

- 在界面上**脱敏只读**，只显示「已设置 / 未设置」，不回显明文。
- 这类值**绝不写入数据库**，仅来自配置文件或环境变量。

::: warning
敏感项无法在本页直接改值。需要变更时请通过服务器上的配置文件或环境变量处理，并按提示重启相关服务。
:::

## 历史版本与回滚

每个配置项卡片上有「历史版本」按钮，可查看该参数的历史改动记录并回滚到此前的某个值。回滚同样走正常保存流程——若该项需重启，回滚后同样需要重启才生效。

## 配置体检

顶部「配置体检」按钮会扫描当前配置，列出潜在问题（如取值不合理、相互冲突或有更优推荐）。每条结果可「定位参数」直接跳到对应字段。体检结果会缓存，重开面板不会重复扫描，除非手动重扫。


## 导出与导入

- **导出**：点「导出」下载当前配置快照（JSON 文件，文件名带时间戳），可用于备份或迁移到另一套环境。
- **导入**：点「导入」选择快照文件。平台会**先做 dry-run 预览**，列出将发生的改动数量与受影响服务，确认后才真正写入。

::: tip
导入前建议先「导出」一份当前配置作为回滚点。
:::

## 配置助手（Config Helper）

配置页内置 AI 助手，帮你用自然语言找参数、理解某项作用、评估调整影响。

### 用自然语言找参数

页面「想调什么，直接说」区提供一个自然语言搜索框（语义匹配，不只是关键字）。

1. 在输入框描述目标，例如「降低成本」「对话总丢上下文」。
2. 点「AI 搜索」。命中的参数会被过滤并高亮显示。
3. 也可直接点预置的建议查询：**降低使用成本**、**对话总丢上下文**、**哪些改了要重启**。

::: info
搜索可能返回零命中（例如问的参数不在可管理范围内，会提示「AI 命中 0 个相关的参数」）。此时换个说法或关键词再试。
:::

### 字段级 AI 解释

每个配置项卡片上有「问 AI：作用与调整影响」按钮，点它会打开助手并就该参数自动提问——用于快速理解「这项是干嘛的、调大调小会怎样」。助手给出的建议可一键写入草稿（沿用正常保存流程），也可随时还原。

### 助手面板

点浮动「Nexus 助手」按钮打开助手面板，可切换「右侧停靠 / 居中大窗」两种形态。面板给出常见问题建议，例如：

- 我想降低使用成本
- 对话经常丢失上下文怎么办
- prompt 缓存是干嘛的，建议开吗
- 哪些参数改了需要重启服务


::: warning
助手只做解释、搜索和写入草稿建议，**不会替你保存或重启**。所有改动仍需你在主界面点「保存」并确认。
:::

## 常用配置项速查

以下是较常调整的参数及其生效方式（并非全部，完整列表以页面为准）。

### AI 与模型

| 配置项 | 作用 | 生效方式 |
|--------|------|----------|
| 标准模型 | 默认对话 / 构建所用模型 | 🟢 热加载 |
| 轻量模型 | 低成本任务（分类、摘要、快速判断） | 🟢 热加载 |
| 高级模型 | 复杂推理 / 多模态主模型 | 🟢 热加载 |
| 启用 Prompt 缓存 | 缓存 system prompt / 工具定义，降低 input token 成本 | 🟢 热加载 |
| Bedrock 读取超时(秒) | 长响应需要更大值 | 🟠 需重启（api、worker） |
| 启用对话管理 | 长对话自动滑窗 / 摘要，控制上下文长度 | 🟢 热加载 |
| 管理策略 | 滑窗（保留最近 N 条）或摘要（压缩旧消息） | 🟢 热加载 |
| 主动压缩阈值 | 上下文用量达此比例时主动压缩 | 🟢 热加载 |
| Embedding 模型 | 向量检索所用嵌入模型 | 🟠 需重启（改后需重建索引才完全生效） |

### 内容与协作

| 配置项 | 作用 | 生效方式 |
|--------|------|----------|
| 附件大小上限(字节) | 单个附件最大字节数（默认 50MB） | 🟢 热加载 |
| 下载 / 上传 URL 有效期(秒) | 预签名链接有效期 | 🟢 热加载 |
| 模板 AI 分析 | 上传模板时自动用 AI 解析 / 向量化 | 🟢 热加载 |
| 备份分享模式 / 有效期 | 备份分享的方式与默认 / 最大有效期 | 🟢 热加载 |

### 运行与部署

| 配置项 | 作用 | 生效方式 |
|--------|------|----------|
| 部署 dry-run | 只演练不真正部署，用于调试 | 🟠 需重启（api、worker） |
| 部署后自动测试 | 部署完成后自动跑测试 | 🟠 需重启（api、worker） |
| 启用重试 / 最大重试次数 | Agent 运行时重试策略 | 🟢 热加载 |
| 构建消息可见性超时(秒) | 应 ≥ 单次构建最长耗时，否则消息会被重复消费 | 🟠 需重启（worker） |
| 最大重试次数 / 消息保留天数 | 队列重试与保留策略 | 🟠 需重启（worker） |

### 可观测与日志

| 配置项 | 作用 | 生效方式 |
|--------|------|----------|
| 启用可观测性 | 追踪 / 指标 / 日志总开关 | 🟠 需重启（api、worker） |
| 生产 / 开发采样率 | 采样比例（0.1 = 采样 10%） | 🟠 需重启（api、worker） |
| 工具入参捕获粒度 | none / hash_only / redacted_preview（合规场景建议 hash_only 或 none） | 🟠 需重启（api、worker） |
| 日志级别 | DEBUG / INFO / WARNING / ERROR / CRITICAL | 🟢 热加载 |

### 敏感项

| 配置项 | 作用 | 生效方式 |
|--------|------|----------|
| 管理员密码 | 脱敏只读，仅文件 / 环境变量，绝不写入数据库 | 🟠 需重启（api） |

## 注意事项

- 需重启的改动尽量集中在业务低峰期一次做完，减少服务中断次数。
- 导入配置前先导出一份当前快照作为回滚点。
- 敏感项不在本页改值，走配置文件 / 环境变量。
- 拿不准某项作用或影响，先用字段上的「问 AI」按钮问配置助手，再决定是否改。
