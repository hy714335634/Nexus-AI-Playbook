# 用户与权限

用户管理页让你在一个界面里管理平台的所有账号、分组（部门）和权限策略——创建和停用用户、分配角色、把用户组织进部门树、以及定义细粒度的自定义权限。权限以「策略」为准，角色只是策略的一层简称。

::: info
用户管理仅对**管理员**开放。非管理员打开此页会看到「无权访问」占位；basic 版下该页整体不可用。
:::

## 打开用户管理

侧边栏「用户管理」，或直接访问 `/users`。

页面分为两个标签：

- **用户列表** — 管理用户、部门（分组）、给用户分配角色与策略（默认打开）
- **策略管理** — 查看托管策略、创建和维护自定义权限策略

![users](/images/users.png)

## 角色与权限模型

平台的权限来自**策略（Policy）**。每个用户绑定一条或多条策略，角色（管理员 / 编辑者 / 观察者）由所绑定的策略自动推导——你选「角色」，系统在背后落成对应的托管策略。

系统内置四条**托管策略**，覆盖大多数场景，不可编辑或删除：

| 策略 | 角色 | 能做什么 | 权限数量 |
|------|------|----------|----------|
| **AdministratorAccess** | 管理员 | 完全管理权限，可操作所有资源和用户 | 49 |
| **EditorAccess** | 编辑者 | 创建和编辑 Agent、项目、工具等资源 | 43 |
| **UserAccess** | 使用者 | 使用 Agent 对话、查看已有资源 | 25 |
| **ViewerAccess** | 观察者 | 只读查看所有资源，不可编辑或交互 | 18 |

权限本身是「资源 + 操作」的组合。可管理的资源与操作如下：

| 资源 | 可用操作 |
|------|----------|
| Agent | 列表、读取、创建、更新、删除、调用、对话 |
| 项目 / 工具 / 技能 / 事件任务 / 连接器 / 指令 | 列表、读取、创建、更新、删除 |
| 会话 | 列表、读取、创建、删除 |
| 配置 | 读取、更新 |
| 统计 | 读取 |
| 用户 | 列表、读取、创建、更新、删除 |

## 用户列表标签

用户列表标签把用户按**部门（分组）**组织成一棵树，顶部有搜索框（「搜索用户...」）和两个主操作：「添加部门」和「创建用户」。开箱即有两个默认分组：**Default**（所有用户的默认组）和 **SystemAdmin**（系统管理员组）。

### 创建用户

1. 点右上角「创建用户」。
2. 填写字段：
   - **用户名**（显示名称，必填）
   - **邮箱**（必填，须唯一）
   - **密码**（必填，至少 4 个字符，可点眼睛图标切换明文）
   - **角色**：四选一卡片——**Admin**（完全管理权限）、**Editor**（创建和编辑资源）、**User**（使用 Agent 和查看）、**Viewer**（只读查看）
3. 点「创建」。


::: warning
邮箱已被注册会报错。basic 版对用户总数有上限，达到上限时创建会弹出升级提示并附联系方式，需升级后才能继续添加。
:::

### 编辑用户资料

在用户行的操作里选编辑，可修改**用户名**和**邮箱**（邮箱同样须唯一）。

### 重置密码

管理员可为用户直接设置新密码，无需知道旧密码：在用户操作里选「重置密码」，输入新密码（至少 4 个字符）后确认。

::: warning
无法重置 SSO（SAML）用户的密码——这类账号的密码由你的身份提供商管理，请到 IdP 侧处理。
:::

### 修改角色与权限策略

打开用户的「权限策略」对话框：

- **角色**（单选）：选一条托管策略作为主角色，会替换当前角色。
- **自定义策略**（多选）：在主角色之外附加自定义策略，给该用户额外权限。

保存后，用户的角色会自动与所选策略保持一致。

::: tip
右侧面板会实时预览所选策略包含的资源与操作，分配前可先核对。
:::

### 启用 / 禁用用户

在用户操作里切换状态。被禁用的用户无法登录，但账号与资源保留，可随时重新启用。

### 删除用户

删除用户时，其名下的资源会**转移给另一位用户**（默认转移给当前管理员，也可指定目标用户）。删除不可撤销。

::: warning
你不能修改自己的角色或状态，也不能删除自己——这是为了避免管理员把自己锁在门外。
:::

## 部门（分组）管理

分组把用户按组织结构组织成树，并可按组分配策略，便于批量管理权限。

### 创建 / 编辑分组

1. 点「添加部门」（或在分组卡片右上角菜单选「编辑分组」）。
2. 填写：
   - **分组名称**（必填，例如「工程团队」）
   - **描述**（可选）
   - **上级分组**（下拉，选「无（顶级分组）」建顶级组，或选一个已有组作为父级）
3. 点「创建」或「保存」。


### 分组策略

在分组卡片右上角菜单选「分组策略」，可为整个分组勾选策略，组内成员据此获得相应权限。

### 移动用户

把用户移动到其他分组：在用户操作里选移动，从「目标分组」下拉选目标（选「未分组」则移出所有分组）。

::: tip
移动用户会改变其权限可见范围，生效可能有短暂延迟（缓存刷新）。若刚移动完权限看起来没更新，稍等片刻再看。
:::

### 删除分组

在分组卡片右上角菜单选「删除分组」。

## 策略管理标签

策略管理标签集中查看和维护所有权限策略，顶部有搜索框（「策略名称」）和「创建策略」按钮。策略分两类：

- **托管策略** — 系统内置四条（见上文），标注「系统内置，不可编辑」，只能查看。
- **自定义策略** — 管理员自行创建，可编辑和删除。

点任意策略卡片可展开查看其权限矩阵。


### 创建自定义策略

1. 点「创建策略」。
2. 填写**策略名称**（不能与托管策略重名）和**描述**（可选）。
3. 在**权限矩阵**里勾选：每行是一个资源，每列是一个操作，打勾即授予该「资源 + 操作」权限。灰色格子表示该资源不支持此操作。每行末尾有「全选行」快速勾选整行。
4. 底部实时显示已选权限数。点「创建」保存。


### 编辑 / 删除自定义策略

在自定义策略卡片上编辑或删除。删除前会二次确认，且不可撤销。托管策略不可编辑或删除。

### 给用户附加自定义策略

自定义策略创建后，可在用户的「权限策略」对话框里作为附加策略勾选给具体用户（见上文「修改角色与权限策略」）。

## 用户自助

普通用户无需管理员即可管理自己的账号：

- **个人资料** — 查看和更新自己的用户名、邮箱。
- **修改密码** — 输入当前密码与新密码（至少 4 个字符）即可自助修改。SSO 用户请通过身份提供商修改。

## 注意事项

- 权限以策略为准，角色是策略的简称；改角色会重置为对应托管策略，改策略会同步角色。
- 你不能改自己的角色 / 状态，也不能删除自己。
- 无法重置或修改 SSO（SAML）用户的密码，走身份提供商。
- 删除用户前先想清楚资源转移目标，删除不可撤销。
- basic 版有用户数上限，超限需升级。
- 移动用户或调整分组后，权限生效可能有短暂延迟。
