# 资源组管理

资源组是把多个资源（Agent、技能、项目、工具等）打包进一个「文件夹」，再作为整体分享给某个用户或部门的功能。相比逐个分享单个资源，资源组让你按团队、项目或用途集中授权：加进文件夹的资源随文件夹一起共享，权限也在文件夹这一层统一管理。界面里这个功能叫「共享资源」。

::: info
资源组对所有用户开放，每个人都能建自己的文件夹。作为**管理员**，你能看到并管理平台上**所有**资源组；普通用户只能看到自己创建的，以及别人分享给他的。
:::

## 打开共享资源

侧边栏「共享资源」，或直接访问 `/resource-groups`。

页面顶部是概览条（文件夹总数、资源总数、已共享数）和权限说明，下面把文件夹分成两组：

- **我创建的** — 你自己建的文件夹
- **共享给我的** — 别人分享给你的文件夹

每张卡片显示文件夹名、资源数、成员数，以及一枚标记：**已共享**（有其他成员）或**私有**（只有创建者）。顶部还有搜索框和排序（最近 / 名称 / 资源数 / 成员数）。

## 权限与资源类型

分享文件夹时，每个被授权的用户或部门会拿到一个权限级别：

| 权限 | 能做什么 |
|------|----------|
| **观察者（viewer）** | 查看文件夹及其中资源 |
| **编辑者（editor）** | 在查看之外，可增删和调整文件夹内的资源 |
| **所有者（owner）** | 完全控制，含管理其他成员的权限 |

文件夹里可以放这些类型的资源：

| 类型 | 说明 |
|------|------|
| Agent、技能、项目、工具 | 平台的核心可分享资源 |
| 连接器、指令、密钥、MCP 服务、模板 | 其余可分享资源类型 |

::: warning
**应用（App）不支持加入共享资源组**——即便是管理员也不行。应用始终归其所有者私有。
:::

## 新建文件夹

1. 点右上角「新建文件夹」（空状态时是「创建第一个文件夹」）。
2. 填写：
   - **名称**（必填，最长 255 字）
   - **描述**（可选，最长 500 字）
3. 点「创建」。

创建后你自动成为该文件夹的**所有者**。

## 管理文件夹内的资源

点任意文件夹卡片进入详情页。资源按**类型**分成标签页（Agent、技能、项目……），每个标签上标着该类型的数量。

- **搜索** — 顶部搜索框跨所有类型过滤，命中哪些类型就只显示哪些标签。
- **排序** — 手动 / 名称 / 类型 / 添加时间。
- **拖拽排序** — 选「手动」排序、未在搜索、且当前标签资源不超过 40 个时，可拖动卡片调整顺序；超过或开启搜索时自动降级为按规则排序（页面顶部有提示）。

### 添加资源

只能把**你自己创建的**资源加入文件夹（管理员不受此限，可添加任意资源）。加入的资源随文件夹一起被共享。

### 移除资源

在资源卡片右上角点移除按钮（`✕`），把资源移出文件夹。移除只是解除关联，不会删除资源本身。

::: tip
如果文件夹里某个资源在别处被删除了，平台会在你下次打开文件夹时自动清掉这条失效项，无需手动处理。
:::

## 分享文件夹

1. 在文件夹详情页点右上角「分享」。
2. 在选人框里搜索目标——可按用户名 / 邮箱找**用户**，或按名称找**部门（用户组）**；也可在树形结构里按部门层级浏览、直接选中整个部门。
3. 选权限级别（观察者 / 编辑者 / 所有者）。
4. 确认授予。

被授权者随即能在自己的「共享给我的」里看到这个文件夹。要撤销，在访问列表里对应成员上点移除按钮即可。

<!-- SCREENSHOT: resource-groups-share -->

::: info
访问列表（谁有权限）**只有文件夹的所有者和管理员看得到**。被分享的普通用户只能看到文件夹里的资源，看不到还有谁被授权——这是刻意的隐私保护。
:::

::: warning
- 只有文件夹的**创建者或管理员**能分享和撤销权限。
- 归属某个部门的文件夹，只有其创建者或管理员可分享。
- **所有者**权限无法通过撤销按钮移除，避免文件夹意外失去归属。
:::

## 删除文件夹

在文件夹卡片上（或详情页）删除。只有**创建者或管理员**能删除，删除前会二次确认，且不可撤销。删除文件夹只解除资源与文件夹的关联，不会删除其中的资源。

## 管理员视角

作为管理员，你在资源组上拥有全局权限：

- **看得到所有文件夹** — 不论归属，平台上每个资源组都在你的列表里。
- **能管理任意文件夹** — 向任意文件夹增删资源、分享、撤销、删除，都不受「只能操作自己资源」的限制。
- **审阅共享面** — 你能看到每个文件夹的完整访问列表，核对谁被授予了什么权限。

## 注意事项

- 权限在文件夹层统一管理：改文件夹的分享，即改其中所有资源对被授权者的可见性。
- 普通用户只能把自己创建的资源加入文件夹；管理员不受此限。
- 应用（App）不能加入共享资源组。
- 访问列表仅所有者和管理员可见，被分享者看不到其他成员。
- 所有者权限不可通过撤销按钮移除。
- 删除文件夹或移除资源都只解除关联，不删除资源本身；删除文件夹不可撤销。
