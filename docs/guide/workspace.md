# 认识工作台

登录成功后，你将看到 Nexus-AI 的工作台（Dashboard）。这是你使用平台的起点和控制中心，提供全局概览和快捷操作入口。

![工作台概览](/images/dashboard.png)

## 页面整体布局

工作台采用经典的三栏布局：

```
┌──────────┬───────────────────────────────────┐
│          │          快速构建区域               │
│   左侧   ├───────────────────────────────────┤
│   导航栏  │          数据概览卡片               │
│          ├───────────────────────────────────┤
│          │  最近项目          运行中的 Agent    │
│          │                                    │
└──────────┴───────────────────────────────────┘
```

## 左侧导航栏

左侧是全局导航菜单，它是你在平台中导航的主要方式。不管你在哪个页面，都可以通过左侧导航栏快速切换到其他功能模块。

### 导航菜单说明

| 菜单项 | 图标 | 功能 | 详细说明 |
|--------|------|------|----------|
| **工作台** | 🏠 | 回到主页 | 查看概览信息和快速创建入口 |
| **Agents** | 🤖 | Agent 管理 | 查看所有已构建的 Agent，包括运行状态、配置、对话记录 |
| **会话** | 💬 | 对话测试 | 独立的对话界面，选择 Agent 后进行多轮交互 |
| **构建项目** | 📋 | 项目管理 | 查看所有构建任务的列表和进度 |
| **能力工具** | 🔧 | 工具和 MCP | 浏览平台工具库、管理 MCP 服务器 |
| **业务洞察** | 📊 | 数据分析 | 查看平台使用数据和业务分析 |
| **系统配置** | ⚙️ | 个人设置 | 管理账户信息、API 配置、通知偏好 |
| **用户管理** | 👥 | 管理用户 | 管理平台用户账号和权限（仅管理员可见） |

### 导航栏底部

导航栏底部显示以下信息：

- **当前用户** — 你的用户名和角色标识（Admin 或 User）
- **创建 Agent** — 快捷创建入口，点击「开始创建」可直接进入创建页面

::: tip 导航栏折叠
点击导航栏顶部的折叠按钮可以收起导航栏，在小屏幕上获得更大的工作区域。
:::

## 快速构建区域

工作台最醒目的区域是顶部的 **快速构建入口**，这是创建 Agent 最便捷的方式。

### 使用方法

1. **输入需求描述** — 在文本框中用自然语言描述你想要的 Agent，例如：

   > 创建一个能查询天气信息并给出穿衣建议的 Agent

   > 帮我做一个数据分析助手，能读取 Excel 文件生成图表

   > 我需要一个能在 PubMed 搜索医学论文的研究助手

2. **点击发送** — 点击右侧发送按钮（或按 Enter）
3. **开始构建** — 系统自动创建构建项目并跳转到构建进度页面

### 快捷模板

输入框下方提供 **快捷模板**，帮你快速启动常见类型的 Agent 构建：

| 模板 | 用途 | 点击后效果 |
|------|------|-----------|
| **医学文献** | 创建能检索和分析医学文献的 Agent | 自动填充需求描述并开始构建 |
| **AWS 报价** | 创建能查询 AWS 服务价格的 Agent | 自动填充需求描述并开始构建 |
| **新闻简报** | 创建能生成每日新闻摘要的 Agent | 自动填充需求描述并开始构建 |

::: tip
快捷模板会直接触发快速创建流程。如果你想先修改需求描述，建议使用 [创建 Agent](/using/create-agent) 页面的完整创建模式。
:::

## 数据概览

快速构建区域下方展示 **4 张统计卡片**，一目了然地展示平台当前的关键状态：

| 指标 | 说明 | 作用 |
|------|------|------|
| **运行中 Agent** | 当前处于运行状态的 Agent 数 / Agent 总数 | 快速了解有多少 Agent 可用 |
| **构建中项目** | 正在进行中的构建任务数量 | 了解当前有多少构建正在进行 |
| **今日业务处理** | 今天所有 Agent 累计处理的业务请求次数 | 了解 Agent 的使用活跃度 |
| **构建成功率** | 历史构建任务的成功百分比 | 了解整体构建质量 |

::: info 数据刷新
统计数据会实时更新。如果数据未更新，可以刷新页面获取最新数据。
:::

## 最近项目

工作台下方左侧展示你 **最近创建或更新的构建项目**，帮助你快速跟踪正在进行的工作：

每个项目卡片显示：

| 字段 | 说明 |
|------|------|
| **项目名称** | 基于你的需求描述自动生成的名称 |
| **构建进度** | 进度条直观展示当前完成百分比 |
| **当前阶段** | 正在执行的 Builder Agent（如 Requirements Agent、Tools Agent 等） |
| **状态标签** | 构建中（蓝色）/ 已完成（绿色）/ 失败（红色） |
| **更新时间** | 最后一次状态更新的时间 |

**点击操作：** 点击项目卡片，直接跳转到该项目的 [构建进度](/using/build-progress) 详情页面。

## 运行中的 Agent

工作台下方右侧展示 **当前正在运行的 Agent 列表**：

| 字段 | 说明 |
|------|------|
| **Agent 名称** | Agent 的名称和简要描述 |
| **调用次数** | 该 Agent 累计被调用的次数 |
| **状态标识** | 运行中（绿色标记）|

**快捷操作：** 点击 Agent 卡片上的「对话」按钮，可以直接打开对话窗口，与该 Agent 进行交互测试。

## 工作流程建议

作为新用户，建议按以下顺序使用工作台：

### 第一次使用

1. **快速构建试试手** — 在快速构建区域输入一个简单的需求，体验自动构建流程
2. **查看构建进度** — 在"最近项目"中点击刚创建的项目，观察 9 个阶段的执行过程
3. **对话测试** — 构建完成后，在"运行中的 Agent"中找到它并发起对话

### 日常使用

1. **查看数据概览** — 了解当前 Agent 运行情况和构建状态
2. **快速创建** — 有新需求时直接在工作台输入描述
3. **管理项目** — 通过"最近项目"快速跟踪构建进展
4. **测试 Agent** — 通过"运行中的 Agent"快速发起对话
