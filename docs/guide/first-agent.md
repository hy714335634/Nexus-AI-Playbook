# 创建第一个 Agent

本指南将带你一步步创建你的第一个 AI Agent。我们将以一个真实案例——"数据分析助手"为例，详细演示整个创建流程。

## 前提条件

- 已成功 [登录系统](/guide/login)
- 了解你想让 Agent 做什么（不需要很具体，一两句话即可）

## 方法一：从工作台快速创建（推荐新手）

这是最快的方式，适合需求比较明确的场景。整个过程只需 3 步。

### 第 1 步：输入需求描述

在工作台顶部的 **快速构建输入框** 中，用自然语言描述你想要的 Agent。

![工作台快速构建](/images/dashboard.png)

**我们的示例需求：**
> 帮我创建一个数据分析 Agent，能读取上传的 CSV 和 Excel 文件，自动识别数据类型、进行统计分析，生成数据摘要报告和可视化图表

::: tip 需求描述建议
好的需求描述应该包含：
- **Agent 做什么** — 核心功能（如"分析数据文件"）
- **输入是什么** — 需要处理的数据格式（如"CSV 和 Excel"）
- **输出是什么** — 期望的结果形式（如"统计报告和图表"）
- **特殊要求** — 任何特殊需求（如"支持中文"、"需要连接 API"）

不需要描述实现细节，平台的 AI 团队会自动设计最佳方案。
:::

输入完成后，点击右侧的 **发送按钮**（或按 Enter 键）。

### 第 2 步：查看构建进度

点击发送后，系统自动创建一个构建项目，页面跳转到 **构建进度** 页面。

![构建进度](/images/build-progress.png)

在这里，你可以实时看到 8 个专业 AI Agent 依次工作：

| 阶段 | Builder Agent | 正在做什么 | 预计耗时 |
|------|--------------|-----------|----------|
| 1 | **Orchestrator** | 分析你的需求，制定构建计划 | ~30 秒 |
| 2 | **Requirements Agent** | 将需求转化为详细的功能规格 | ~1 分钟 |
| 3 | **Architecture Agent** | 设计 Agent 的技术架构（需要哪些工具、模型配置等） | ~1 分钟 |
| 4 | **Design Agent** | 设计 Agent 的对话流程和行为逻辑 | ~1 分钟 |
| 5 | **Prompt Agent** | 编写系统提示词，定义"数据分析专家"角色 | ~1 分钟 |
| 6 | **Tools Agent** | 开发文件读取、统计计算、图表生成等工具函数 | ~2 分钟 |
| 7 | **Developer Agent** | 编写 Agent 主程序代码，整合所有模块 | ~2 分钟 |
| 8 | **DevManager Agent** | 审查代码质量，运行测试 | ~1 分钟 |
| 9 | **Agent Deployer** | 部署 Agent 并使其可用 | ~30 秒 |

**你可以观察到：**
- ✅ **绿色对勾** — 已完成的阶段，点击可查看该阶段的产出
- 🔄 **蓝色旋转** — 正在执行的阶段
- ⏳ **灰色等待** — 尚未开始的阶段

::: info 构建时间
一般需要 **3-10 分钟**，具体取决于需求的复杂程度。简单的 Agent 可能只需 3 分钟，需要开发多个自定义工具的复杂 Agent 可能需要更长时间。构建过程中你可以离开页面，稍后回来查看。
:::

### 第 3 步：测试 Agent

当所有 9 个阶段都显示 ✅ 完成后，Agent 就构建好了！

点击页面上的 **「对话测试」** 按钮，进入与新 Agent 的对话界面。

![对话测试](/images/chat.png)

**试着发送以下消息进行测试：**

1. 先发送一条简单的问候：
   > 你好，你能帮我做什么？

2. Agent 会介绍自己的能力。然后上传一个 CSV 文件并提问：
   > 请分析这份数据，给我一个摘要报告

3. Agent 会读取文件、分析数据、生成报告。你还可以追问：
   > 请帮我画一个柱状图，展示各列的分布情况

恭喜！你的第一个 Agent 已经可以正常工作了。

## 方法二：引导创建（适合复杂或模糊需求）

如果你的需求比较模糊，或者需要构建功能复杂的 Agent，建议使用 **引导创建** 模式。在这个模式下，AI 会通过多轮对话帮你把模糊的想法梳理成精确的需求。

### 第 1 步：进入创建页面

点击左侧导航栏的 **「Agents」** 或工作台底部的 **「创建 Agent」** 按钮。

![创建 Agent 页面](/images/create-agent.png)

### 第 2 步：选择引导创建

你会看到两个选项卡：

| 模式 | 特点 | 适用场景 |
|------|------|----------|
| **快速创建** | 直接输入需求 → 开始构建 | 需求明确，想快速开始 |
| **引导创建** | AI 通过多轮问答帮你完善需求 | 需求模糊，需要梳理 |

选择 **「引导创建」** 标签。

### 第 3 步：描述初始想法

在文本框中描述你的初步想法，不需要很具体。例如：

> 我想做一个帮助客服团队的 Agent

页面提示说明："*不需要描述得很详细，AI 会通过提问帮你补充细节*"

![引导创建](/images/guided-create.png)

### 第 4 步：回答 AI 的智能提问

**Requirements Agent** 会分析你的初步描述，然后提出一系列有针对性的问题来帮你完善需求。例如：

**第一轮提问：**
- "你的客服团队主要处理哪类产品/服务的咨询？"
- "目前客户最常提出的 Top 5 问题类别是什么？"
- "Agent 需要访问哪些知识库或内部系统来获取答案？"

**你的回答：**
> 我们是一家 SaaS 公司，客户主要询问产品功能、账单问题、技术故障排除。需要能查询我们的帮助中心文档。

**第二轮追问：**
- "Agent 需要支持哪些语言？"
- "当 Agent 无法回答时，如何处理？转人工客服还是提交工单？"
- "对回复风格有什么要求？正式、专业、还是友好轻松？"

**你的回答：**
> 需要中英文双语。无法回答时转人工客服。风格要专业但友好。

AI 可能会继续追问，也可能认为信息已经足够了。

::: info 多轮对话
你可以进行多轮对话直到满意。每一轮回答后，AI 会评估需求是否足够完整和精确。
:::

### 第 5 步：审核增强需求

当 AI 认为收集的信息足够后，会生成一份 **增强需求文档**。这份文档比你的原始描述更完整、更精确：

**增强需求文档示例：**

```
Agent 名称：智能客服助手

目标定位：
  为 SaaS 产品提供 7×24 小时自动客服，处理产品咨询、
  账单查询和技术支持。

核心功能：
  1. 产品功能咨询 — 根据帮助中心文档回答功能使用问题
  2. 账单问题处理 — 查询账单状态、解释收费规则
  3. 技术故障排除 — 引导用户进行基础排障
  4. 人工转接 — 无法处理时自动转接人工客服

语言支持：中文、英文
回复风格：专业、友好、简洁

工具需求：
  - 帮助中心文档搜索工具
  - 账单查询 API 工具

行为约束：
  - 不编造信息，无法确定时坦诚告知
  - 涉及敏感操作（退款、账号删除）必须转人工
```

### 第 6 步：编辑并确认

你可以在文本编辑器中直接修改增强需求的内容：

- **添加** 遗漏的功能点
- **删除** 不需要的内容
- **调整** 优先级或措辞
- **补充** 更多细节

修改完成后，点击 **「确认并开始构建」**。后续流程与快速创建相同 — 系统启动 9 阶段构建流水线。

## 使用快捷模板

如果你没有明确的需求，可以从 **预置模板** 开始。模板提供了常见场景的需求描述，你可以在此基础上修改。

![快速创建](/images/quick-create.png)

### 可用模板

| 模板 | 预置功能 | 适用场景 |
|------|----------|----------|
| **数据分析 Agent** | 读取数据文件、统计分析、生成图表 | 需要定期处理和分析数据 |
| **内容创作 Agent** | 撰写文章、生成文案、内容编辑 | 需要高质量的文字内容产出 |
| **市场调研 Agent** | 搜索网络信息、整理报告、竞品分析 | 需要收集和整理市场信息 |
| **技术开发 Agent** | 编写代码、代码审查、技术文档 | 需要辅助编程和技术工作 |

### 使用方法

1. 在创建页面选择 **「快速创建」** 标签
2. 点击你感兴趣的模板卡片
3. 模板会自动填充 Agent 名称和需求描述
4. **修改和补充**需求描述（非常重要！模板是通用的，你应该根据实际场景调整）
5. 点击 **「开始构建」**

::: tip 模板只是起点
模板提供的是一个通用的起点。建议你在模板基础上，补充你的具体业务场景、数据格式、输出要求等信息，这样构建出来的 Agent 会更符合你的实际需求。
:::

## 需求描述技巧

好的需求描述能显著提升 Agent 的质量。以下是一些技巧：

### 好的需求描述

```
创建一个医学文献研究助手，具备以下能力：
1. 在 PubMed 上搜索指定主题的论文
2. 能解析上传的 PDF 论文，提取摘要、结论和关键数据
3. 按照 APA 格式生成引用列表
4. 能用中文和英文回答问题
5. 遇到不确定的信息时明确告知，不编造引用
```

### 不太好的需求描述

```
帮我做个能搜论文的东西
```

### 需求描述要素清单

| 要素 | 说明 | 示例 |
|------|------|------|
| **核心功能** | Agent 的主要能力 | "搜索论文、解析 PDF" |
| **数据来源** | 需要连接什么数据或服务 | "PubMed 数据库" |
| **输入格式** | 用户会提供什么 | "PDF 文件、搜索关键词" |
| **输出格式** | 期望 Agent 返回什么 | "APA 格式引用列表" |
| **语言要求** | 需要支持什么语言 | "中文和英文" |
| **行为约束** | Agent 不应该做什么 | "不编造引用" |

## 构建完成后你可以做什么

Agent 构建完成后，你可以：

| 操作 | 入口 | 说明 |
|------|------|------|
| **对话测试** | 构建进度页 → "对话测试" | 立即与 Agent 对话，验证功能 |
| **查看代码** | Agent 详情页 → "代码" | 查看自动生成的 Python 代码和提示词 |
| **管理 Agent** | 左侧导航 → "Agents" | 修改配置、查看调用记录 |
| **部署到云端** | Agent 详情页 → "部署到 AgentCore" | 将 Agent 部署到 AWS 云端托管 |
| **增量更新** | Agent 详情页 → "更新 Agent" | 基于新需求更新已有 Agent |
