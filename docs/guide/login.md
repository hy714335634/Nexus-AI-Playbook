# 登录系统

打开浏览器，访问系统地址即可进入 Nexus-AI 登录页面。

![登录页面](/images/login.png)

## 支持的浏览器

Nexus-AI 是一个现代化的 Web 应用，推荐使用以下浏览器的最新版本：

| 浏览器 | 版本要求 |
|--------|----------|
| **Google Chrome** | 90+ (推荐) |
| **Microsoft Edge** | 90+ |
| **Mozilla Firefox** | 88+ |
| **Apple Safari** | 14+ |

::: warning
不支持 Internet Explorer。如果使用过旧版本的浏览器，可能会遇到显示异常或功能不可用的情况。
:::

## 登录方式

Nexus-AI 提供两种安全的身份认证方式，适用于不同的组织环境。

### 方式一：账号密码登录

这是最基础的登录方式，适用于所有用户。

**操作步骤：**

1. 在登录页面，找到用户名和密码输入框
2. 输入你的 **用户名**（由管理员分配）
3. 输入你的 **密码**
4. 点击 **「登录」** 按钮
5. 登录成功后，系统自动跳转到工作台

![填写登录信息](/images/login-filled.png)

::: tip 默认管理员账号
系统首次部署后，会生成一个默认管理员账号。请联系系统管理员获取你的账号和初始密码。建议首次登录后及时修改密码。
:::

**安全机制：**

Nexus-AI 使用 **JWT（JSON Web Token）** 进行身份认证。登录成功后，系统会颁发一个加密令牌，后续的所有操作都通过该令牌验证身份。令牌有过期时间，过期后需要重新登录。

### 方式二：SSO 单点登录

如果你所在的组织配置了 **SSO（Single Sign-On）** 单点登录，登录页面会显示 **「SSO 登录」** 按钮。

**操作步骤：**

1. 在登录页面点击 **「SSO 登录」** 按钮
2. 系统跳转到你组织的身份认证平台（如企业 AD、SAML 服务等）
3. 在认证平台上使用你的企业账号完成身份验证
4. 认证成功后，系统自动返回 Nexus-AI 并完成登录

**SSO 的优势：**

| 优势 | 说明 |
|------|------|
| **统一认证** | 使用企业已有的账号体系，无需记忆额外密码 |
| **安全性高** | 支持 SAML 协议，企业级安全标准 |
| **便捷管理** | 离职员工在企业系统中禁用后，自动无法登录 Nexus-AI |

::: info 关于 SSO 配置
SSO 登录需要管理员预先配置 SAML 集成。如果你在登录页面没有看到 SSO 选项，请联系系统管理员开启。
:::

## 登录后的界面

登录成功后，你将直接进入 **工作台（Dashboard）**。工作台是 Nexus-AI 的主界面，你可以在这里：

- 快速创建新的 Agent
- 查看平台整体数据
- 管理已有的 Agent 和构建项目
- 与 Agent 进行对话测试

详细介绍请参阅 [认识工作台 →](/guide/workspace)

## 账号角色

Nexus-AI 有两种用户角色，登录后看到的功能菜单可能略有不同：

| 角色 | 说明 | 可用功能 |
|------|------|----------|
| **Admin（管理员）** | 拥有所有权限 | 所有功能 + 用户管理 + 系统配置 |
| **User（普通用户）** | 日常使用权限 | Agent 创建、管理、对话、工具使用 |

你可以在登录后左侧导航栏底部看到自己的用户名和角色标识。

## 常见问题排查

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 忘记密码 | — | 联系管理员，在 [用户管理](/admin/users) 页面重置密码 |
| 输入正确密码但无法登录 | 账号被禁用 | 联系管理员检查账号状态是否为 Active |
| SSO 登录失败 | 企业认证服务异常 | 检查企业网络连接，联系 IT 部门确认 SAML 服务状态 |
| 页面无法访问 | 网络不通或地址错误 | 确认系统地址正确，检查网络连接和防火墙设置 |
| 登录后自动退出 | Token 过期 | 正常现象，重新登录即可 |
